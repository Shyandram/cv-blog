This site is a computer vision course you can read in order or dip into. It starts with images as arrays of numbers and builds up to modern deep networks.

## How it is organized

The **Learn** section has eight tracks: Foundations, Image Processing, Natural Language Processing, Pattern Recognition, Machine Learning, Deep Learning for Computer Vision, Optimization and Information Theory. Each tutorial lists its prerequisites, so you can always see what to read first.

## Running the code

Some tutorials provide a matching Jupyter notebook; others include standalone code blocks. When a notebook is available, click **Open in Colab** at the top of the page to run it in your browser.

The blog, where this post lives, is for everything outside the curriculum: paper notes, tool reviews and longer essays.
