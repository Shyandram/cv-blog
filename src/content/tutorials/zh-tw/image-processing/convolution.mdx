## 直覺

每一個輸出像素，都是它周圍鄰居的加權總和。這些權重排成一個小網格，稱為**卷積核**（kernel）。只要改變這九個數字，同一個運算就能做到模糊、銳化或強調邊緣。

## 數學

對輸入影像 $I$ 與大小為 $(2k+1) \times (2k+1)$ 的卷積核 $K$，輸出 $G$ 為

$$
G(x, y) = \sum_{i=-k}^{k} \sum_{j=-k}^{k} K(i, j)\, I(x + i,\; y + j)
$$

嚴格來說這是*互相關*（cross-correlation）。真正的卷積會先把卷積核翻轉成 $K(-i, -j)$；對於模糊這類對稱的卷積核，兩者沒有差別。

模糊卷積核的權重總和為 $1$，所以平坦區域的亮度不變；邊緣卷積核的權重總和為 $0$，平坦區域會變成 $0$，只留下變化的地方。

<Callout type="note" title="OpenCV 小細節">
`cv2.filter2D` 計算的是互相關而不是卷積。需要區分時，先用 `cv2.flip(K, -1)` 翻轉卷積核。
</Callout>

## 程式碼

用 NumPy 從頭實作：

```python
import numpy as np

def conv2d(img, K):
    """img: (H, W) float32，K: (3, 3)，邊界以複製邊緣像素處理。"""
    H, W = img.shape
    p = np.pad(img, 1, mode="edge")
    out = np.zeros_like(img)
    for i in range(3):
        for j in range(3):
            out += K[i, j] * p[i:i + H, j:j + W]
    return out
```

用 OpenCV 做同樣的事：

```python
import cv2
import numpy as np

img = cv2.imread("cameraman.png", cv2.IMREAD_GRAYSCALE).astype(np.float32) / 255
sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], np.float32)
edges = cv2.filter2D(img, -1, sobel_x)
```

<ImageCompare beforeLabel="輸入" afterLabel="高斯 σ=1.4" alt="包含圓形、方塊、棋盤格與條紋的測試影像" />

常見錯誤：

- **整數溢位。** 用銳化卷積核處理 `uint8` 影像時，負值會被截成 0。請改用 `float32` 計算。
- **邊界處理。** 補零會讓模糊後的影像邊緣變暗。請使用 `mode="edge"` 或 `cv2.BORDER_REFLECT`。
