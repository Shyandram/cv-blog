## 先看全貌

語言表面是線性的，解讀卻有結構。句子以有順序的詞序列輸入，但讀者會把詞分組，並辨識彼此的關係。「We saw robots with cameras」可能描述帶著相機的機器人，也可能描述觀察時使用的器材。單靠詞清單無法選定解讀。

McRoy 第 3、4 章介紹語法類別與語法處理，並另附圖表剖析附錄 [1]。Hagiwara 第 5 章發展序列標記，包括詞性標記 [2]。本章結合兩種觀點：標記器為各位置附上類別，剖析器則搜尋連結位置的結構。當某個位置的選擇會限制其他位置的選擇時，兩者都是結構化預測。

<Callout type="tip" title="用最簡單的話說">
句子像一組建構玩具。詞是零件，文法說明怎樣連接。標記為零件貼上標籤；剖析顯示連接方式。有時相同零件能做出兩種合理建構。好的解釋應呈現兩者，再詢問哪個符合情境。
</Callout>

語法有助擷取誰做了什麼、定位修飾語、辨識論元邊界，並建立區分流暢度與結構理解的測試。它無法處理所有語意問題：合文法的句子可能是假的，拼字錯誤或不完整訊息也可能清楚傳達意思。因此，我們把語法視為範圍明確的表示，而不是理解的通用定義。

## 詞、詞法與語法類別

**白話版。** 詞的類別描述它在句子中的行為。拼字能提供線索，但脈絡通常決定實際用法。

詞法（morphology）研究詞內結構。複數詞尾、時態標記與派生前綴能提供有用證據，但不同語言不一定用相同片段或詞邊界表達性質。為了建模效率學出的子詞 token，也不一定對應語言學上的詞素。應區分模型斷詞與標註使用的語法單位。

詞性（part of speech）描述名詞、動詞等語法類別。名詞通常是名詞片語的中心，動詞通常是子句述語的中心。這是分布上的描述，不是每個名詞都必須指實體物品的規則。「Decision」與「arrival」雖指抽象內容與事件，仍是名詞。

相同表面詞可以有不同類別。在原創例句「the pilots can land」與「the metal can fell」中，「can」扮演不同角色。第二句也顯示，句子其餘部分改變時，熟悉的局部片語可能誤導。標記器必須考慮允許的脈絡與標註規則。

已標記句子可表示為：

$$
\mathbf x=(x_1,\ldots,x_T),
\qquad
\mathbf y=(y_1,\ldots,y_T),
\qquad
y_t\in\mathcal Y.
$$

其中 $\mathbf x$ 是輸入詞序列，$x_t$ 是位置 $t$ 的詞，$T$ 是序列長度，$\mathbf y$ 是標記序列，$y_t$ 是詞 $x_t$ 的標記，$\mathcal Y$ 是有限標記集合。$t$ 與 $T$ 指語言學上的詞位置，不會自動等同模型子詞位置。

標註也需要縮寫、標點、多詞表達與多種合理分析的規則。當模型使用子詞時，應定義如何把輸出對應回詞。只用第一個子詞表示是一種做法；池化所有子詞則是另一種。不論選哪個，標準標籤與解碼輸出都必須使用相同單位。

## 局部分類與序列預測

**白話版。** 分別替每個詞選最佳標記，可能錯過更好的共同解讀。序列模型把標記間的關係寫清楚。

局部分類器可以預測：

$$
\hat y_t=\operatorname*{argmax}_{k\in\mathcal Y}
p_\theta(y_t=k\mid\mathbf x).
$$

其中 $\hat y_t$ 是位置 $t$ 選出的標記，$k$ 遍歷標記集合 $\mathcal Y$，$p_\theta$ 是參數為 $\theta$ 的模型，$\mathbf x$ 是整個可見輸入序列。局部輸出頭仍可以讀取上下文；「獨立」描述輸出決策規則，不一定描述編碼器。

結構化解碼器則選擇：

$$
\hat{\mathbf y}
=\operatorname*{argmax}_{\mathbf y\in\mathcal A(\mathbf x)}
S_\theta(\mathbf x,\mathbf y).
$$

其中 $\hat{\mathbf y}$ 是選出的完整標記序列，$\mathcal A(\mathbf x)$ 是輸入 $\mathbf x$ 允許的分析集合，$S_\theta$ 是由參數 $\theta$ 對輸入與分析配對給出的分數。允許集合可以限制標註規則，分數則可以獎勵合理的相鄰標籤。

許多 NLP 任務都有這個差別。實體標籤必須組成有效跨度；依存樹中每個非根詞需要一個父節點；生成的結構化紀錄需要符合結構規格。較強的編碼器不會自動保證有效輸出，解碼器或獨立驗證器必須落實應用需要的限制。

結構化解碼也有取捨：錯誤的硬限制可能排除合法構造。如果文法要求每句都有明示主語，就會拒絕許多命令與片段。應記錄限制與預期輸入範圍，而不是把受限制的輸出當成該限制普遍適用所有語言的證據。

## 用隱藏馬可夫模型標記

**白話版。** 想像標記形成一串隱藏序列，每個標記再產生一個詞。相鄰標記與詞的相容性共同決定分數。

Rabiner 綜述的一階隱藏馬可夫模型（hidden Markov model，HMM）[3] 使用：

$$
p(\mathbf x,\mathbf y)
=\pi_{y_1}b_{y_1}(x_1)
\prod_{t=2}^{T}a_{y_{t-1},y_t}b_{y_t}(x_t).
$$

其中 $p(\mathbf x,\mathbf y)$ 是詞與標記的聯合機率，$\pi_k$ 是起始標記為 $k$ 的機率，$a_{j,k}$ 是從標記 $j$ 轉移到 $k$ 的機率，$b_k(w)$ 是標記 $k$ 發射詞 $w$ 的機率，$x_t$ 與 $y_t$ 是位置 $t$ 的詞與標記，$T$ 是序列長度。本例以固定長度為條件；若要建模終止，可加入明確的結束狀態因子。

起始機率總和為一；每列轉移機率總和為一；每個發射分布在觀察詞彙表上的總和也為一。這些正規化條件讓式子成為機率模型，而不是任意有用分數的乘積。

假設相當有限：下一個標記只依前一個標記，發射詞只依目前標記。真實句子有長距離依存、詞彙偏好與篇章脈絡。本章使用這個模型的價值，在於假設與精確解碼器都看得見；它是一個用來區分模型容量與搜尋的小型實驗室。

如果有完整標記的訓練樣本，可以計算起始狀態、轉移與發射次數，再依明確平滑規則正規化。如果只有詞，估計隱藏狀態就是另一個問題；沒有監督學出的狀態，不會自動成為有名稱的語法類別。下例手動指定機率，避免訓練不確定性遮蔽解碼機制。

## 最大路徑解碼

**白話版。** 保留以每種標記結束的最佳部分路徑。延伸這些路徑，就能找到最佳完整序列，不必列出所有可能。

使用對數機率，把乘積轉成總和：

$$
\begin{aligned}
D_1(k)&=\log\pi_k+\log b_k(x_1),\\
D_t(k)&=\log b_k(x_t)+
\max_{j\in\mathcal Y}\bigl[D_{t-1}(j)+\log a_{j,k}\bigr].
\end{aligned}
$$

其中 $D_t(k)$ 是涵蓋位置 $1$ 到 $t$、且以標記 $k$ 結束的最佳路徑對數分數，$\pi_k$ 是起始機率，$b_k(x_t)$ 是發射機率，$a_{j,k}$ 是轉移機率，$\mathcal Y$ 是標記集合。$j$ 與 $k$ 分別指前一個與目前標記。零機率貢獻 $-\infty$。

這是最大路徑動態規劃，通常稱為 Viterbi 解碼 [3]。每格記錄達到最大值的前一個標記。選出最佳最後標記後，反向追蹤回溯指標。如果只保留分數，就會失去實際序列。

解碼器考慮 $T$ 個位置與所有相鄰標記配對，因此 $K=|\mathcal Y|$ 個標記時，時間複雜度為 $O(TK^2)$。保留所有回溯指標的分數表占 $O(TK)$ 空間；列舉所有標記序列則需考慮 $K^T$ 種可能。這是在特定分解下的計算節省，不是近似搜尋結果。

下列獨立範例以完整列舉確認動態規劃答案。教學觀察「fish fish」刻意使用歧義詞。獨立的發射偏好會在兩個位置選名詞，聯合模型則可能偏好名詞後接動詞。

```python
import itertools
import numpy as np

tags = ["N", "V"]
vocabulary = ["fish", "swim"]
initial = np.array([0.8, 0.2])
transition = np.array([[0.1, 0.9], [0.8, 0.2]])
emission = np.array([[0.7, 0.3], [0.3, 0.7]])
words = ["fish", "fish"]
observation = [vocabulary.index(word) for word in words]
assert np.allclose(transition.sum(axis=1), 1)
assert np.allclose(emission.sum(axis=1), 1)

scores = np.empty((len(words), len(tags)))
back = np.zeros_like(scores, dtype=int)
scores[0] = np.log(initial) + np.log(emission[:, observation[0]])
for t in range(1, len(words)):
    candidates = scores[t - 1, :, None] + np.log(transition)
    back[t] = candidates.argmax(axis=0)
    scores[t] = candidates.max(axis=0) + np.log(emission[:, observation[t]])
path = [int(scores[-1].argmax())]
for t in range(len(words) - 1, 0, -1):
    path.append(int(back[t, path[-1]]))
path.reverse()

def joint_score(sequence):
    value = np.log(initial[sequence[0]])
    value += np.log(emission[sequence[0], observation[0]])
    for t in range(1, len(words)):
        value += np.log(transition[sequence[t - 1], sequence[t]])
        value += np.log(emission[sequence[t], observation[t]])
    return value

all_paths = list(itertools.product(range(len(tags)), repeat=len(words)))
brute = max(all_paths, key=joint_score)
assert tuple(path) == brute
print("local emission choices:", [tags[emission[:, w].argmax()] for w in observation])
print("best joint path:", [tags[index] for index in path])
print("joint log score:", round(joint_score(path), 3))
```

改變轉移機率，即使每個詞的局部偏好不變，也能改變選出的序列。這並不證明新選擇符合真實語言；它證明模型與解碼器實作了預期的依存關係。

## 成分與上下文無關文法

**白話版。** 片語結構把詞組成能遞迴結合的單位。文法規定允許的組合；剖析則是某個句子的推導。

上下文無關文法（context-free grammar）可定義為：

$$
G=(\mathcal N,\Sigma,\mathcal R,S).
$$

其中 $G$ 是文法，$\mathcal N$ 是非終結類別集合，$\Sigma$ 是終結詞彙表，$\mathcal R$ 是改寫規則集合，$S\in\mathcal N$ 是起始類別。非終結符代表名詞片語等結構，終結符則是觀察到的詞。上下文無關規則替換一個非終結符，而不檢查周圍符號。

原創教學文法可使用 $S\rightarrow NP\ VP$、$VP\rightarrow V\ NP$、$PP\rightarrow P\ NP$ 與 $NP\rightarrow NP\ PP$。其中 $S$ 表示句子，$NP$ 表示名詞片語，$VP$ 表示動詞片語，$PP$ 表示介系詞片語，$V$ 表示動詞類別，$P$ 表示介系詞類別。這是教學文法的符號選擇，不是完整英文文法。

遞迴規則能以有限規格產生無界的句子家族，但也可能讓天真的搜尋反覆做相同工作或無限循環。剖析器因此需要搜尋策略、終止規則，以及緊湊的部分分析表示。

應區分涵蓋範圍與偏好。規則系統可能接受句子，卻給出多個分析；也可能因缺少詞彙條目或產生式，無法剖析完全合理的句子。剖析失敗只表示所實作的文法與搜尋沒有找到分析，不表示使用者寫了無意義的內容。

McRoy 把文法、搜尋與圖表視為明確的計算表示 [1]。對應用而言，可檢查性是重要優點：能顯示哪個規則連結了跨度，以及歧義出現在哪裡。這對把結構送往擷取系統之前尤其有用，否則系統可能默默選錯修飾對象。

## 依跨度進行圖表剖析

### 由上而下的假設與由下而上的證據

**白話版。** 剖析器可以從句子預期包含什麼開始，也可以從觀察詞已支持什麼開始。兩個方向都需要避免重複工作。

由上而下搜尋從起始類別展開產生式，形成預期子節點。它能排除不符合預期的詞彙分析，但不好的展開選擇可能導致很長的失敗路徑。若遞迴產生式把第一個子節點展成同一類別，就可能在還沒消耗輸入前反覆遇到同一個未解預期。

由下而上搜尋從觀察詞建立跨度支持的類別，可能產生許多不屬於任何完整句子的片語。對特定最後推導而言，這是多餘工作；但中間結果也可能被多個成功分析共用。

因此，設計問題不只是選哪個方向「比較好」。應問部分工作如何表示、套用哪些限制，以及兩個部分分析何時算同一搜尋狀態。圖表能儲存完成跨度；更一般的實作也能儲存部分完成的規則應用。另一條路徑抵達既有狀態時，不必重新計算。

記憶化本身不會解決歧義。兩個推導可能共享跨度與類別，但內部不同。如果任務只需辨識，合併成布林狀態便足夠；如果需要偏好的剖析，狀態需保留分數與回溯指標；如果需要所有選項，就需以森林保留不同推導連結。

這也說明實作加入遞迴文法時為何需要小心。數學上定義良好的文法，可能讓天真的遞迴剖析器無法終止；反之，剖析器也可能藉由刪掉文法允許的分析而快速結束。應說明演算法是否完整搜尋所實作文法，或採取有界搜尋。

下一個可執行範例使用由下而上的二元跨度，依存順序因此很簡單：每個父節點只依較短的子節點。限制文法是教學選擇。支援一元產生式、空跨度或更廣文法，需要對應的演算法延伸，不能只把字典條目加進原本迴圈。

**白話版。** 儲存每個連續跨度可能的類別。把短跨度結合成長跨度，並讓所有完整剖析共用結果。

採用半開邊界：跨度 $[i,j)$ 包含位置 $i$ 到 $j-1$ 的 token。對二元與詞彙規則的文法，辨識可寫成：

$$
C[i,j,A]=
\bigvee_{\substack{A\rightarrow BC\in\mathcal R\\i<k<j}}
\left(C[i,k,B]\land C[k,j,C]\right).
$$

其中 $C[i,j,A]$ 是類別 $A$ 能涵蓋跨度 $[i,j)$ 的布林敘述，$\mathcal R$ 是二元規則集合，$A\rightarrow BC$ 結合左類別 $B$ 與右類別 $C$，$k$ 是內部切分邊界，$\land$ 表示兩個子節點都必須存在，$\bigvee$ 表示至少一組規則與切分成功。字母 $C$ 同時出現在圖表符號與右子節點類別中，可由中括號與類別引數分辨角色。

先以詞彙規則初始化長度為一的格子，再依跨度長度、起點、切分點與相容規則迭代。子節點比父節點短，因此已經完成。一元規則與空產生式需要額外處理；本章可執行文法刻意不包含兩者。

這個演算法能辨識輸入，但辨識本身無法解釋樹。應以回溯指標或緊湊森林儲存成功組合。多個父節點可以共享子跨度，而不必複製完整子樹。高度歧義句子若展開所有完整樹，即使辨識是多項式時間，展開仍可能需要指數時間。

固定二元文法下，跨度與切分巢狀迴圈對 token 長度呈立方關係；圖表有平方數量的跨度，每個跨度包含可能類別。這些成本描述指定演算法，不是所有現代剖析器。神經網路或轉移式方法使用不同表示與搜尋選擇。

## 保留兩種分析的剖析器

**白話版。** 文法允許兩種附接時，應報告兩個選項。剖析器不應只因某個選項先插入，就丟掉歧義。

下列獨立剖析器在圖表格子中儲存完整小樹，刻意比緊湊森林簡單。它適合五詞示範；前一節已說明，明確列舉不適合大型歧義輸入。

```python
from collections import defaultdict

words = "we saw robots with cameras".split()
lexical = {
    "we": ["NP"], "saw": ["V"], "robots": ["NP"],
    "with": ["P"], "cameras": ["NP"],
}
rules = [
    ("S", "NP", "VP"),
    ("VP", "V", "NP"),
    ("VP", "VP", "PP"),
    ("NP", "NP", "PP"),
    ("PP", "P", "NP"),
]
chart = defaultdict(lambda: defaultdict(list))
for i, word in enumerate(words):
    for category in lexical.get(word, []):
        chart[i, i + 1][category].append((category, word))
for length in range(2, len(words) + 1):
    for start in range(len(words) - length + 1):
        end = start + length
        for split in range(start + 1, end):
            for parent, left, right in rules:
                for left_tree in chart[start, split].get(left, []):
                    for right_tree in chart[split, end].get(right, []):
                        tree = (parent, left_tree, right_tree)
                        if tree not in chart[start, end][parent]:
                            chart[start, end][parent].append(tree)

def bracket(tree):
    if len(tree) == 2:
        return f"({tree[0]} {tree[1]})"
    return f"({tree[0]} {bracket(tree[1])} {bracket(tree[2])})"

parses = chart[0, len(words)].get("S", [])
assert len(parses) == 2
for tree in parses:
    print(bracket(tree))
print("complete parses:", len(parses))
```

一棵樹把介系詞片語放進受詞名詞片語，另一棵則讓它修飾動詞片語。兩者都按順序使用每個詞，並符合文法。要選擇其中之一，可能需要周圍場景、先前篇章，或超出目前規則的詞彙偏好。

加入未知詞，某個詞彙格子可能變空。正確做法是診斷涵蓋範圍。正式服務可以使用備援標記器、允許明確未知類別，或要求澄清，但每個備援都會改變接受的語言，應記錄並測試。

## 結構上的機率

**白話版。** 文法說明哪些分析存在；機率模型可以偏好部分分析，並彙整各選項的不確定性。

機率式上下文無關文法為每個產生式配置機率，並在相同父類別的規則間正規化。一個推導具有：

$$
p(\mathcal T)=\prod_{r\in\mathcal T}p(r),
\qquad
\hat{\mathcal T}=\operatorname*{argmax}_{\mathcal T\in\mathcal P(\mathbf x)}
p(\mathcal T).
$$

其中 $\mathcal T$ 是完整推導樹，$r$ 索引樹中每次產生式使用，$p(r)$ 是規則機率，$\mathcal P(\mathbf x)$ 是終結輸出為輸入 $\mathbf x$ 的允許剖析集合，$\hat{\mathcal T}$ 是機率最高的剖析。同一規則重複使用時，乘積會分別計入。

把圖表中的選項改成加總，就能計算各推導總機率質量；改成最大值，就能計算最佳推導。兩者回答不同問題：具有許多中等機率剖析的句子，總機率可能高於只有一個強剖析的句子。最佳樹不一定占後驗質量的大部分。

從樹庫估計的規則機率取決於標註慣例與領域。新聞樹庫與客服語料可能有不同片段模式與附接偏好。機率建模提供偏好機制，但不會消除領域依賴。

也可以用上下文編碼器為跨度、規則或依存關係評分。此時語法表示與特徵計算分開：即使分數來自大型神經網路，輸出仍是一棵樹。應直接比較輸出有效性與剖析準確度，而不是由編碼器大小推論結構能力。

## 依存結構與語法角色

**白話版。** 依存分析直接連結詞，顯示哪個詞依附哪個詞，並標記語法關係。

基本依存樹可用中心詞索引表示：

$$
h_t\in\{0,1,\ldots,T\}\setminus\{t\},
\qquad
r_t\in\mathcal D.
$$

其中 $h_t$ 是詞 $t$ 的中心詞索引，$0$ 表示人工根節點，$T$ 是句子長度，$r_t$ 是該詞的關係標籤，$\mathcal D$ 是關係集合。有效基本樹還需要明確的根節點規則、連通性與無有向循環。

逐詞獨立選中心詞可能違反全域要求。兩個詞可能互相選為中心而形成循環；數個不連通部分可能沒有唯一句根。樹解碼器應落實預期結構，或由服務驗證並拒絕無效分析。

Universal Dependencies 提供跨語言的詞法、詞性與語法依存標註框架 [4]。類別設計希望兼顧跨語言比較與語言專屬差異。這是標註框架，不表示每種語言具有相同詞序或明示語法標記。

片語結構與依存關係強調不同資訊。成分樹清楚表示跨度分組；依存樹清楚表示詞彙中心與關係。相互轉換需要中心詞、標點與功能詞的約定，不能只當成換一種畫法。

對擷取而言，語法角色是有用證據，但不能與語意角色互換。被動句改變語法主語位置，卻保留誰對誰做了什麼。下一章發展這個差別，說明依存箭頭為何不能單獨證明真實世界關係。

## 評估與實務失敗模式

**白話版。** 比較剖析器承諾產生的表示，並檢查斷詞、標註或脈絡改變答案的情況。

標記準確率比較已對齊詞位置的預測與參考標籤。成分評估通常比較有標籤跨度，但需說明是否包含詞彙預終結符、標點與根。依存評估可以只比中心詞，也可以一起比較中心詞與關係標籤。不同納入規則改變分母，應把慣例與分數一起公布。

帶標籤依存附接可寫成：

$$
\operatorname{LAS}=
\frac1M\sum_{t\in\mathcal I}
\mathbf1[(\hat h_t,\hat r_t)=(h_t,r_t)].
$$

其中 $\operatorname{LAS}$ 是帶標籤附接分數（labeled attachment score），$\mathcal I$ 是評估詞位置集合，$M=|\mathcal I|$ 是集合大小，$\hat h_t$ 與 $\hat r_t$ 是預測中心詞與關係，$h_t$ 與 $r_t$ 是參考中心詞與關係，$\mathbf1[\cdot]$ 是指示函數。Universal Dependencies 框架定義這類比較所用結構 [4]。套用公式前，必須固定 token 對齊。

把結構錯誤與輸入切分錯誤分開。如果標準標註有兩個詞，斷詞器卻輸出一個，就無法正常解讀附接比較。應報告切分不符，並說明如何處理對齊，不要默默刪除困難樣本。

建立小型診斷配對：保持詞彙相近但移動修飾語，加入巢狀子句，把主動句改為被動句，或加入片段與混合語言片語。即使總體分數穩定，這些測試仍能揭露模型結構在什麼條件下改變。

句子確實有歧義時，不要把一棵標準樹視為絕對確定。語料需要選定慣例或經裁決的分析，但其他分析可能也合理。對應用而言，應問分歧是否改變擷取事實或行動，讓剖析錯誤與實際後果連結。

## 現代觀點

**綜述觀點。** Zhao 等人的 2023–2026 年大型語言模型綜述區分訓練、調適、使用與能力評估 [5]。語法在這個分類中可扮演不同角色：監督輸出、內部表示探測、生成限制或診斷挑戰。Chang 等人的評估綜述再區分量測任務與使用的基準及程序 [6]。流暢生成與一般評估分數，都不能取代對指定樹表示的檢查。

**近期原始研究。** Tian、Xia 與 Song 的 2024 年研究檢查語言模型成分剖析與改善結構輸出的做法 [7]。Hale 與 Stanojević 的 2024 年研究則跨語言測試特定語法普遍性 [8]。後者結果因語言而異，顯示以英文為主的結構測試不能證明一致的多語言能力。兩者回答不同問題：產生有標註的剖析，以及呈現特定語法泛化。

**2023–2026 年實務。** 上下文編碼器可以為標記與樹提供豐富證據，大型語言模型也可以依提示回傳結構 [5]、[7]。輸出剖析器與結構驗證器仍有必要。看起來合理的括號字串，可能漏掉 token、重排詞，或不形成連通樹。消費輸出前，應驗證終結輸出、類別集合與全域限制。

**未解問題。** 標註框架各有差異；低資源語言缺少獨立檢查的樹；切分與語法交互影響；自發對話含有片段與修正；模型也可能學會基準慣例，卻缺乏穩健的組合能力。保留替代分析、測試結構最小配對，以及量測下游後果，是研究這些限制的具體做法。

## 重點整理

- 語言學詞單位與模型子詞單位需要明確對齊。
- 上下文特徵與結構化輸出限制是不同設計選擇。
- 最大路徑解碼在指定分解與假設下是精確的。
- 文法無法剖析表示涵蓋範圍不足，不是對說話者的評價。
- 圖表共享跨度；列舉所有樹仍可能呈指數成長。
- 片語結構與依存關係表示語法的不同面向。
- 驗證結構輸出，並清楚說明評估分母。
- 語法為意義提供證據，但不決定真實性或意圖。
