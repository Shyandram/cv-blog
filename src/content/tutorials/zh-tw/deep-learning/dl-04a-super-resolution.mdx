## 你將學到

- 為什麼單張超解析度（SR）是**不適定問題**：平方誤差學後驗平均，L1 學逐座標中位數，兩者都可能抑制不確定細節。
- **非盲**設定已知退化，常用 bicubic ×2／×3／×4；插值與線性濾波能做到什麼。
- 依序理解六個深度 SR 決策：放大位置／子像素卷積、殘差、移除 BN、通道與視窗注意力，從 SRCNN 到 HAT。
- 感知、對抗與擴散目標如何以像素準確度交換自然外觀，以及感知—失真邊界的意義。
- Y 通道、裁邊、測試集與指標如何影響排名，以及常見失敗模式。

## 先看全貌

超解析度要把小圖放大，也讓它更清楚。伸展像素容易，補足從未記錄的細節才難；模型從自然影像知識補上內容，同時帶來能力與風險。

## 問題：一個輸入，許多答案

縮圖會失去資訊，多個 HR 可產生同一 LR；平方誤差以它們的平均為目標，可能模糊位置不一致的邊緣和紋理。

### 問題設定與符號

單圖超解析度（SISR）從 $y\in\mathbb R^{H\times W\times C}$ 估計 $x\in\mathbb R^{sH\times sW\times C}$，$s$ 是倍率，$H,W$ 是 LR 尺寸，$C$ 是色彩通道。[DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#統一的觀點) 的前向模型為：

$$
y = (x * k)\downarrow_s + n,
$$

$k$ 是光學、像素積分或抗混疊核，$*$ 是逐通道二維卷積，$\downarrow_s$ 每 $s\times s$ 留一個樣本，$n$ 為雜訊。非盲推論已知核、倍率及雜訊，條件模型可接受變動值；本章多用訓練／測試相符的固定退化，通常每倍率另訓練。多張位移 LR 的舊式多幀問題 [1] 見[影片 SR](/zh-tw/learn/deep-learning/video-super-resolution/)。

### 為什麼這是病態問題

HR 未知數是量測的 $s^2$ 倍。$s=4$ 時，整體維度每個量測對應 16 個未知，即使無雜訊且算子滿列秩，仍至少有 15 個自由維度。模糊會跨區塊混合，這不是每塊有 15 個獨立不可見像素。$\mathcal D(x)=(x*k)\downarrow_s$ 有大**零空間**：若 $\mathcal D(z)=0$，加上 $z$ 不改變觀測。細紋、精確邊緣和小字常落在這類未約束資訊。

所以 SR 需要一個**先驗**（prior）$p(x)$，也就是「哪些 HR 影像是合理的」的模型。依貝氏定理，每個 HR 候選都有一個後驗機率

$$
p(x \mid y) \propto p(y \mid x)\, p(x),
$$

其中 $p(y \mid x)$ 是概似（likelihood，在給定雜訊下 $\mathcal D(x)$ 能多好地解釋 $y$），$p(x)$ 是先驗。傳統方法手寫先驗；深度 SR 則從（LR, HR）配對中學習先驗。

### 後驗平均造成的模糊

大多數 SR 網路都是在配對上最小化像素損失來訓練的。用平方誤差時，最好的網路輸出的是**後驗平均**（posterior mean）

$$
\hat x_{\text{MMSE}}(y) = \mathbb E[x \mid y] = \int x \, p(x \mid y)\, dx,
$$

這是最小均方誤差（MMSE）估計；L1 則以逐座標後驗中位數為最優，未必等於平均。若多個清楚候選的邊位置／紋理相位不同，平均會變平滑，甚至不是合理樣本。更多資料不能消除目標本身的平均效果。

一個一維的小例子可以把這件事講清楚。一個 64 個取樣的 HR 訊號是一個位置未知的階梯邊緣。我們把每 4 個取樣平均成一個，加上標準差 0.2 的雜訊，然後精確算出 32 個可能邊緣位置上的後驗、它的平均，以及從中隨機抽出的一個樣本。

```python
import numpy as np

rng = np.random.default_rng(0)
n, s, sigma = 64, 4, 0.2                 # HR length, scale factor, LR noise level
cand = np.arange(16, 48)                 # possible edge positions t (the prior: uniform)
X = (np.arange(n)[None, :] >= cand[:, None]).astype(float)    # every HR step edge x_t
DX = X.reshape(len(cand), n // s, s).mean(axis=2)              # their LR versions D(x_t)

err_mmse, err_samp, jump_mmse, jump_samp = [], [], [], []
for _ in range(2000):
    t = rng.integers(len(cand))
    y = DX[t] + sigma * rng.standard_normal(n // s)               # observed LR signal
    logp = -((y - DX) ** 2).sum(axis=1) / (2 * sigma**2)          # log posterior over t
    post = np.exp(logp - logp.max()); post /= post.sum()
    x_mmse = post @ X                                             # posterior mean E[x | y]
    x_samp = X[rng.choice(len(cand), p=post)]                     # one posterior sample
    err_mmse.append(np.mean((x_mmse - X[t]) ** 2)); err_samp.append(np.mean((x_samp - X[t]) ** 2))
    jump_mmse.append(np.diff(x_mmse).max()); jump_samp.append(np.diff(x_samp).max())

print(f"MSE   posterior mean {np.mean(err_mmse):.4f} | posterior sample {np.mean(err_samp):.4f} "
      f"| ratio {np.mean(err_samp) / np.mean(err_mmse):.2f}")
print(f"largest one-pixel jump (a real edge has 1.00): mean {np.mean(jump_mmse):.2f} | sample {np.mean(jump_samp):.2f}")
```

```text
MSE   posterior mean 0.0072 | posterior sample 0.0143 | ratio 1.97
largest one-pixel jump (a real edge has 1.00): mean 0.48 | sample 1.00
```

後驗平均的誤差只有後驗樣本的一半，但它的邊緣是斜坡：平均而言，它最大的單像素跳躍只有 0.48，而每個真實邊緣（以及每個樣本）都跳 1.00。樣本看起來和真實邊緣一模一樣，只是有時位置不對。比值約為 2 並非巧合。Blau 與 Michaeli 證明，如果一個估計器的輸出分布與真實影像完全相同（例如後驗取樣器），它的 MSE 永遠不需要超過 MMSE 估計器的兩倍，也就是 PSNR 差 3 dB [2]。圖 1 顯示一個例子，以及兩個估計器之間的整個範圍。

### 從頻域看 LR 失去的資訊

**白話說。** 縮圖可能把細條紋變成假的粗條紋；前濾波又會削弱倖存細節。SR 同時要銳化被削弱的內容，並用先驗推估缺失內容。

## 基準設定：已知退化

用固定已知算子產生 LR—HR 配對，再對原圖計算重建誤差；常見規則是亮度通道 PSNR。

多數基準用 MATLAB `imresize` 預設 bicubic，縮小時預設抗混疊 [3]、[4]；沒有額外雜訊、相機模糊或壓縮。可重現使多年結果可比，但模型只學反解這個算子。

本章用另一個已知配方：HR 高斯寬 **1.2**、4 × 4 平均、Gaussian **0.01**、八位元量化。比較四種插值，按 Y 通道、裁 $s$ 邊框計 PSNR。

```python
import numpy as np, cv2
from scipy import ndimage as ndi
from skimage import data, img_as_float64

def degrade(hr, s=4, blur=1.2, noise=0.01, rng=None):
    """hr: (H, W, 3) in [0, 1], H and W divisible by s. Returns the LR image y."""
    rng = rng or np.random.default_rng(0)
    x = ndi.gaussian_filter(hr, sigma=(blur, blur, 0))          # 1) lens blur
    H, W, C = x.shape
    x = x.reshape(H // s, s, W // s, s, C).mean(axis=(1, 3))      # 2) s x s pixel integration + decimation
    x = x + noise * rng.standard_normal(x.shape)                  # 3) sensor noise
    return np.round(np.clip(x, 0, 1) * 255) / 255                 # 4) 8-bit quantization

def y_channel(rgb):
    """BT.601 luma on the [16, 235] scale (the MATLAB rgb2ycbcr convention)."""
    return 16 + rgb @ np.array([65.481, 128.553, 24.966])

def psnr(a, b, shave, peak):
    if shave:
        a, b = a[shave:-shave, shave:-shave], b[shave:-shave, shave:-shave]
    return 10 * np.log10(peak**2 / np.mean((a - b) ** 2))

hr = img_as_float64(data.astronaut())                             # (512, 512, 3)
lr = degrade(hr)                                                  # (128, 128, 3)
print("LR shape:", lr.shape)
for name, flag in [("nearest", cv2.INTER_NEAREST), ("bilinear", cv2.INTER_LINEAR),
                   ("bicubic", cv2.INTER_CUBIC), ("lanczos", cv2.INTER_LANCZOS4)]:
    sr = cv2.resize(lr, (512, 512), interpolation=flag)
    sr = np.clip(sr, 0, 1)
    y_hr, y_sr = y_channel(hr), y_channel(sr)
    print(f"{name:8s}  Y, shave 4: {psnr(y_hr, y_sr, 4, 255):.2f} dB | "
          f"Y, no shave: {psnr(y_hr, y_sr, 0, 255):.2f} dB | RGB, shave 4: {psnr(hr, sr, 4, 1):.2f} dB")
```

```text
LR shape: (128, 128, 3)
nearest   Y, shave 4: 24.62 dB | Y, no shave: 24.66 dB | RGB, shave 4: 23.06 dB
bilinear  Y, shave 4: 25.35 dB | Y, no shave: 25.40 dB | RGB, shave 4: 23.83 dB
bicubic   Y, shave 4: 26.36 dB | Y, no shave: 26.40 dB | RGB, shave 4: 24.81 dB
lanczos   Y, shave 4: 26.50 dB | Y, no shave: 26.54 dB | RGB, shave 4: 24.94 dB
```

此例各規則的排名相同，Y 與 RGB 卻差約 **1.5 dB**，因此只比相同計算規則。

## 傳統基準方法

插值以固定濾波器分配既有樣本；學得線性濾波可補部分細節，但仍難描述自然影像的多樣性。

### 插值：固定線性濾波

內插把 LR 取樣放到 HR 網格上，再用鄰近取樣的加權和填補空隙。在一維中，

$$
\hat x(t) = \sum_{u} y[u]\; \phi\!\left(\frac{t + \tfrac12}{s} - \tfrac12 - u\right),
$$

$t$ 是 HR 索引，$u$ 是 LR 索引，$\phi$ 為插值核，半像素項對齊 OpenCV 的像素中心慣例；二維沿列與行分離套用。[IP 02](/zh-tw/learn/image-processing/fundamentals/#影像內插) 有常見核推導。

- **最近鄰／線性：** 寬 1 方盒與寬 2 三角，分別偏塊狀和柔軟。
- **三次卷積：** Keys [5] 的寬 4 分段三次式，$a=-\tfrac12$ 有該家族的最佳近似階；小負瓣略銳化。OpenCV `INTER_CUBIC` 用 $a=-0.75$。
- **Lanczos：** $\phi(t)=\operatorname{sinc}(t)\operatorname{sinc}(t/a)$，$|t|<a$，其餘零；$\operatorname{sinc}(t)=\sin(\pi t)/(\pi t)$，$a$ 為單側葉數 [6]。`INTER_LANCZOS4` 用 4。

較寬的核更接近理想 sinc，Lanczos 此例 **26.50 dB** 略高於 bicubic **26.36**。但固定插值對邊緣和平坦區使用同一線性規則，不能從 LR 唯一確定缺失真實頻率；有限核也會產生頻譜複本和振鈴，有高頻不代表恢復原細節。

### 從配對區塊學線性濾波

**白話說。** 用曾見過的清晰／模糊區塊學對應，再預先算好每種區塊的修正式，就能快速套用。

範例法從外部資料 [7] 或單圖跨尺度重複 [8] 找配對，稀疏編碼用雙字典 [9]；ANR／A+ 預算 ridge 迴歸 [10]、[11]，RAISR 依梯度方向、強度及一致性分桶 [12]。共同形式為：

$$
\hat r = W_{c(p)}^{\top} \tilde p,
\qquad
W_c = \arg\min_{W} \sum_{i \in c} \bigl\| W^{\top} \tilde p_i - r_i \bigr\|_2^2 + \lambda \|W\|_F^2
= (P_c^{\top} P_c + \lambda I)^{-1} P_c^{\top} R_c,
$$

其中 $p$ 是 LR 區塊，$\tilde p$ 是它的特徵向量，$c(p)$ 是它所屬的類別（原子或雜湊桶），$r$ 是要預測的 HR 細節，$(\tilde p_i, r_i)$ 是類別 $c$ 的訓練配對，分別堆疊成 $P_c$ 與 $R_c$ 的列，$\lambda$ 是嶺迴歸的權重，$\|\cdot\|_F$ 是 Frobenius 範數。

*選讀：[以範例為基礎的 SR 與稀疏編碼細節](#以範例為基礎的-sr-與稀疏編碼細節)（見「補充資料」頁）。列出稀疏編碼的目標函數，以及 ZSSR 背後的內部學習想法。*

此例灰階每個 LR 點取 7 × 7 鄰域、去平均加偏置，預測 4 × 4 HR **殘差**。每點輸出 $s^2$ 再重排為區塊，即單層線性子像素卷積。用另 **11** 張 `skimage` 圖，分別以只有平均的銳利 LR、及先模糊 **1.2** 再平均的 LR 訓練，測太空人。

```python
import numpy as np, cv2
from numpy.lib.stride_tricks import sliding_window_view
from scipy import ndimage as ndi
from skimage import data, img_as_float64
from skimage.color import rgb2gray

s, p = 4, 7                                     # scale factor, LR patch size

def degrade(x, blur):                           # blur (optional) -> s x s average
    x = ndi.gaussian_filter(x, blur) if blur else x
    H, W = x.shape[0] // s * s, x.shape[1] // s * s
    return x[:H, :W].reshape(H // s, s, W // s, s).mean(axis=(1, 3))

def bicubic(lr):
    return cv2.resize(lr, None, fx=s, fy=s, interpolation=cv2.INTER_CUBIC)

def features(lr):                               # one p x p patch per LR pixel, mean removed, plus a bias
    f = sliding_window_view(np.pad(lr, p // 2, mode="reflect"), (p, p)).reshape(lr.size, p * p)
    return np.c_[f - f.mean(axis=1, keepdims=True), np.ones(lr.size)]

def to_blocks(r):                               # HR residual -> one s*s vector per LR pixel (space-to-depth)
    h, w = r.shape[0] // s, r.shape[1] // s
    return r.reshape(h, s, w, s).transpose(0, 2, 1, 3).reshape(h * w, s * s)

def from_blocks(b, h, w):                       # inverse: depth-to-space (pixel shuffle)
    return b.reshape(h, w, s, s).transpose(0, 2, 1, 3).reshape(h * s, w * s)

def train(images, blur, lam=1e-3):
    A, B = [], []
    for im in images:
        im = im[: im.shape[0] // s * s, : im.shape[1] // s * s]
        lr = degrade(im, blur)
        A.append(features(lr)); B.append(to_blocks(im - bicubic(lr)))
    A, B = np.concatenate(A), np.concatenate(B)
    return np.linalg.solve(A.T @ A + lam * np.eye(A.shape[1]), A.T @ B)   # ridge: (p*p+1, s*s)

def super_resolve(lr, Wt):
    return bicubic(lr) + from_blocks(features(lr) @ Wt, *lr.shape)

def psnr(a, b):
    a, b = a[s:-s, s:-s], b[s:-s, s:-s]          # shave s border pixels
    return 10 * np.log10(1.0 / np.mean((a - np.clip(b, 0, 1)) ** 2))

train_imgs = [img_as_float64(im) for im in (data.camera(), data.moon(), data.coins(), data.page(),
              data.text(), data.brick(), data.grass(), data.gravel(),
              rgb2gray(data.coffee()), rgb2gray(data.chelsea()), rgb2gray(data.rocket()))]
models = {"trained sharp": train(train_imgs, 0.0), "trained blurry": train(train_imgs, 1.2)}
test = img_as_float64(rgb2gray(data.astronaut()))           # never seen in training
print("weights per model:", models["trained sharp"].shape)
for name, blur in [("sharp", 0.0), ("blurry", 1.2)]:
    lr = degrade(test, blur)
    row = "  ".join(f"{m} {psnr(test, super_resolve(lr, W)):.2f}" for m, W in models.items())
    print(f"test {name:6s} | bicubic {psnr(test, bicubic(lr)):.2f} | {row}  (dB)")
```

```text
weights per model: (50, 16)
test sharp  | bicubic 25.61 | trained sharp 26.05  trained blurry 25.43  (dB)
test blurry | bicubic 24.98 | trained sharp 25.66  trained blurry 26.26  (dB)
```

每模型只有 $50\times16=800$ 權重，約一秒封閉求解。退化相符時比 bicubic 增 **0.44／1.28 dB**。模糊訓練模型遇銳利輸入會過銳化，**25.43** 低於 bicubic **25.61**；銳利訓練遇模糊修不足，**25.66** 低於匹配模型 **26.26**。正確退化假設很重要，Efrat 等人 [13] 也有相關經典結果。圖 6 的 16 濾波對應 16 子像素偏移。

## 深度 SR：六個設計決策

深網路是前面線性迴歸的非線性擴充。從三層 CNN 到 Transformer，可沿六個解決具體問題、也帶來成本的決策理解。

表 1 是本節地圖，下文按同一順序解釋。

| 決策 | 代表模型 | 解決問題 | 代價 |
| --- | --- | --- | --- |
| 1. Bicubic 後端到端學習 | SRCNN [14] | 手工區塊管線 | 每層在 HR 工作 |
| 1. 改在末端放大 | FSRCNN [15]、ESPCN [16] | HR 的 $s^2$ 成本 | 每倍率放大尾端 |
| 2. 子像素卷積 | ESPCN [16] | 學得放大器成本 | 初始化棋盤紋 |
| 3. 深網路及殘差 | VDSR [17] | 深層訓練慢／不穩 | 計算與啟動記憶體 |
| 4. 去 BN、殘差縮放 | EDSR [18] | 記憶體及動態範圍 | 寬模型須穩定化 |
| 5. 通道注意力、殘差中殘差 | RCAN [19] | 通道等權、400 多層訓練 | 深度帶來延遲 |
| 6. 遠距內容注意力 | SwinIR [20]、HAT [21] | 固定局部卷積 | 注意力時間／記憶體 |

這些像素損失模型仍是中心估計：MSE 為條件平均，L1 為逐座標中位數，不代表完整分布。架構可改善預測，下一節則改變統計目標。

### 決策一：在哪裡放大

**白話說。** 每軸放大 $s$ 倍後有 $s^2$ 倍像素。先放大使後續每層都在大圖工作，後放大則讓主體留在小圖。

SRCNN [14] 先 bicubic，再三卷積做區塊抽取、非線性映射與重建。前放大簡單，也可共用多倍率，如 VDSR [17]；但 $k\times k$、$C_{\mathrm{in}}\to C_{\mathrm{out}}$、$h\times w$ 卷積需要：

$$
\text{MAC} = h \, w \, C_{\text{in}} \, C_{\text{out}} \, k^2
$$

次乘加。成本正比 $hw$，相同層在 HR 精確多 $s^2$ 倍。

```python
def conv_macs(h, w, c_in, c_out, k=3):
    """Multiply-accumulates of one k x k convolution on an h x w feature map."""
    return h * w * c_in * c_out * k * k

s, H, W, C = 4, 128, 128, 64                    # x4 SR of a 128 x 128 input, 64 feature channels
body_pre = conv_macs(s * H, s * W, C, C)        # one body layer at HR size (pre-upsampling)
body_post = conv_macs(H, W, C, C)               # the same layer at LR size (post-upsampling)
tail = conv_macs(H, W, C, 3 * s * s)            # sub-pixel tail: 64 -> 3*s*s channels, then pixel shuffle
print(f"one body layer, pre-upsampling : {body_pre / 1e9:.2f} GMAC")
print(f"one body layer, post-upsampling: {body_post / 1e9:.2f} GMAC (ratio {body_pre / body_post:.0f})")
print(f"sub-pixel tail, 64 -> 48 channels at LR size: {tail / 1e9:.2f} GMAC")
```

```text
one body layer, pre-upsampling : 9.66 GMAC
one body layer, post-upsampling: 0.60 GMAC (ratio 16)
sub-pixel tail, 64 -> 48 channels at LR size: 0.45 GMAC
```

128 × 128 LR、×4 的 64 通道層，HR 約 **9.66 GMAC**、LR **0.60**。FSRCNN [15] 用末端轉置卷積及薄映射，在 C++ Intel i7 比較中比 SRCNN-Ex 快逾 **40 倍**。代價是尾端依倍率；MDSR [18] 共享主體、×2／×3／×4 各尾端。後續多採末端放大。

### 決策二：轉置或子像素卷積

**白話說。** 每 LR 點需產生 $s^2$ 個輸出。轉置卷積把每點以學得印章分散出去；子像素卷積在 LR 算成 $s^2$ 通道，再重排為區塊。

stride $s$ 的轉置卷積等價於樣本間插 $s-1$ 零再卷積。不同輸出偏移只使用不同核係數，總共 $s^2$ 模式，因此可寫成 LR 的多個卷積再交錯輸出 [16]。ESPCN 末層直接輸出 $Cs^2$，無參數 pixel shuffle 變成 $C$ 通道大圖；EDSR／RCAN／SwinIR／HAT 也使用 [18]、[19]、[20]、[21]。

精確的版本是一條索引規則。設 $T$ 是形狀為 $(C s^2, H, W)$ 的 LR 特徵張量，$X = \mathrm{PS}(T)$ 是形狀為 $(C, sH, sW)$ 的輸出，則

$$
X\bigl[c,\; s h + i,\; s w + j\bigr] = T\bigl[c\, s^2 + s\, i + j,\; h,\; w\bigr],
\qquad 0 \le c \lt C,\;\; 0 \le h \lt H,\;\; 0 \le w \lt W,\;\; 0 \le i, j \lt s,
$$

$c$ 是輸出通道，$(h,w)$ 是 LR 位置，$(i,j)$ 是區塊內子像素偏移；依行優先將 $s^2$ 通道散到區塊。這符合 PyTorch `PixelShuffle` [22] 將通道拆成 $(C,s,s)$ 再排列的慣例。反向 pixel unshuffle 把區塊收回通道，高效率模型可用它先降低空間大小。

<Figure src={shuffleFig} alt="左：四張彩色的 3 × 3 LR 特徵圖，標示為通道 0 到 3，子像素偏移分別為 (0,0)、(0,1)、(1,0)、(1,1)；每張左上角的格子有外框。右：一張 6 × 6 的 HR 網格，每個 2 × 2 區塊依閱讀順序包含通道 0、1、2、3 的顏色；左上角的區塊有外框。文字：輸出像素 (s·h + i, s·w + j) 來自 LR 位置 (h, w) 的通道 s·i + j。" caption="圖 8 — s = 2、C = 1 時的 pixel shuffle。同一個 LR 位置上的四個值（每個通道一個）變成一個 2 × 2 的輸出區塊。" />

NumPy 用 reshape／transpose／reshape 實作兩方向，逐元素檢查索引式及精確互逆。

```python
import numpy as np

def pixel_shuffle(t, s):
    """Depth-to-space: (C*s*s, H, W) -> (C, H*s, W*s)."""
    Cs2, H, W = t.shape
    C = Cs2 // (s * s)
    return t.reshape(C, s, s, H, W).transpose(0, 3, 1, 4, 2).reshape(C, H * s, W * s)

def pixel_unshuffle(x, s):
    """Space-to-depth: (C, H*s, W*s) -> (C*s*s, H, W)."""
    C, Hs, Ws = x.shape
    H, W = Hs // s, Ws // s
    return x.reshape(C, H, s, W, s).transpose(0, 2, 4, 1, 3).reshape(C * s * s, H, W)

rng = np.random.default_rng(0)
s, C, H, W = 3, 2, 4, 5
t = rng.standard_normal((C * s * s, H, W))
x = pixel_shuffle(t, s)
print(x.shape)                                                   # (2, 12, 15)

# The index rule: output (c, s*h + i, s*w + j) comes from channel c*s*s + s*i + j at (h, w).
ok = all(x[c, s*h + i, s*w + j] == t[c*s*s + s*i + j, h, w]
         for c in range(C) for h in range(H) for w in range(W)
         for i in range(s) for j in range(s))
print("index rule holds:", ok)
print("unshuffle(shuffle(t)) == t:", np.array_equal(pixel_unshuffle(x, s), t))
print("shuffle(unshuffle(x)) == x:", np.array_equal(pixel_shuffle(pixel_unshuffle(x, s), s), x))
```

```text
(2, 12, 15)
index rule holds: True
unshuffle(shuffle(t)) == t: True
shuffle(unshuffle(x)) == x: True
```

核尺寸為 $s$ 倍數時，可對應兩種放大表示。Pixel shuffle 是排列、精確可逆、梯度為反排列，但各偏移獨立濾波，隨機初始化可能讓平坦輸入變棋盤紋。ICNR [23] 將偏移濾波初始化為副本，起始等價卷積後最近鄰放大。[DLCV 01B](/zh-tw/learn/deep-learning/building-blocks/#上取樣轉置卷積pixel-shuffle-與-resize-convolution) 有程式分析；線性例子的 16 個核就是此偏移。

### 決策三：深度與殘差預測

**白話說。** 深層能看更多鄰域，但難訓練。只預測廉價放大結果缺少的修正，使目標較小且多處接近零。

VDSR [17] 以 **20** 層 3 × 3 卷積和兩項設計使深層可訓練。先用全域殘差，讓 $f_\theta$ 只補插值修正：

$$
\hat x = U(y) + f_\theta(U(y)), \qquad \mathcal L(\theta) = \tfrac12 \bigl\| x - U(y) - f_\theta(U(y)) \bigr\|_2^2,
$$

$U$ 為 bicubic，$f_\theta$ 接收 HR 大小輸入，$\hat x$ 是輸出，$\mathcal L$ 為配對損失；再用高學習率搭配**可調梯度裁切** [17]。

*選讀：[可調梯度裁切](#可調梯度裁切)（見「補充資料」）。VDSR 裁切規則與學習率的關係。*

插值已含低頻，目標 $x-U(y)$ 較小、以零為中心；以下在貫穿範例測量。

```python
import numpy as np, cv2
from scipy import ndimage as ndi
from skimage import data, img_as_float64
from skimage.color import rgb2gray

s = 4
hr = img_as_float64(rgb2gray(data.astronaut()))                        # (512, 512), values in [0, 1]
lr = ndi.gaussian_filter(hr, 1.2).reshape(128, s, 128, s).mean(axis=(1, 3))   # the running example
up = cv2.resize(lr, None, fx=s, fy=s, interpolation=cv2.INTER_CUBIC)   # bicubic upsampling
r = hr - up                                                            # what a residual network predicts
print(f"HR image: mean {hr.mean():.3f}  std {hr.std():.3f}")
print(f"residual: mean {r.mean():+.3f}  std {r.std():.3f}  |r| < 0.05 at {np.mean(np.abs(r) < 0.05):.0%} of pixels")
```

```text
residual: mean -0.000  std 0.056  |r| < 0.05 at 82% of pixels
```

殘差標準差約為影像五分之一，**82%** 像素絕對值低於 **0.05**。零輸出已接近 bicubic，可集中容量處理邊紋。末端放大模型保留局部殘差及長跳接，見 [DLCV 01B](/zh-tw/learn/deep-learning/building-blocks/#resnet-對-edsr-與-nafnet)。加法便宜，不代表增加主體深度免費。

### 決策四：移除批次正規化

**白話說。** BN 重新縮放特徵，分類常有用，但 SR 要保留精確強度與範圍。EDSR 移除它，將記憶體用於更寬網路。

訓練 BN 用批次統計，測試用移動統計。SRResNet [24] 保留 BN，EDSR [18] 為範圍彈性與記憶體移除，訓練相較約省 **40%**。完整模型 **32** 殘差塊、**256** 通道，以 **0.1** 殘差縮放穩定；改 L1，×3／×4 由 ×2 初始化，贏 NTIRE 2017 [25]。ESRGAN [26] 又指出統計不符時 BN 可生偽影。

去 BN 仍須小心初始化及縮放。啟動範圍也可能更大，使量化困難，見 [DLCV 01C](/zh-tw/learn/deep-learning/model-compression/#密集預測與影像復原)；一般正規化選擇見 [DLCV 01B](/zh-tw/learn/deep-learning/building-blocks/#正規化bnlngn以及何時不用)。

### 決策五：通道重新加權（RCAN）

**白話說。** 不同通道承載低頻或細節，通道注意力依影像調高低，而非一律等權。

RCAN [19] 對各通道取平均，經瓶頸產生縮放。對 $C$ 個 $H\times W$ 通道 $x_1,\dots,x_C$：

$$
z_c = \frac{1}{HW} \sum_{i=1}^{H} \sum_{j=1}^{W} x_c(i, j), \qquad
\mathbf s = f\bigl(W_U \, \delta(W_D \, \mathbf z)\bigr), \qquad
\hat x_c = s_c \, x_c,
$$

$x_c(i,j)$ 是值，$\mathbf z$ 為通道平均，$W_D$ 將 $C$ 降為 $C/r$，$\delta$ 是 ReLU，$W_U$ 還原，$f$ 是 sigmoid，$s_c\in(0,1)$ 縮放通道。$C=64,r=16$，瓶頸僅 **4** 通道。一般 SE 背景見 [DLCV 01B](/zh-tw/learn/deep-learning/building-blocks/#cnn-內的注意力se-與-cbam)。

**殘差中殘差**含 **10** 組、每組 **20** 通道注意力塊、短及長跳接，超過 **400** 層 [19]。低頻可走跳接，主體偏細節，但深度仍增加序列執行延遲。

### 決策六：遠距內容注意力（SwinIR、HAT）

**白話說。** 卷積用固定權重，注意力依內容產生權重，可借相似結構資訊。整圖昂貴，因此使用交替位移小視窗。

每個 $M\times M$ LR token 視窗，注意力為：

$$
\operatorname{Attention}(Q, K, V) = \operatorname{SoftMax}\!\bigl(Q K^{\top} / \sqrt d + B\bigr) V,
$$

$Q,K,V$ 為線性投影、各 $M^2$ 列，$d$ 是 query／key 維度，$B$ 為相對位置偏置 [21]。每輸出按 query—key 相似度平均 values，見 [ML 05](/zh-tw/learn/ml/vision-transformers/#swin-與階層式-transformer)。$h\times w$ token、$C$ 通道成本：

$$
\Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2 C, \qquad \Omega(\text{W-MSA}) = 4hwC^2 + 2M^2 hwC,
$$

MSA 是全域，W-MSA 是視窗，首項投影、次項注意力 [27]。固定視窗時對像素線性，整圖則平方。$C=180,M=8$、128 × 128 LR，每層約 **98.8 GMAC** 全域、**2.50 GMAC** 視窗，是本章算術例。

SwinIR [20] 淺層 3 × 3、殘差 Swin 主體及 pixel shuffle；標準設定 **6** 塊、各 **6** 層、視窗 **8**、寬 **180**、L1。HAT [21] 依 LAM 歸因發現利用範圍有限，加入平行通道注意力、視窗 **16**、重疊交叉注意力，及同 SR 任務的 ImageNet 預訓練，再微調 DIV2K／Flickr2K。DAT [28] 交替空間／通道，MambaIR [29] 用狀態掃描擴大上下文。

視窗、容量及大圖分塊增加時間與記憶體，也可能留接縫。L1 架構的改善來自更有效上下文，不是隨機抽樣。

**共同配方。** DIV2K 或加 Flickr2K 小裁切，翻轉、90° 旋轉、L1、Adam；EDSR 用 48 × 48 LR。「+」如 EDSR+ 為八種幾何變換輸出還原平均 [18]，並非免費。一般損失見 [DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#損失函數)。

## 感知式與對抗式 SR

改變損失可獎勵自然細節，代價可能是較低 PSNR 與虛構，而非只改網路架構。

### 感知損失與 GAN

Johnson 等人 [31] 用 VGG [30] 感知距離得到較清晰但較低 PSNR；SRGAN [24] 加判別器與 **16** 殘差塊 SRResNet，提升人類偏好。ESRGAN [26] 用無 BN 的 RRDB、相對判別器和啟動前 VGG 特徵，其變體贏 PIRM 2018 區域 3 [32]。常見生成損失為：

$$
\mathcal L = \lambda_1 \,\| \hat x - x \|_1 + \lambda_p \,\bigl\| \phi(\hat x) - \phi(x) \bigr\|_2^2 + \lambda_a \,\mathcal L_{\text{adv}}(\hat x),
$$

$\hat x$ 為輸出，$x$ 為目標，$\phi$ 為固定特徵層，$\mathcal L_{\mathrm{adv}}$ 為對抗項，$\lambda_1,\lambda_p,\lambda_a\ge0$ 為權重；GAN 見 [ML 07](/zh-tw/learn/ml/generative-models/#gan與對手一起學習)。

ESRGAN [26] 的**網路內插**以 $\theta=(1-\alpha)\theta_{\mathrm{PSNR}}+\alpha\theta_{\mathrm{GAN}}$、$0\le\alpha\le1$ 混合像素模型及 GAN 微調權重，不重訓探索平滑／紋理取捨。

*選讀：[ESRGAN 設計詳解](#esrgan-設計詳解)（見「補充資料」）。相對判別器、啟動前感知特徵與區塊結構。*

### 感知–失真權衡

Blau 與 Michaeli [2] 以輸出和真值的期望差異定義**失真**，以輸出分布與真實分布的距離定義**感知品質**，研究最佳邊界。允許失真越小，最佳可達分布品質不會更好；歧義後驗的平均可能不自然，但無雜訊可逆問題未必有衝突。詳見 [DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#感知失真權衡)。本章從平均移向後驗樣本，MSE **0.0072→0.0143**，自然度差距縮小。非線性權重內插不等於輸出內插，也不保證位於理論最優邊界。

- 方法應該說明它瞄準權衡上的*哪個位置*。只用 PSNR，或只用一個感知指標，去比較 GAN 與 MSE 網路，無法說明哪一個比較好。
- 基準必須同時量測兩個軸。PIRM 2018 挑戰賽就是這樣做的：它依 RMSE 把感知–失真平面分成三個區域（RMSE 上限分別為 11.5、12.5 與 16），在每個區域內以一個感知指數為方法排名，這個指數由兩個無參考指標組成：NIQE [33] 與 Ma 等人的 SR 專用指標 [34], [32]。

## 已知退化的擴散 SR

條件擴散近似條件影像分布，可產生多個合理候選，代價是迭代推論。訓練好的取樣器不自動證明精確貝氏後驗或量測一致性。

SR3 [35] 以 bicubic LR 做非盲條件，U-Net [36] 輸入為吵 HR 與 bicubic 放大 LR 的通道串接，學多種雜訊程度去除。推論從純高斯開始，原文最多 **100** 步。

×8 人臉 16→128 的研究，受試者把 SR3 當真照片接近 **50%**，GAN 基準至多 **34%**。×4 ImageNet 同骨幹回歸 PSNR／SSIM 較高，SR3 樣本品質較好；它也檢查縮回 LR 的一致性 [35]。訓練程序見 [DLCV 09B](/zh-tw/learn/deep-learning/generative-restoration/#路線-a訓練條件式擴散復原模型)，擴散機制見 [ML 08](/zh-tw/learn/ml/diffusion-flow-matching/#潛在擴散)。

生成細節未對齊會降 PSNR，即使人類偏好，但不是所有模型必然較低。內容仍可能錯且多次評估昂貴；大型先驗、少步／一步真實照片方法見 [DLCV 09A.1](/zh-tw/learn/deep-learning/blind-real-world-super-resolution/)。

## 退化未知：盲與真實世界 SR

**白話說。** 真圖帶未知模糊、雜訊及壓縮，固定 bicubic 模型會像前面錯配線性例子般誤判。方法可廣泛合成、先估退化或實拍配對，也須在無真值下評估；完整內容見 [DLCV 09A.1：盲與真實世界超解析度](/zh-tw/learn/deep-learning/blind-real-world-super-resolution/)。

## 任意倍率 SR

**白話說。** 固定 ×4 模型只能產生特定大小；任意倍率模型把影像視為連續函數，能查詢 ×2.7 等非整數輸出。

Meta-SR [37] 依倍率及輸出相對位置預測放大濾波權重；LIIF [38] 學**局部隱式影像函數**：

$$
\hat I(x_q) = f_\theta\bigl(z^{*},\; x_q - v^{*}\bigr),
$$

$x_q$ 是連續查詢座標，$z^*$ 是 LR 編碼器在最近網格 $v^*$ 的特徵，$f_\theta$ 是輸出 RGB 的小 MLP。原文以 ×1–×4 訓練，展示至 **×30**。代價是每輸出像素一次 MLP；極端倍率依賴學得假設，不會增加量測資訊。

*選讀：[LIIF 的三項改良](#liif-的三項改良)（見「補充資料」頁）。說明特徵展開、局部集成與像素格解碼。*

## 效率

**白話版。** 許多 SR 用途（手機、視訊通話、遊戲算繪）需要在小晶片上以毫秒級的時間給出結果。高效率 SR 問的是：在維持品質門檻的前提下，網路可以做到多小、多快。

末端 pixel shuffle 先省空間成本，其他如 IMDN [39] 分出保留特徵、繼續處理部分，再以對比感知通道注意力融合。參數、FLOPs、時間不同；NTIRE 高效率 2024／2025 ×4 [40]、[41] 要求驗證 **26.90 dB**、測試 **26.99 dB** 以上再降低成本。壓縮見 [DLCV 01C](/zh-tw/learn/deep-learning/model-compression/#密集預測與影像復原)。

## 評估 SR

保真依固定 PSNR／SSIM 規則，外觀另加感知及人類評估，不能只用一個數字混排。一般指標見 [DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#評估指標)，此處聚焦 SR 特有細節。

### 在 Y 通道上計算並裁去邊界的 PSNR 與 SSIM

經典 MATLAB 社群規則通常是：

1. 把 HR 影像與 SR 輸出都轉成 YCbCr，只保留亮度（luma）通道
$$
Y = 16 + 65.481\, R + 128.553\, G + 24.966\, B,
$$
$R,G,B\in[0,1]$ 為 gamma 編碼，$Y\in[16,235]$；係數依 MATLAB／scikit-image `rgb2ycbcr` 的 BT.601 [42]、[43]。
2. 兩張圖裁掉邊框，避免 padding 邊界主導。
3. 剩餘 Y 以峰值 **255** 算 PSNR 及 SSIM [44]，定義見 [DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#全參考指標)。

同篇也可能不同：EDSR [18] 基準 Y 裁 $s$，消融 DIV2K 則 RGB 裁 $6+s$；NTIRE ×4 裁 **4** [45]、[46]。通道／色域曾在報告例子差達 **4 dB** [4]。若 $Y=16+219\ell$，以 Y／峰 255 比 $\ell$／峰 1 多 $20\log_{10}(255/219)\approx1.32$ dB。量化、裁切和縮放也有影響，公平比較應用同一評估腳本。

### 標準測試集

SR 論文在一小組公開測試集上回報結果，每個測試集各有特色 [4]：

| 測試集 | 影像數 | 內容 | 出處 |
| --- | --- | --- | --- |
| Set5 | 5 | 嬰兒、鳥、蝴蝶、頭像、女性 | [47] |
| Set14 | 14 | 人物、動物、花、漫畫、投影片 | [48] |
| BSD100 (B100) | 100 | 自然場景，即 Berkeley 分割資料集的測試影像 | [49] |
| Urban100 | 100 | 具有規則結構的建築與城市景觀 | [50] |
| Manga109 | 109 | 日本漫畫單行本（線稿與網點） | [51], [52] |
| DIV2K validation | 100 | 多樣的 2K 解析度照片 | [53] |

Set5、Set14 很小，百分之幾 dB 意義有限；Urban100 重複結構多，大視窗 HAT 在此尤其受益 [21]。

### 為什麼 PSNR 與感知排名不一致

三種原因造成分歧：MSE 最優中心可能模糊；紋理統計對卻位移，像素誤差仍大；感知／無參考模型如 LPIPS [54]、NIQE [33] 評外觀，也可能被過銳化影響。NTIRE 2025 [46] 分 PSNR 復原及六指標合成感知賽道。[DLCV 09](/zh-tw/learn/deep-learning/image-restoration/#使用者研究與成對比較) 建議同報保真、感知，生成模型另做人類研究。

## 資料集與基準

**白話說。** 幾個資料集與年度競賽形塑了非盲 SR 的常見基準。

- **DIV2K** [53] 有 **1,000** 張 2K 圖，訓練／驗證／測試 **800／100／100** [46]；Flickr2K 有 **2,650**，合稱 DF2K。HAT [21] 先 ImageNet 同任務預訓練，再微調。
- **NTIRE 2017** [25] 各有 bicubic、可由配對學習的未知退化，×2／×3／×4。
- **NTIRE 2024／2025** [45]、[46] 用 DIV2K ×4 bicubic，2025 加感知賽道。
- **高效率 SR** [40]、[41] 在固定品質門檻下比較時間、參數與 FLOPs。

真實資料與挑戰不只有乾淨 bicubic，見 [DLCV 09A.1](/zh-tw/learn/deep-learning/blind-real-world-super-resolution/)。

## 失效模式

**白話版。** SR 模型失敗的方式，可能是太謹慎（模糊），也可能是太大膽（捏造細節）。大膽的失敗比較危險，因為結果看起來很有說服力。

- **過度平滑：** 中心估計可能抑制歧義細節，MSE／L1 分別學平均／中位數，不保證每張都模糊，也不表示所有候選。
- **假文字／人臉：** 清楚卻錯字或身分；Ren 等人 [55] 指出既有指標不足，提議多模態虛構評估。
- **紋理偽影：** GAN 重複噪狀細節、錯核暈邊 [26]。
- **偏色：** 擴散仍有全域色彩漂移 [56]。
- **退化錯配：** 修不足／過度，補救見 [DLCV 09A.1](/zh-tw/learn/deep-learning/blind-real-world-super-resolution/)。
- **接縫：** 大圖非重疊分塊可留下邊界 [20]。

對任何 SR 輸出都很有用的一個合理性檢查，是**與輸入的一致性**：用假設的模型把輸出退化，再與 $y$ 比較。差異很大，代表模型改動了 LR 影像確實量測到的內容。

## 現代觀點

### 綜述論文

Wang、Chen、Hoi [4] 分監督、無監督、領域專用，再以放大位置、算子、殘差／遞迴／密集／注意力、損失與訓練策略等獨立軸描述，提醒新模型通常只改其中幾項。它早於 Transformer／擴散。Moser 等人 [56] 則按像素／潛在／小波、條件、引導、損傷空間及零樣本整理擴散 SR，指出成本、比較、可解釋性與偏色。盲及真實綜述見 [DLCV 09A.1](/zh-tw/learn/deep-learning/blind-real-world-super-resolution/)。

### 2023–2026 年的最新進展

1. **保真架構：** HAT、DAT、MambaIR [21]、[28]、[29] 搭配預訓練，在 NTIRE 復原賽道評估 [45]、[46]。
2. **評估跟上生成：** 感知專用賽道及虛構評估 [46]、[55]，不再只依 PSNR。
3. **效率獨立比較：** 在品質門檻下測成本 [40]、[41]。

### 尚未解決的問題

- **可信生成：** 如何提供自然細節，同時辨識哪些已量測、哪些只是推估。
- **評估：** 中心估計、感知分數迎合與新虛構指標的限制。
- **小基準飽和：** 微小 dB 增益不代表真實相機用途。
- **成本：** 大注意力／擴散與高效率網路差異很大。
- **極端倍率：** 訓練範圍外、幾乎全靠先驗時的行為仍不明確。

## 重點整理

- ×4 的每個 LR 量測只限制 16 個 HR 值的一種組合，其他依先驗。MSE 學平均、L1 學逐座標中位數；理想條件下獨立精確後驗樣本的期望 MSE 是最優平均估計的兩倍，任意生成器沒有此保證。
- 非盲已知退化，錯模糊會修不足或過度。
- 六項決策是末端放大、pixel shuffle、殘差、去 BN 與縮放、通道調制、視窗注意力。Shuffle 索引 $X[c,sh+i,sw+j]=T[cs^2+si+j,h,w]$。
- 像素模型依損失學平均或中位數；感知／GAN／擴散鼓勵自然輸出。感知—失真理論限制最優邊界，不禁止從次佳基準同時改善多項。
- 明示 Y、裁邊與評估規則，生成模型加感知及人類研究。
- 檢查文字、人臉、紋理、偏色、平滑及分塊，並比較縮回 LR 的一致性。

<details>
<summary>提示</summary>

令 $q = 2i + j$，解 $4c + q = 3q + c$：$3c = 2q$，所以只有 $(c, q) = (0, 0)$ 與 $(2, 3)$ 重合，12 個通道中只有 2 個（我們逐一列舉全部 12 個確認過）。其他值被移到錯誤的色彩通道與錯誤的子像素偏移，所以即使粗略的影像仍認得出來，每個 2 × 2 區塊都會出現細碎的彩色馬賽克。$C = 1$ 時兩種順序一致，這就是為什麼這類錯誤常常要到從灰階模型換成彩色模型時才出現。

### 以範例為基礎的 SR 與稀疏編碼細節

本節補充經典範例法與稀疏編碼如何壓縮範例庫。

Freeman 等人 [7] 找與 LR 相符且與鄰居相容的 HR 區塊；Glasner 等人 [8] 利用單圖跨尺度重複，Huang 等人 [50] 加透視／仿射搜尋以助城市場景。ZSSR [57] 則在測試時以輸入本身抽出的範例訓練小 CNN。

Yang 等人學習一本 LR 字典 $D_\ell$ 與一本 HR 字典 $D_h$，兩者的行是成對的原子 [9]。對一個 LR 區塊特徵 $p_\ell$，他們求解

$$
\min_{\alpha} \; \bigl\| D_\ell\, \alpha - p_\ell \bigr\|_2^2 + \lambda \|\alpha\|_1,
\qquad \hat p_h = D_h\, \alpha,
$$

$\alpha$ 為稀疏代碼，$\|\alpha\|_1$ 鼓勵少係數，$\lambda>0$ 控制稀疏，$\hat p_h$ 為 HR 區塊，重疊平均。Zeyde 等人 [48] 加速此流程，ANR／A+ [10]、[11] 預算 ridge 取代稀疏求解；主線即其簡化。SRCNN [14] 也可讀作學得的三階段版本。

### LR 頻譜的混疊

本節精確說明 HR 頻率如何折疊到 LR。

一維 HR 的離散時間傅立葉頻譜為 $X(f)$，$f$ 以每 HR 樣本週期計、週期一。每 $s$ 點取一後：

$$
Y(f') = \frac{1}{s} \sum_{m=0}^{s-1} X\!\left(\frac{f' + m}{s}\right), \qquad -\tfrac12 \le f' \lt \tfrac12,
$$

$f'$ 以每 LR 樣本週期計，$m$ 索引折到同位置的 $s$ 個 HR 頻率 $(f'+m)/s$。只有基頻帶 $|f|\le1/(2s)$ 應保留，其餘為混疊。前模糊以頻率響應 $H$ 乘 $X$，抑制帶外後，$Y(f')\approx H(f'/s)X(f'/s)/s$：低頻保留但受衰減，高頻不再可觀測。

圖 2 的斜向 **0.30** 週期，兩軸分量約 **0.21**；×4 後約 **0.85** 週期／LR，超出 $[-\tfrac12,\tfrac12)$，折為 **−0.15**，出現原場景沒有的粗條紋。先模糊幾乎消去此成分而成灰。只看 LR 不能判定粗紋原有還是混疊，必須依先驗。

### 可調梯度裁切

本節說明 VDSR [17] 如何用高學習率訓練 20 層網路。

一般裁切把梯度 $g$ 各項限制 $[-\theta,\theta]$，SGD 更新為 $\gamma g$。原文起始學習率比 SRCNN 高 $10^4$ 倍；固定小 $\theta$ 雖使初期安全，降學習率後又讓更新太小。因此改用：

$$
g_i \leftarrow \min\!\Bigl(\max\bigl(g_i, -\tfrac{\theta}{\gamma}\bigr), \tfrac{\theta}{\gamma}\Bigr),
$$

$g_i$ 為梯度項，$\gamma$ 為當前學習率，最大更新 $\gamma\theta/\gamma=\theta$，不隨學習率改變。此規則結合殘差訓練控制爆炸梯度，原文報 20 層在 **4 小時**內訓練 [17]。

### 為什麼後驗樣本的誤差是 MMSE 的兩倍

本節推導理想後驗樣本和後驗平均的期望 MSE 二倍關係。

**白話版。** 後驗平均正好位於所有合理答案的中心。真實影像是那團雲中的一個隨機點，後驗樣本則是同一團雲中另一個獨立的隨機點。兩個隨機點之間的平均（平方）距離，是一個隨機點到中心距離的兩倍。

**精確版。** 設 $X$ 為 HR 影像，$Y$ 為 LR 觀測，$\mu(Y) = \mathbb E[X \mid Y]$ 為後驗平均，$\hat X$ 是在給定 $Y$ 下與 $X$ 獨立、從 $p(x \mid Y)$ 抽出的樣本。那麼在以 $Y$ 為條件下，

$$
\begin{aligned}
\mathbb E\bigl[\|X - \hat X\|^2 \mid Y\bigr]
&= \mathbb E\bigl[\|(X - \mu) - (\hat X - \mu)\|^2 \mid Y\bigr] \\
&= \mathbb E\bigl[\|X - \mu\|^2 \mid Y\bigr] + \mathbb E\bigl[\|\hat X - \mu\|^2 \mid Y\bigr] - 2\,\mathbb E\bigl[(X - \mu)^{\top}(\hat X - \mu) \mid Y\bigr] \\
&= 2\,\mathbb E\bigl[\|X - \mu\|^2 \mid Y\bigr],
\end{aligned}
$$

$\|\cdot\|$ 為整張像素歐氏範數。$X,\hat X$ 給定 $Y$ 同分布且獨立，平均皆 $\mu$，因此兩平方項相等、交叉項為零。再對 $Y$ 取期望，得 $\mathbb E\|X-\hat X\|^2=2\mathbb E\|X-\mu(Y)\|^2$。以期望 MSE 算 PSNR 約差 **3 dB**；逐圖 PSNR 平均不是同一統計。精確樣本邊際等真實分布，符合此處理想感知定義，但不表示細節屬特定原場景。此建構支持完美分布品質存在不超過二倍最優 MSE 的解 [2]。

同樣的代數也給出圖 1 的曲線。對於混合 $X_\alpha = \mu + \alpha(\hat X - \mu)$，$0 \le \alpha \le 1$，

$$
\mathbb E\|X - X_\alpha\|^2 = (1 + \alpha^2)\, \mathbb E\|X - \mu\|^2,
$$

其中交叉項基於同樣的理由為零。失真從 $\alpha = 0$ 時的 MMSE 值平滑地增加到 $\alpha = 1$ 時的兩倍，而混合的輸出則從模糊的後驗平均移向真實的樣本。在我們的小例子中，量到的 MSE 從 0.0072 增加到 0.0143。

```python
import numpy as np

rng = np.random.default_rng(1)
mu = rng.standard_normal((100000, 1))                  # posterior means for many observations y
X = mu + rng.standard_normal(mu.shape)                 # the truth: one draw from p(x | y) = N(mu, 1)
X_hat = mu + rng.standard_normal(mu.shape)             # an independent posterior sample
for a in (0.0, 0.5, 1.0):
    print(f"alpha {a:.1f}: MSE {np.mean((X - (mu + a * (X_hat - mu))) ** 2):.3f}  (theory {1 + a * a:.3f})")
```

```text
alpha 0.0: MSE 1.002  (theory 1.000)
alpha 0.5: MSE 1.250  (theory 1.250)
alpha 1.0: MSE 1.996  (theory 2.000)
```

### ESRGAN 設計詳解

本節說明 ESRGAN 對 SRGAN 的四項改動 [26]。

**生成區塊。** RRDB 把密集卷積區塊串接，外內兩層殘差，無 BN；分支相加前乘縮放，原文 **0.2**，初始化權重也縮小。大型模型 **23** 個 RRDB。

**相對平均判別器。** $C$ 為 sigmoid 前 raw 輸出，$\sigma$ 為 sigmoid，$x_r$ 為真 HR，$x_f$ 為生成。一般用 $\sigma(C(x))$ 作真實感分數，相對版改為：

$$
D_{Ra}(x_r, x_f) = \sigma\bigl(C(x_r) - \mathbb E_{x_f}[C(x_f)]\bigr),
$$

比較真實圖與批次生成平均 logit 的相對分數，$\mathbb E_{x_f}$ 對生成批次平均；不是校準後的客觀影像真實機率。損失為：

$$
\begin{aligned}
\mathcal L_D^{Ra} &= -\mathbb E_{x_r}\bigl[\log D_{Ra}(x_r, x_f)\bigr] - \mathbb E_{x_f}\bigl[\log\bigl(1 - D_{Ra}(x_f, x_r)\bigr)\bigr], \\
\mathcal L_G^{Ra} &= -\mathbb E_{x_r}\bigl[\log\bigl(1 - D_{Ra}(x_r, x_f)\bigr)\bigr] - \mathbb E_{x_f}\bigl[\log D_{Ra}(x_f, x_r)\bigr],
\end{aligned}
$$

$D_{Ra}(x_f,x_r)$ 交換真／生成角色。生成損失也含真圖，但梯度仍透過生成分數及其批次平均回到生成器。

**啟動前感知。** 原例所用深層 ReLU 後僅 **11.17%** 神經元啟動，監督較稀疏，也可能改變重建亮度。因此用 ReLU 前 VGG。總損失 $\mathcal L_G=\mathcal L_{\mathrm{percep}}+\lambda\mathcal L_G^{Ra}+\eta\mathcal L_1$，$\lambda,\eta$ 為權重。

**權重內插。** $\theta_{\mathrm{INTERP}}=(1-\alpha)\theta_{\mathrm{PSNR}}+\alpha\theta_{\mathrm{GAN}}$，GAN 版由像素版微調，具有共同起點。原文報權重內插比兩輸出逐像素混合有較好雜訊／模糊取捨，不是一般非線性網路的等價定理。

### LIIF 的三項改良

本節補充 LIIF [38] 三種讓特徵查詢更豐富、平滑且感知輸出像素大小的設計。

**特徵展開**串接每潛在點的 3 × 3 鄰域；**局部集成**查詢 $x_q$ 周圍四個代碼，以面積權重混合，避免最近點變動時跳躍；**像素格解碼**另把輸出像素高寬餵 MLP，區分細與粗樣本。
