## 你將學到

- 為什麼單張影像超解析度（super-resolution, SR）是**病態**（ill-posed）問題：同一張低解析度影像與許多張高解析度影像都相容，而用像素損失訓練的網路會傳回它們模糊的平均。
- **退化模型**（degradation model；只有雙三次縮小，或是模糊、降取樣、雜訊與 JPEG）如何決定模型能做到什麼、為什麼用雙三次資料訓練的模型在真實照片上會失效，以及混疊在頻域中是什麼樣子。
- 傳統工具箱（內插核、以範例為基礎與自相似的方法、稀疏編碼、學習式線性迴歸器），以及一個在 CPU 上大約一秒就能訓練完的線性迴歸器。
- CNN、GAN、Transformer 與擴散 SR 網路怎麼建構：先上取樣與後上取樣、**子像素卷積（sub-pixel convolution，又稱 pixel shuffle）**的精確索引規則、殘差與注意力網路、感知損失，以及**感知–失真權衡**（perception–distortion trade-off）。
- 簡介盲超解析度與真實世界 SR、任意倍率 SR、影片與參考影像 SR，以及高效率 SR。
- 實務上怎麼評估 SR（在 Y 通道上計算、裁去邊界的 PSNR 與 SSIM，標準測試集，NTIRE 挑戰賽），以及典型的失效模式：捏造的文字與人臉、紋理瑕疵、色偏與過度平滑。

## 先看全貌

超解析度讓小圖變大，**而且**變清楚。把像素拉開很容易；難的是補上小圖從來沒有記錄下來的細節。現代 SR 模型依據它對自然影像的認識來補這些細節，這是它的長處，也是它的風險。

為什麼重要：手機用的是數位變焦，影片與遊戲常先以小尺寸算繪再放大，衛星與顯微鏡受限於光學與感測器，老照片也要為了典藏而修復。許多低階視覺的想法也是先在 SR 上驗證的：殘差學習、通道注意力、感知損失、視窗注意力與擴散先驗。

## 問題：一個輸入，許多答案

**白話版。** 低解析度（low-resolution, LR）影像的數字比我們想要的高解析度（high-resolution, HR）影像少。許多張 HR 影像縮小後都會變成同一張 LR 影像。模型必須從中選一張，而怎麼選，取決於它相信自然影像長什麼樣子。

### 問題設定與符號

單張影像超解析度（single-image super-resolution, SISR）從一張 LR 影像 $y \in \mathbb R^{H \times W \times C}$ 估計 HR 影像 $x \in \mathbb R^{sH \times sW \times C}$，其中 $s$ 是**放大倍率**（scale factor，2、3、4……），$H \times W$ 是 LR 尺寸，$C$ 是色彩通道數。標準的正向模型已在 [DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#統一的觀點) 介紹過：

$$
y = (x * k)\downarrow_s + n,
$$

其中 $k$ 是模糊核（相機光學與像素積分造成的模糊，或刻意加上的抗混疊濾波器），$*$ 是對每個通道做的二維卷積，$\downarrow_s$ 在每個 $s \times s$ 區塊中只保留一個取樣，$n$ 是雜訊。多影格 SR（multi-frame SR）是這個問題較早的形式，它結合同一場景多張彼此有位移的 LR 影像，Park 等人 [1] 有完整的回顧；本篇談的是單張影像的情況，另有一小節談影片。

### 為什麼這是病態問題

數一數就知道。放大倍率為 $s$ 時，每個 LR 像素概括了 $s^2$ 個 HR 像素，所以 HR 影像的未知數是量測值的 $s^2$ 倍。在 $s = 4$ 時，即使是完美、沒有雜訊的 LR 影像，每 16 個 HR 值也只確定了其中一個線性組合；另外 15 個方向完全看不見。用數學的話說，退化運算子 $\mathcal D(x) = (x * k)\downarrow_s$ 有很大的**零空間**（null space）：任何滿足 $\mathcal D(z) = 0$ 的 HR 圖樣 $z$，加到解上都不會改變 $y$。細緻的紋理、邊緣的確切位置與小字，大多落在這個零空間裡。雜訊讓情況更糟，因為它連我們*確實*量到的資訊也一起破壞。

所以 SR 需要一個**先驗**（prior）$p(x)$，也就是「哪些 HR 影像是合理的」的模型。依貝氏定理，每個 HR 候選都有一個後驗機率

$$
p(x \mid y) \propto p(y \mid x)\, p(x),
$$

其中 $p(y \mid x)$ 是概似（likelihood，在給定雜訊下 $\mathcal D(x)$ 能多好地解釋 $y$），$p(x)$ 是先驗。傳統方法手寫先驗；深度 SR 則從（LR, HR）配對中學習先驗。

### 後驗平均造成的模糊

大多數 SR 網路都是在配對上最小化像素損失來訓練的。用平方誤差時，最好的網路輸出的是**後驗平均**（posterior mean）

$$
\hat x_{\text{MMSE}}(y) = \mathbb E[x \mid y] = \int x \, p(x \mid y)\, dx,
$$

也就是最小均方誤差（minimum mean-squared-error, MMSE）估計。（用 L1 損失時，最佳解是逐像素的後驗中位數，行為類似。）當後驗包含許多清晰的候選，彼此只差在邊緣的確切位置或紋理的相位時，它們的平均是一個平滑的折衷，*本身並不是*一張合理的影像。這就是用 MSE 訓練的 SR 看起來模糊的原因，再多訓練資料也去不掉：對於損失函數提出的問題，它就是正確答案。

一個一維的小例子可以把這件事講清楚。一個 64 個取樣的 HR 訊號是一個位置未知的階梯邊緣。我們把每 4 個取樣平均成一個，加上標準差 0.2 的雜訊，然後精確算出 32 個可能邊緣位置上的後驗、它的平均，以及從中隨機抽出的一個樣本。

```python
import numpy as np

rng = np.random.default_rng(0)
n, s, sigma = 64, 4, 0.2                 # HR length, scale factor, LR noise level
cand = np.arange(16, 48)                 # possible edge positions t (the prior: uniform)
X = (np.arange(n)[None, :] >= cand[:, None]).astype(float)    # every HR step edge x_t
DX = X.reshape(len(cand), n // s, s).mean(axis=2)              # their LR versions D(x_t)

err_mmse, err_samp, jump_mmse, jump_samp = [], [], [], []
for _ in range(2000):
    t = rng.integers(len(cand))
    y = DX[t] + sigma * rng.standard_normal(n // s)               # observed LR signal
    logp = -((y - DX) ** 2).sum(axis=1) / (2 * sigma**2)          # log posterior over t
    post = np.exp(logp - logp.max()); post /= post.sum()
    x_mmse = post @ X                                             # posterior mean E[x | y]
    x_samp = X[rng.choice(len(cand), p=post)]                     # one posterior sample
    err_mmse.append(np.mean((x_mmse - X[t]) ** 2)); err_samp.append(np.mean((x_samp - X[t]) ** 2))
    jump_mmse.append(np.diff(x_mmse).max()); jump_samp.append(np.diff(x_samp).max())

print(f"MSE   posterior mean {np.mean(err_mmse):.4f} | posterior sample {np.mean(err_samp):.4f} "
      f"| ratio {np.mean(err_samp) / np.mean(err_mmse):.2f}")
print(f"largest one-pixel jump (a real edge has 1.00): mean {np.mean(jump_mmse):.2f} | sample {np.mean(jump_samp):.2f}")
```

```text
MSE   posterior mean 0.0072 | posterior sample 0.0143 | ratio 1.97
largest one-pixel jump (a real edge has 1.00): mean 0.48 | sample 1.00
```

後驗平均的誤差只有後驗樣本的一半，但它的邊緣是斜坡：平均而言，它最大的單像素跳躍只有 0.48，而每個真實邊緣（以及每個樣本）都跳 1.00。樣本看起來和真實邊緣一模一樣，只是有時位置不對。比值約為 2 並非巧合。Blau 與 Michaeli 證明，如果一個估計器的輸出分布與真實影像完全相同（例如後驗取樣器），它的 MSE 永遠不需要超過 MMSE 估計器的兩倍，也就是 PSNR 差 3 dB [2]。圖 1 顯示一個例子，以及兩個估計器之間的整個範圍。

## 退化模型

**白話版。** 訓練 SR 網路需要配對，而配對是把 HR 影像縮小做出來的。*怎麼*縮小是一個建模選擇，網路學會的正好是把那一種縮小還原回去，其他的都不會。

### 雙三次基準設定

大多數 SR 基準用 MATLAB 的 `imresize` 以預設設定產生 LR 影像：預設使用雙三次內插，而且縮小時預設開啟抗混疊濾波 [3], [4]。不加雜訊、沒有相機模糊，也沒有壓縮。這種「bicubic」設定乾淨又可重現，讓多年來的結果可以互相比較，但真實相機並不是這樣縮小影像的。

### 模糊、降取樣、雜訊、壓縮

更真實的模型依循相機的物理過程，以及照片在網路上流傳的路徑：

$$
y = \mathcal C_q\Bigl( \mathcal Q\bigl( \mathcal A_s(x * k) + n \bigr) \Bigr),
\qquad
\mathcal A_s(z)[u, v] = \frac{1}{s^2} \sum_{a=0}^{s-1} \sum_{b=0}^{s-1} z[su + a,\; sv + b],
$$

其中 $k$ 是光學模糊（常以高斯函數建模），$\mathcal A_s$ 把每個 $s \times s$ 區塊平均（相當於一個較大的感測器像素收集到的光），每個區塊只留一個值，$[u, v]$ 是 LR 像素的索引，$n$ 是感測器雜訊，$\mathcal Q$ 把數值捨入成 8 位元，$\mathcal C_q$ 是品質 $q$ 的 JPEG 壓縮。順序很重要：在降取樣之後加入的雜訊，在 LR 影像中仍是細顆粒；在模糊之前加入的雜訊則會被抹平。

下面的程式實作前三步再加上量化（為了簡短省略 JPEG），然後用四種標準內插法上取樣，並照 SR 論文的方式回報 PSNR：在亮度（Y）通道上計算，並去掉寬 $s$ 像素的邊界。這套協定的細節在評估一節說明。

```python
import numpy as np, cv2
from scipy import ndimage as ndi
from skimage import data, img_as_float64

def degrade(hr, s=4, blur=1.2, noise=0.01, rng=None):
    """hr: (H, W, 3) in [0, 1], H and W divisible by s. Returns the LR image y."""
    rng = rng or np.random.default_rng(0)
    x = ndi.gaussian_filter(hr, sigma=(blur, blur, 0))          # 1) lens blur
    H, W, C = x.shape
    x = x.reshape(H // s, s, W // s, s, C).mean(axis=(1, 3))      # 2) s x s pixel integration + decimation
    x = x + noise * rng.standard_normal(x.shape)                  # 3) sensor noise
    return np.round(np.clip(x, 0, 1) * 255) / 255                 # 4) 8-bit quantization

def y_channel(rgb):
    """BT.601 luma on the [16, 235] scale (the MATLAB rgb2ycbcr convention)."""
    return 16 + rgb @ np.array([65.481, 128.553, 24.966])

def psnr(a, b, shave, peak):
    if shave:
        a, b = a[shave:-shave, shave:-shave], b[shave:-shave, shave:-shave]
    return 10 * np.log10(peak**2 / np.mean((a - b) ** 2))

hr = img_as_float64(data.astronaut())                             # (512, 512, 3)
lr = degrade(hr)                                                  # (128, 128, 3)
print("LR shape:", lr.shape)
for name, flag in [("nearest", cv2.INTER_NEAREST), ("bilinear", cv2.INTER_LINEAR),
                   ("bicubic", cv2.INTER_CUBIC), ("lanczos", cv2.INTER_LANCZOS4)]:
    sr = cv2.resize(lr, (512, 512), interpolation=flag)
    sr = np.clip(sr, 0, 1)
    y_hr, y_sr = y_channel(hr), y_channel(sr)
    print(f"{name:8s}  Y, shave 4: {psnr(y_hr, y_sr, 4, 255):.2f} dB | "
          f"Y, no shave: {psnr(y_hr, y_sr, 0, 255):.2f} dB | RGB, shave 4: {psnr(hr, sr, 4, 1):.2f} dB")
```

```text
LR shape: (128, 128, 3)
nearest   Y, shave 4: 24.62 dB | Y, no shave: 24.66 dB | RGB, shave 4: 23.06 dB
bilinear  Y, shave 4: 25.35 dB | Y, no shave: 25.40 dB | RGB, shave 4: 23.83 dB
bicubic   Y, shave 4: 26.36 dB | Y, no shave: 26.40 dB | RGB, shave 4: 24.81 dB
lanczos   Y, shave 4: 26.50 dB | Y, no shave: 26.54 dB | RGB, shave 4: 24.94 dB
```

不論用哪種協定，排名都一樣，但 Y 與 RGB 相差約 1.5 dB，所以只能比較用同一種方式量出的數字。圖 2 在一塊裁切區域上顯示流程的各個階段，最後再加上 JPEG。

### 為什麼用雙三次資料訓練的模型在真實照片上會失效

**白話版。** 用某一種縮小方式訓練的網路，會學到那種縮小方式的確切「指紋」。給它一張用別的方式縮小的影像，它就會套用錯誤的修正。

用雙三次配對訓練的模型，學會的是反轉一個特定、溫和而且沒有雜訊的核。真實的手機影像卻有更寬、因相機而異的模糊，去馬賽克（demosaicking）與去雜訊留下的痕跡，感測器雜訊，以及壓縮。於是會出兩種錯。如果真實的模糊比訓練時**更寬**，模型修正不足，結果仍然偏軟。如果真實影像比預期**更清晰**或雜訊更多，模型就會過度修正：連雜訊與 JPEG 區塊也一起銳化，並在邊緣周圍畫出光暈。Efrat 等人在傳統方法上指出，準確的模糊模型比精巧的影像先驗更重要，而 SR 演算法預設的模糊模型可能和真實相機的模糊不同，通常會導致過度平滑的結果 [5]。Cai 等人在深度網路上提出同樣的論點：他們用兩台 DSLR 相機以不同焦距拍攝，取得真實的 LR–HR 配對（RealSR 資料集），用這些真實配對訓練的模型，在真實影像上比用模擬雙三次資料訓練的模型表現更好 [6]。下一節會用一個很小的模型重現這種不匹配的效應（圖 6）。真實世界 SR 試著涵蓋所有相機退化，後面另有一節介紹。

### 混疊與頻域觀點

**白話版。** 縮小影像可能讓細條紋變成假的粗條紋。一旦發生，小圖就沒辦法告訴你那些粗條紋是真的還是假的，SR 模型只能猜。

在 LR 網格上取樣，只能表示到 LR **奈奎斯特極限**（Nyquist limit）為止的頻率，也就是每個 HR 像素 $1/(2s)$ 週期（$s = 4$ 時為 0.125）。在一維中，若 $X(f)$ 是 HR 訊號的頻譜，$f$ 以「每個 HR 取樣的週期數」為單位，那麼每 $s$ 個取樣保留一個，得到的 LR 頻譜為

$$
Y(f') = \frac{1}{s} \sum_{m=0}^{s-1} X\!\left(\frac{f' + m}{s}\right), \qquad -\tfrac12 \le f' \lt \tfrac12,
$$

其中 $f'$ 以每個 LR 取樣的週期數為單位，$X$ 以 1 為週期。每個 LR 頻率 $f'$，都是 $s$ 個「摺疊」到它上面的 HR 頻率 $(f' + m)/s$ 的總和：這種摺疊就是**混疊**（aliasing），[IP 04](/zh-tw/learn/image-processing/dip-04-frequency-domain/#二維取樣與混疊) 有詳細說明。取樣前的模糊（模型中的 $k$）會衰減高於 $1/(2s)$ 的 HR 頻率，讓摺疊進來的成分變少；這就是相機與 `imresize` 都先做模糊的原因。

這對 SR 有兩個後果。第一，高於 LR 奈奎斯特極限的內容，不是被模糊移除（只能憑空補出），就是混疊進 LR 影像（必須*展開*，而這只有在先驗能判斷哪個摺疊頻率比較合理時才做得到）。第二，即使在奈奎斯特極限以下，模糊也已經削弱了 HR 頻率，所以 SR 模型在實務上做的事，很大一部分其實是**去模糊**。圖 3 右圖同時顯示了這兩點：雙三次內插在每像素 0.125 週期之前就已經低於 HR 頻譜，而學習式線性模型（後面介紹）把這一段頻帶找回了不少，但在它之上幾乎沒有增加什麼。

## 傳統超解析度

**白話版。** 在深度學習之前，SR 方法要嘛用固定公式填補像素（內插），要嘛從相似的影像區塊複製細節（以範例為基礎的方法），要嘛學一個從小區塊到大區塊的簡單映射。這些想法都還活在現代網路裡。

### 內插是固定的線性濾波器

內插把 LR 取樣放到 HR 網格上，再用鄰近取樣的加權和填補空隙。在一維中，

$$
\hat x(t) = \sum_{u} y[u]\; \phi\!\left(\frac{t + \tfrac12}{s} - \tfrac12 - u\right),
$$

其中 $t$ 是 HR 像素索引，$u$ 是 LR 像素索引，$\phi$ 是**內插核**（interpolation kernel），兩個半像素項讓 LR 與 HR 像素的中心對齊（OpenCV 採用的慣例）。在二維中，這個核沿著列與行分離地套用。[IP 02](/zh-tw/learn/image-processing/dip-02-fundamentals/#影像內插) 推導了最近鄰、雙線性與雙三次內插；這裡把它們當作濾波器來比較。

- **最近鄰**（nearest neighbor）：$\phi$ 是寬度 1 的方框。呈方塊狀，但從不創造新的數值。
- **線性**（linear）：$\phi$ 是寬度 2 的三角形。連續，但偏軟。
- **三次卷積**（cubic convolution，Keys）[7]：寬度 4 的分段三次多項式，帶一個自由參數 $a$；Keys 證明在這個家族中，$a = -\tfrac12$ 有最好的逼近階數。它的小負瓣會稍微銳化邊緣，也可能造成輕微的振鈴。各個函式庫用的 $a$ 不盡相同：我們用 OpenCV 的 `INTER_CUBIC` 縮放單一個亮點，輸出與 $a = -0.75$ 的 Keys 核完全吻合，而不是 $a = -0.5$（練習 1）。
- **Lanczos**：用較寬的 sinc 加窗的 sinc，$\phi(t) = \operatorname{sinc}(t)\operatorname{sinc}(t/a)$（$|t| \lt a$ 時；其他情況為 0），其中 $\operatorname{sinc}(t) = \sin(\pi t)/(\pi t)$，$a$ 是每一側保留的瓣數 [8]。OpenCV 的 `INTER_LANCZOS4` 使用 $a = 4$。

對頻帶受限的訊號，理想的重建器就是 sinc 本身，它的頻率響應在奈奎斯特極限以下為 1、以上為 0。圖 4 比較各個核及其頻率響應。越寬的核越接近理想，所以 Lanczos 在上面的程式中得分最高（26.50 dB，雙三次為 26.36 dB）；但每個內插器都是**線性且平移不變**的：它無法創造高於 LR 奈奎斯特極限的頻率，對邊緣與平坦區域也用同一組權重。

### 以範例為基礎的 SR、自相似性與稀疏編碼

**白話版。** 如果一個模糊的小區塊看起來像你以前見過的某個清晰區塊的模糊版本，就把那個清晰版本貼上去。範例可以來自其他影像，也可以來自同一張影像較粗的尺度。

Freeman 等人從訓練影像建立這樣的配對 [9]；Glasner 等人發現小區塊會在同一張影像的尺度內與尺度間重複出現，所以輸入影像本身就能提供範例 [10]；Yang 等人則用一對共享同一組稀疏碼的字典來表示 LR 與 HR 區塊 [11]。SRCNN 後來把這條稀疏編碼流程解讀成一個三層網路（擷取區塊、映射、重建），深度 SR 就從這裡開始 [12]。

### 學習式線性迴歸器

**白話版。** 與其在測試時搜尋相似的區塊，不如事先為每一類區塊擬合一條簡單的公式：「長得像這樣的區塊，就加上這個修正。」這樣 SR 就只剩幾次矩陣乘法。

錨定鄰域迴歸（anchored neighborhood regression, ANR）用預先算好的嶺迴歸器取代稀疏編碼步驟，每個字典原子一個：LR 區塊被分派給與它最相關的原子，再乘上該原子的矩陣 [13]。A+ 改用原子附近的訓練樣本、而不是鄰近的原子來擬合每個迴歸器，在相同速度下提升了品質 [14]。RAISR 依局部梯度的角度、強度與一致性（coherence）把每個區塊雜湊分桶，再套用以最小平方法為該桶學到的濾波器 [15]。共同的結構是

$$
\hat r = W_{c(p)}^{\top} \tilde p,
\qquad
W_c = \arg\min_{W} \sum_{i \in c} \bigl\| W^{\top} \tilde p_i - r_i \bigr\|_2^2 + \lambda \|W\|_F^2
= (P_c^{\top} P_c + \lambda I)^{-1} P_c^{\top} R_c,
$$

其中 $p$ 是 LR 區塊，$\tilde p$ 是它的特徵向量，$c(p)$ 是它所屬的類別（原子或雜湊桶），$r$ 是要預測的 HR 細節，$(\tilde p_i, r_i)$ 是類別 $c$ 的訓練配對，分別堆疊成 $P_c$ 與 $R_c$ 的列，$\lambda$ 是嶺迴歸的權重，$\|\cdot\|_F$ 是 Frobenius 範數。

下面的程式實作最簡單的版本，只有一個類別。對每個 LR 像素，取它周圍 $7 \times 7$ 的 LR 區塊（減去平均值，再加一個常數 1 當偏差項），預測 $4 \times 4$ 的 HR **殘差**區塊，也就是 HR 影像與其雙三次上取樣之間的差。每個 LR 像素預測 $s^2$ 個值，再重新排成一個 $s \times s$ 區塊，正是子像素卷積在做的事，CNN 一節會再看到：這個模型就是一層、線性的 ESPCN。我們用十一張 `skimage` 影像訓練它兩次：一次針對「清晰」的 LR 輸入（只做區塊平均），一次針對「模糊」的 LR 輸入（平均前先做 σ = 1.2 的高斯模糊），再把兩個模型都拿到不在訓練集裡的太空人影像上測試。

```python
import numpy as np, cv2
from numpy.lib.stride_tricks import sliding_window_view
from scipy import ndimage as ndi
from skimage import data, img_as_float64
from skimage.color import rgb2gray

s, p = 4, 7                                     # scale factor, LR patch size

def degrade(x, blur):                           # blur (optional) -> s x s average
    x = ndi.gaussian_filter(x, blur) if blur else x
    H, W = x.shape[0] // s * s, x.shape[1] // s * s
    return x[:H, :W].reshape(H // s, s, W // s, s).mean(axis=(1, 3))

def bicubic(lr):
    return cv2.resize(lr, None, fx=s, fy=s, interpolation=cv2.INTER_CUBIC)

def features(lr):                               # one p x p patch per LR pixel, mean removed, plus a bias
    f = sliding_window_view(np.pad(lr, p // 2, mode="reflect"), (p, p)).reshape(lr.size, p * p)
    return np.c_[f - f.mean(axis=1, keepdims=True), np.ones(lr.size)]

def to_blocks(r):                               # HR residual -> one s*s vector per LR pixel (space-to-depth)
    h, w = r.shape[0] // s, r.shape[1] // s
    return r.reshape(h, s, w, s).transpose(0, 2, 1, 3).reshape(h * w, s * s)

def from_blocks(b, h, w):                       # inverse: depth-to-space (pixel shuffle)
    return b.reshape(h, w, s, s).transpose(0, 2, 1, 3).reshape(h * s, w * s)

def train(images, blur, lam=1e-3):
    A, B = [], []
    for im in images:
        im = im[: im.shape[0] // s * s, : im.shape[1] // s * s]
        lr = degrade(im, blur)
        A.append(features(lr)); B.append(to_blocks(im - bicubic(lr)))
    A, B = np.concatenate(A), np.concatenate(B)
    return np.linalg.solve(A.T @ A + lam * np.eye(A.shape[1]), A.T @ B)   # ridge: (p*p+1, s*s)

def super_resolve(lr, Wt):
    return bicubic(lr) + from_blocks(features(lr) @ Wt, *lr.shape)

def psnr(a, b):
    a, b = a[s:-s, s:-s], b[s:-s, s:-s]          # shave s border pixels
    return 10 * np.log10(1.0 / np.mean((a - np.clip(b, 0, 1)) ** 2))

train_imgs = [img_as_float64(im) for im in (data.camera(), data.moon(), data.coins(), data.page(),
              data.text(), data.brick(), data.grass(), data.gravel(),
              rgb2gray(data.coffee()), rgb2gray(data.chelsea()), rgb2gray(data.rocket()))]
models = {"trained sharp": train(train_imgs, 0.0), "trained blurry": train(train_imgs, 1.2)}
test = img_as_float64(rgb2gray(data.astronaut()))           # never seen in training
print("weights per model:", models["trained sharp"].shape)
for name, blur in [("sharp", 0.0), ("blurry", 1.2)]:
    lr = degrade(test, blur)
    row = "  ".join(f"{m} {psnr(test, super_resolve(lr, W)):.2f}" for m, W in models.items())
    print(f"test {name:6s} | bicubic {psnr(test, bicubic(lr)):.2f} | {row}  (dB)")
```

```text

test sharp  | bicubic 25.61 | trained sharp 26.05  trained blurry 25.43  (dB)
test blurry | bicubic 24.98 | trained sharp 25.66  trained blurry 26.26  (dB)
```

每個模型只有 $50 \times 16 = 800$ 個權重，以封閉解大約一秒就擬合完成。在退化相符時，它在一張沒看過的影像上比雙三次高 0.44 dB（清晰輸入）與 1.28 dB（模糊輸入）。非對角的結果重現了前面描述的失效。用模糊資料訓練的模型套在清晰輸入上會**過度銳化**，結果反而低於雙三次（25.43 dB 對 25.61 dB）；用清晰資料訓練的模型套在模糊輸入上則修正不足（25.66 dB，退化相符的模型為 26.26 dB）。圖 6 顯示裁切結果與 16 個學到的濾波器，每個子像素偏移一個。下面的滑桿在模糊輸入上比較雙三次與退化相符的線性模型。

## CNN 超解析度

**白話版。** CNN 是上面那個迴歸器豐富得多的版本：許多層堆疊、非線性、看得到大範圍鄰域的濾波器。主要的設計問題是：在哪裡提高解析度、怎麼讓深層網路訓練得起來，以及運算量要花在哪裡。

### 先上取樣：SRCNN 與 VDSR

SRCNN 是第一個端到端的 SR CNN，它先用雙三次內插放大輸入，再套用三層卷積，作者把這三層解讀為區塊擷取、非線性映射與重建，也就是稀疏編碼 SR 的同樣三個步驟 [12]。VDSR 把網路做得深得多（20 個由 $3 \times 3$ 濾波器組成的權重層），並靠兩個選擇讓這樣的深度可以訓練：它只預測 HR 影像與內插輸入之間的**殘差**，並使用非常高的學習率，再以可調整的梯度裁剪維持穩定 [16]。殘差的想法和我們的線性模型相同：雙三次影像已經包含低頻，網路只需要補上缺少的細節，而那是一個小而以零為中心的訊號。

先上取樣很簡單，一個網路就能處理任何倍率（只要改變內插倍率），但每一層都在 HR 尺寸上運算，所以每層的成本是在 LR 尺寸上的 $s^2$ 倍，網路還得清理內插造成的瑕疵。圖 7 把它與後上取樣對照。

### 後上取樣與子像素卷積

FSRCNN 把上取樣移到最後，改用學習得到的轉置（分數步長）卷積，在映射層之前先縮小特徵維度，並報告比 SRCNN 快 40 倍以上 [17]。ESPCN 提出**子像素卷積層**（sub-pixel convolution layer）：最後一層卷積在 LR 解析度上產生 $C s^2$ 個通道，再由一個固定的重新排列（現在稱為 **pixel shuffle**，或 depth-to-space）把它們變成 $s$ 倍解析度的 $C$ 個通道 [18]。所有學習的層都在 LR 尺寸上運算，重新排列本身沒有參數。EDSR、RCAN 與 SwinIR 的上取樣模組都使用它 [19], [20], [21]。

精確的版本是一條索引規則。設 $T$ 是形狀為 $(C s^2, H, W)$ 的 LR 特徵張量，$X = \mathrm{PS}(T)$ 是形狀為 $(C, sH, sW)$ 的輸出，則

$$
X\bigl[c,\; s h + i,\; s w + j\bigr] = T\bigl[c\, s^2 + s\, i + j,\; h,\; w\bigr],
\qquad 0 \le c \lt C,\;\; 0 \le h \lt H,\;\; 0 \le w \lt W,\;\; 0 \le i, j \lt s,
$$

其中 $c$ 是輸出通道，$(h, w)$ 是一個 LR 位置，$(i, j)$ 是屬於該 LR 位置的 $s \times s$ 輸出區塊內的**子像素偏移**（sub-pixel offset）。換句話說：屬於輸出通道 $c$ 的那 $s^2$ 個通道，依 $(i, j)$ 的列優先順序讀出，攤到一個 $s \times s$ 區塊上。這正是 PyTorch `PixelShuffle` 的順序：它的實作把通道軸重塑成 $(C, s, s)$，再把它們排到高度軸與寬度軸旁邊 [22]。反向運算 **space-to-depth**（pixel unshuffle）把每個 $s \times s$ 區塊讀回 $s^2$ 個通道；有些高效率網路在輸入端使用它，以便在較低的解析度上運算。圖 8 畫出 $s = 2$ 時的規則。

<Figure src={shuffleFig} alt="左：四張彩色的 3 × 3 LR 特徵圖，標示為通道 0 到 3，子像素偏移分別為 (0,0)、(0,1)、(1,0)、(1,1)；每張左上角的格子有外框。右：一張 6 × 6 的 HR 網格，每個 2 × 2 區塊依閱讀順序包含通道 0、1、2、3 的顏色；左上角的區塊有外框。文字：輸出像素 (s·h + i, s·w + j) 來自 LR 位置 (h, w) 的通道 s·i + j。" caption="圖 8 — s = 2、C = 1 時的 pixel shuffle。同一個 LR 位置上的四個值（每個通道一個）變成一個 2 × 2 的輸出區塊。" />

下面的 NumPy 版本把 pixel shuffle 與它的反運算各寫成一次 reshape、一次 transpose、再一次 reshape，逐元素檢查索引規則，並確認兩個運算互為精確的反運算。

```python
import numpy as np

def pixel_shuffle(t, s):
    """Depth-to-space: (C*s*s, H, W) -> (C, H*s, W*s)."""
    Cs2, H, W = t.shape
    C = Cs2 // (s * s)
    return t.reshape(C, s, s, H, W).transpose(0, 3, 1, 4, 2).reshape(C, H * s, W * s)

def pixel_unshuffle(x, s):
    """Space-to-depth: (C, H*s, W*s) -> (C*s*s, H, W)."""
    C, Hs, Ws = x.shape
    H, W = Hs // s, Ws // s
    return x.reshape(C, H, s, W, s).transpose(0, 2, 4, 1, 3).reshape(C * s * s, H, W)

rng = np.random.default_rng(0)
s, C, H, W = 3, 2, 4, 5
t = rng.standard_normal((C * s * s, H, W))
x = pixel_shuffle(t, s)
print(x.shape)                                                   # (2, 12, 15)

# The index rule: output (c, s*h + i, s*w + j) comes from channel c*s*s + s*i + j at (h, w).
ok = all(x[c, s*h + i, s*w + j] == t[c*s*s + s*i + j, h, w]
         for c in range(C) for h in range(H) for w in range(W)
         for i in range(s) for j in range(s))
print("index rule holds:", ok)
print("unshuffle(shuffle(t)) == t:", np.array_equal(pixel_unshuffle(x, s), t))
print("shuffle(unshuffle(x)) == x:", np.array_equal(pixel_shuffle(pixel_unshuffle(x, s), s), x))
```

```text

index rule holds: True
unshuffle(shuffle(t)) == t: True
shuffle(unshuffle(x)) == x: True
```

Pixel shuffle 是陣列元素的一種排列（permutation），所以可以精確反轉，它的梯度就是反向的排列。因此，子像素卷積其實就是 $s^2$ 個普通卷積，每個子像素偏移一個，輸出交錯排列；我們的線性迴歸器就是只有一層的情況。如果這 $s^2$ 個濾波器從互不相關的隨機值開始，最初的輸出會出現棋盤狀圖樣；Aitken 等人把它們初始化成等同於「一個卷積接著最近鄰上取樣」，就消除了這個問題 [23]。

### 深層殘差網路與注意力網路

**白話版。** 越深的網路看得到越多上下文，也能建模越複雜的細節，但也越難訓練。解法和影像分類一樣（殘差連接），再加上幾個 SR 特有的技巧。

EDSR 把殘差網路改造成適合 SR 的形式，並拿掉了批次正規化層，作者認為它們對 SR 沒有必要，又耗費 GPU 記憶體；為了穩定訓練一個很寬的模型（32 個殘差區塊、256 個特徵通道），它在相加之前把每個殘差分支乘上 0.1 [19]。EDSR 也改用 L1 損失而不是 L2 來訓練，它的多倍率變體 MDSR 讓 ×2、×3 與 ×4 共用同一個主體，只有頭尾是各倍率專屬的。它贏得了 NTIRE 2017 SR 挑戰賽 [19], [24]。RCAN 走得更深（超過 400 層），採用**殘差中的殘差**（residual-in-residual）結構，也就是在一群群殘差區塊外面加上長跳躍連接、群內使用短跳躍連接，讓低頻資訊可以繞過主體；它還加入**通道注意力**（channel attention），用每個特徵通道的全域統計量算出一個權重，來重新縮放該通道 [20]。這些網路以 DIV2K（見基準一節）訓練，搭配隨機裁切、翻轉與旋轉；一般的訓練做法與損失函數在 [DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#損失函數) 中介紹。

## 感知式與對抗式 SR

**白話版。** 如果像素損失總是傳回保險但模糊的平均，那就換個損失：獎勵看起來像真實照片的輸出，即使細節的位置不完全正確。

### 感知損失與 GAN

Johnson、Alahi 與 Fei-Fei 用**感知損失**（perceptual loss）訓練 SR 網路，也就是輸出與目標在一個預訓練分類網路（VGG [25]）中的特徵之間的距離，得到比像素損失更銳利的邊緣與紋理，代價是 PSNR 較低 [26]。SRGAN 加入**對抗損失**（adversarial loss）：判別器學習分辨 SR 輸出與真實 HR 影像，SR 網路則被訓練去騙過它；用作者的話說，這會「把解推向自然影像流形」，並搭配一個 VGG 內容損失 [27]。ESRGAN 把每個部分都改良了（不含批次正規化的密集殘差區塊；相對式判別器，判斷真實影像是否看起來*比*生成影像更真實；以及在 VGG 激活函數之前的特徵上計算的感知損失），並在 PIRM 2018 感知 SR 挑戰賽中贏得它所在區域的第一名 [28], [29]。典型的生成器損失為

$$
\mathcal L = \lambda_1 \,\| \hat x - x \|_1 + \lambda_p \,\bigl\| \phi(\hat x) - \phi(x) \bigr\|_2^2 + \lambda_a \,\mathcal L_{\text{adv}}(\hat x),
$$

其中 $\hat x$ 是 SR 輸出，$x$ 是 HR 目標，$\phi$ 是預訓練網路中一個固定的層，$\mathcal L_{\text{adv}}$ 是用判別器算出的對抗項，$\lambda_1, \lambda_p, \lambda_a \ge 0$ 是手動選擇的權重。GAN 在 [ML 06](/zh-tw/learn/ml/ml-06-generative-models/#gan與對手一起學習) 中說明。

### 感知–失真權衡

Blau 與 Michaeli 把**失真**（distortion）定義為 $\hat x$ 與 $x$ 之間的期望差異（例如 MSE），把**感知品質**（perceptual quality）定義為輸出分布與真實影像分布之間的距離，並證明兩者無法同時最小化：在給定失真下能達到的最佳感知品質，會隨著允許的失真縮小而變差（這條界線是非遞增的，對常見的散度而言也是凸的），而 MMSE 估計器位於界線上低失真、低真實感的那一端 [2]。正式的敘述見 [DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#感知失真權衡)。圖 1 的小例子就描出了這樣一條曲線：從後驗平均移向後驗樣本，MSE 從 0.0072 升到 0.0143，真實感的差距則消失。這對 SR 有兩個實際的影響：

- 方法應該說明它瞄準權衡上的*哪個位置*。只用 PSNR，或只用一個感知指標，去比較 GAN 與 MSE 網路，無法說明哪一個比較好。
- 基準必須同時量測兩個軸。PIRM 2018 挑戰賽就是這樣做的：它依 RMSE 把感知–失真平面分成三個區域（RMSE 上限分別為 11.5、12.5 與 16），在每個區域內以一個感知指數為方法排名，這個指數由兩個無參考指標組成：NIQE [30] 與 Ma 等人的 SR 專用指標 [31], [29]。

## Transformer SR

**白話版。** Transformer 讓每個輸出像素都能從影像中很遠的地方取得資訊，而且是依內容、而不是依距離來挑選。這對窗戶、磁磚與文字這類重複結構有幫助。

SwinIR 在一個淺層卷積特徵擷取器與一個子像素重建模組之間，放入殘差 Swin Transformer [32] 區塊：在局部視窗內做自注意力，視窗在層與層之間位移，讓資訊能跨越視窗邊界 [21]。視窗注意力的成本隨影像大小線性成長，這對密集輸出很重要。HAT 用歸因分析（attribution analysis）主張 SwinIR 這類模型只用到輸入中有限的空間範圍，於是結合通道注意力與視窗自注意力，並在相鄰視窗之間加入重疊交叉注意力模組，來「激活更多像素」；它也先在大型資料集上針對同一個 SR 任務預訓練，再做微調 [33]。DAT 在連續的區塊中交替使用空間自注意力與通道自注意力，並加入讓兩者互動的模組 [34]。MambaIR 這類狀態空間模型以選擇性掃描取代注意力，以線性成本涵蓋整張影像 [35]。注意力與視窗注意力的一般概念見 [ML 04](/zh-tw/learn/ml/ml-04-vision-transformers/#swin-與階層式-transformer)。

這些網路通常用 L1 損失訓練、用 PSNR 評估，所以它們仍然是**後驗平均估計器**：它們降低了平均值的誤差，並沒有擺脫平均。它們更清楚的輸出來自對上下文更好的利用，而不是來自取樣。

## 以擴散模型為基礎的 SR

**白話版。** 擴散模型學習把雜訊一步步變成逼真的影像。以 LR 影像為條件時，它會生成一張與輸入相符的 HR 影像，不同的隨機種子會給出不同的合理答案：它是後驗取樣器，而不是平均器。

SR3 是具代表性的第一個方法：一個 U-Net [36] 被訓練去除各種強度的雜訊，以上取樣後的 LR 影像為條件，從純高斯雜訊出發、經過許多步的修正來生成 HR 影像 [37]。在一項 ×8 人臉 SR 的人類評測中，它的輸出騙過評分者的比例接近一半，GAN 基準方法都達不到這個比例 [37]。對於真實照片，現在的方法從大型的**預訓練文字生成影像擴散模型**出發，再加上一個以 LR 影像為條件的機制。例如 StableSR 在固定預訓練模型的同時，訓練一個感知時間步的編碼器（time-aware encoder），並加入一個特徵包裹模組（feature wrapping），它的純量權重讓使用者在推論時於真實感與保真度之間取捨 [38]。擴散的機制見 [ML 07](/zh-tw/learn/ml/ml-07-diffusion-flow-matching/#潛在擴散)。

對 SR 而言，最重要的有三件事。擴散的輸出是樣本，所以落在感知–失真權衡中真實、失真較高的一端，PSNR 比迴歸網路低。它們的細節是生成出來的，所以可能是錯的（見失效模式）。而且它們很慢：早期方法每張影像需要數百次網路評估，近期的研究把它降到幾步（ResShift，15 步 [39]），甚至一步（OSEDiff [40]）。Moser 等人把運算量、論文之間難以比較，以及色偏，列為擴散 SR 的開放問題 [41]；StableSR 也因此加入了一個明確的色彩校正步驟 [38]。

## 盲超解析度與真實世界 SR

**白話版。** 在真實世界中，沒有人會告訴模型影像是怎麼被縮小的。模型要嘛學會處理範圍非常廣的損傷，要嘛先估計損傷，再把它還原。

### 退化合成流程

**隱式**路線用一個寬到足以涵蓋真實照片的退化分布，訓練單一個網路。BSRGAN 的實用退化模型以**隨機打亂的順序**套用模糊（等向與非等向高斯核的兩次卷積）、降取樣（隨機選擇最近鄰、雙線性或雙三次）、高斯雜訊、JPEG 壓縮，以及經過處理的相機感測器雜訊 [42]。Real-ESRGAN 則把經典的 模糊–縮放–雜訊–JPEG 鏈套用**兩次**（「高階」退化，實務上是二階），加入 sinc 濾波器來模擬真實影像中的振鈴與過衝瑕疵，並使用 U-Net 判別器 [43]。兩者都只用合成配對訓練，再拿到真實影像上測試。上面退化程式中的 `degrade` 函式，就是這些流程的一階版本。

### 模糊核估計

**明確**路線保留傳統模型 $y = (x * k)\downarrow_s + n$，估計模糊核 $k$ 與雜訊強度，或把它們當作額外輸入交給網路。估計正確時效果很好，而我們的不匹配實驗顯示了估計錯誤時會發生什麼：過度銳化或過度平滑。Liu 等人沿著兩個軸整理盲 SR：退化是明確還是隱式建模，以及使用外部資料集還是單一輸入影像 [44]；[DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#真實世界與盲退化) 介紹了主要的明確方法。

*選讀：[三個利用模糊核的方法](#三個利用模糊核的方法)（見「補充資料」頁）。用幾行分別概述 SRMD、IKC 與 KernelGAN。*

### 實拍配對

第三條路線是拍攝真實資料。RealSR 用兩台 DSLR 相機以不同焦距拍攝同一場景並加以對位，所以「退化」來自真實的鏡頭與感測器 [6]。DRealSR 把這個想法擴展到五台 DSLR 相機，以涵蓋更多樣的退化過程 [45]。實拍配對是最真實的資料，但它們昂貴、規模小、只適用於所用的相機，而且兩個變焦倍率之間需要仔細對齊。

## 任意倍率 SR

**白話版。** 大多數 SR 網路只針對一個固定倍率（例如 ×4）訓練。任意倍率網路把影像當作連續函數，所以你可以要求任何輸出尺寸，包括 ×2.7 這種非整數倍率。

Meta-SR 以**元放大模組**（meta-upscale module）取代固定的上取樣層，它根據放大倍率與每個輸出像素的相對位置，預測放大濾波器的權重 [46]。LIIF 更進一步，學習一個**局部隱式影像函數**（local implicit image function）[47]：

$$
\hat I(x_q) = f_\theta\bigl(z^{*},\; x_q - v^{*}\bigr),
$$

其中 $x_q$ 是影像平面上一個連續的查詢座標，$z^{*}$ 是網格位置 $v^{*}$ 最接近 $x_q$ 的潛在特徵向量（來自套用在 LR 影像上的 CNN 編碼器），$f_\theta$ 是一個小型 MLP，輸出 $x_q$ 處的 RGB 值。因為 $x_q$ 是連續的，同一個網路可以算繪任何輸出尺寸；作者展示了高達 ×30 的輸出，遠超出訓練倍率 [47]。代價是每個輸出像素都要評估一次 MLP，而在遠離訓練範圍的倍率上，品質受限於編碼器看過的東西。

*選讀：[LIIF 的三項改良](#liif-的三項改良)（見「補充資料」頁）。說明特徵展開、局部集成與像素格解碼。*

## 影片與參考影像 SR（簡介）

**白話版。** 同一場景的其他影像含有額外的資訊。影片 SR 利用相鄰的影格；參考影像 SR 則利用另一張內容相近的高解析度照片。

相鄰的影片影格以略微不同的子像素位置拍到場景，正是最初的多影格 SR 情境 [1]，所以在某一格中混疊掉的細節，可能在另一格中看得到；困難在於對齊移動中的內容。BasicVSR 是廣泛使用的基準方法，由雙向循環傳播與光流對齊組成 [48]。參考影像 SR 透過特徵匹配，從一張 HR 參考影像轉移紋理，例如 TTSR 用注意力來做 [49]；參考影像相符時它非常忠實，不相符時表現也必須平穩地退回，不能崩壞。

## 效率

**白話版。** 許多 SR 用途（手機、視訊通話、遊戲算繪）需要在小晶片上以毫秒級的時間給出結果。高效率 SR 問的是：在維持品質門檻的前提下，網路可以做到多小、多快。

用 pixel shuffle 做後上取樣是第一條效率守則：幾乎所有運算都在 LR 尺寸上進行。除此之外，高效率 SR 網路會以低成本重複利用特徵。例如 IMDN 一步步把特徵分成保留下來的「蒸餾」部分與繼續處理的部分，再以感知對比的通道注意力（contrast-aware channel attention）融合它們 [50]。參數量、FLOPs 與執行時間量的是不同的成本，所以 NTIRE 高效率 SR 挑戰賽三者都計分。2024 與 2025 年的任務是 ×4 SR，參賽作品必須在挑戰賽的驗證集上達到至少 26.90 dB、在測試集上達到至少 26.99 dB 的 PSNR，同時盡量減少執行時間、參數量與 FLOPs [51], [52]。擴散模型離這些預算還很遠，這也是一步蒸餾成為熱門題目的原因。

## 評估 SR

**白話版。** SR 結果有兩種評判方式：輸出與真實 HR 影像有多接近（保真度），以及它看起來有多自然（感知品質）。在保真度上，社群使用一套固定的做法，而其中的小細節會改變數字，所以必須完全照做。通用指標、無參考指標與使用者研究在 [DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#評估指標) 中說明；本節只談 SR 特有的部分。

### 在 Y 通道上計算並裁去邊界的 PSNR 與 SSIM

傳統的協定承襲自早期論文的 MATLAB 程式碼，至今仍為大多數論文與挑戰賽採用：

1. 把 HR 影像與 SR 輸出都轉成 YCbCr，只保留亮度（luma）通道
$$
Y = 16 + 65.481\, R + 128.553\, G + 24.966\, B,
$$
其中 $R, G, B \in [0, 1]$ 是（經過 gamma 編碼的）色彩值，$Y$ 落在 $[16, 235]$ 之間。這是 MATLAB 的 `rgb2ycbcr`（以及 `skimage.color.rgb2ycbcr`）所實作的 BT.601 係數 [53], [54]。
2. 比較之前，從兩張影像都去掉一圈邊界像素（「裁邊」，shaving），避免填補造成的邊界效應主導結果。寬度不一：EDSR 回報基準結果時在 Y 上計算，裁去的邊界寬度等於放大倍率 [19]；NTIRE 2024 與 2025 的 ×4 挑戰賽則排除 4 像素寬的邊界，並在 Y 上計算 [55], [56]。
3. 在剩下的部分以峰值 255 計算 PSNR 與 SSIM [57]。定義見 [DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#全參考指標)。

為什麼用亮度？人眼對亮度細節比對色彩細節敏感，而且許多早期方法只對 Y 做超解析度。Wang 等人指出，單是訓練或評估時所選的色彩空間與通道，就可能讓結果差很多，在一個報告的案例中高達 4 dB [4]。這個差異有一部分純粹是算術：上面的係數總和為 219，所以 $Y = 16 + 219\,\ell$，其中 $\ell \in [0, 1]$；以峰值 255 在 $Y$ 上計算 PSNR，比以峰值 1 在 $\ell$ 上計算多出一個常數 $20 \log_{10}(255/219) \approx 1.32$ dB。我們的第一段程式也顯示了 Y 與 RGB 之間類似的差距（約 1.5 dB）。捨入到 8 位元、截斷（clipping），以及用來產生 LR 影像的縮放器，也會讓結果略有偏移，所以公平的比較會讓每個方法都跑同一支評估程式。

### 標準測試集

SR 論文在一小組公開測試集上回報結果，每個測試集各有特色 [4]：

| 測試集 | 影像數 | 內容 | 出處 |
| --- | --- | --- | --- |
| Set5 | 5 | 嬰兒、鳥、蝴蝶、頭像、女性 | [58] |
| Set14 | 14 | 人物、動物、花、漫畫、投影片 | [59] |
| BSD100 (B100) | 100 | 自然場景，即 Berkeley 分割資料集的測試影像 | [60] |

Set5 與 Set14 很小，所以單看它們上面幾百分之一 dB 的差異意義不大。這些測試集全都用在雙三次設定；對於真實世界 SR，論文會再加上 RealSR、DRealSR 這類實拍測試集 [6], [45] 與無參考指標。

### 為什麼 PSNR 與感知排名不一致

有三個原因，本篇都看過了。第一，後驗平均的論證：PSNR 在所有合理答案的平均處最大，而那個平均是模糊的，所以任何選定一個清晰答案的方法都會損失 PSNR，即使它看起來更好（圖 1）。第二，錯位：一個統計特性正確、但平移了半個週期的紋理，像素誤差很大。第三，這些指標本來就是為不同目的設計的：無參考指標與 LPIPS [65] 這類學習式感知指標獎勵看起來自然的紋理，也可能被過度銳化騙過，而 PSNR 獎勵平滑。因此挑戰賽兩者都報告。NTIRE 2025 ×4 挑戰賽設有一個以 PSNR 排名的復原賽道，以及一個感知賽道，後者以六個全參考與無參考品質指標（包括 LPIPS 與 NIQE）合成的單一分數排名 [56], [30]。[DLCV 04](/zh-tw/learn/deep-learning/dl-04-image-restoration/#使用者研究與成對比較) 中的通用建議同樣適用：回報一個保真度指標、一個感知指標，生成式 SR 再加上使用者研究。

## 資料集、基準與 NTIRE 挑戰賽

**白話版。** 幾個資料集加上一年一度的競賽，決定了 SR 中「最新技術」的大部分意義。知道它們量的是什麼，就知道排行榜上的數字代表什麼、不代表什麼。

- **DIV2K** [64] 包含 1,000 張多樣的 2K 解析度影像，依 800／100／100 分成訓練、驗證與測試 [56]。它是為 NTIRE 2017 挑戰賽推出的，也是標準的訓練集。它常與 **Flickr2K** 合用，NTIRE 2025 報告描述 Flickr2K 為 2,650 張 2K 影像 [56]；近年的挑戰賽還加入了大得多的影像集。
- **NTIRE 2017** [24] 是這個系列的第一個 SR 挑戰賽。賽道 1 使用標準的雙三次降取樣；賽道 2 使用未知的降取樣運算子，可以從提供的 LR–HR 訓練配對中學到；兩個賽道各有 ×2、×3 與 ×4 的競賽。
- **NTIRE 2020 真實世界 SR** [66] 完全不提供配對資料：只有一組來源影像與一組非成對的高品質目標影像，一個賽道是合成的處理瑕疵，另一個是真實的智慧型手機影像，以感知品質的人類評測排名。
- **NTIRE 2024 與 2025 ×4 SR** [55], [56] 回到 DIV2K 上的雙三次 ×4；2025 年版加入了上面描述的感知賽道。
- **NTIRE 高效率 SR** [51], [52] 在固定的 PSNR 門檻之上，依執行時間、參數量與 FLOPs 為 ×4 模型排名。

## 失效模式

**白話版。** SR 模型失敗的方式，可能是太謹慎（模糊），也可能是太大膽（捏造細節）。大膽的失敗比較危險，因為結果看起來很有說服力。

- **過度平滑。** 用 MSE 與 L1 訓練的模型傳回後驗平均：蠟像般的皮膚、扁平的草地、軟塌的頭髮。這是預期中的行為，不是程式錯誤（圖 1）。
- **捏造的文字與人臉。** 在大倍率下，生成模型可能把無法辨認的文字變成清楚卻*錯誤*的字元，也可能把只有幾個像素的人臉變成一張具體、清晰、卻不是被拍攝者本人的臉。對鑑識、醫學或科學影像而言，這是不能接受的。Ren 等人主張，保真度指標與無參考品質指標都無法好好捕捉這類幻覺（hallucination），並提出用多模態大型語言模型為它們評分 [67]。
- **紋理瑕疵。** 以 GAN 為基礎的模型可能加入重複、類似雜訊的紋理，或把 JPEG 區塊銳化成結構；ESRGAN 的設計目的之一，就是減少 SRGAN 這類「令人不快的瑕疵」[28]。我們那個不匹配的線性模型，以縮小版呈現了同樣的效應：光暈與誇張的邊緣（圖 6）。
- **色偏。** 以擴散模型為基礎的 SR 可能讓整體色彩偏離輸入 [41], [38]；一個便宜的檢查方法是把輸出降取樣，再與 LR 輸入比較色彩。
- **退化不匹配。** 用錯誤退化訓練的模型會修正不足或過度修正（真實世界一節與圖 6）。在多種退化上測試，而不只是雙三次，就能揭露這個問題。
- **分塊接縫。** 大型影像常分塊處理；不重疊的分塊可能留下明顯的邊界，SwinIR 的作者在談分塊處理時也提到這一點 [21]。

對任何 SR 輸出都很有用的一個合理性檢查，是**與輸入的一致性**：用假設的模型把輸出退化，再與 $y$ 比較。差異很大，代表模型改動了 LR 影像確實量測到的內容。

## 現代觀點

### 綜述論文

**白話版。** 四篇綜述畫出了這個領域的地圖：一篇談一般的深度 SR，一篇談盲 SR，一篇談真實世界 SR，一篇談以擴散模型為基礎的 SR。照這個順序讀。

Wang、Chen 與 Hoi 依上取樣框架、上取樣運算、網路設計、損失函數與學習策略整理深度 SR [4]。Liu 等人依退化如何建模（明確或隱式），以及使用哪些資料（外部資料集或單一輸入影像）為盲 SR 分類 [44]。Chen 等人把真實世界 SR 分成退化建模、實拍影像配對、領域轉換與自學習四類 [68]。Moser 等人涵蓋 SR 所用擴散模型的理論及其開放問題，例如運算量與色偏 [41]。這幾篇綜述合起來，指向本篇討論過的開放問題：真實的退化、忠實的生成，以及評估。

*選讀：[論文導讀](#論文導讀)（見「論文導讀」頁）。四篇綜述在那裡各有一篇簡短的閱讀指南。*

### 2023–2026 年的最新進展

1. **以保真度為導向的 SR** 使用以大量資料訓練的注意力與狀態空間骨幹（HAT、DAT、MambaIR [33], [34], [35]），每年由 NTIRE ×4 復原賽道評比 [55], [56]。
2. **真實世界 SR 轉向預訓練的擴散先驗**（例如 StableSR [38]），現在主要的工程努力在速度：從數百步降到 15 步（ResShift [39]），再降到一步（OSEDiff [40]）。
3. **評估方式正在追上生成能力**：分開的保真度賽道與感知賽道 [56]，以及直接量測幻覺的初步嘗試 [67]。
4. **效率**有自己的基準，並設有固定的品質門檻 [51], [52]。

### 尚未解決的問題

- **忠實的生成式 SR。** 如何得到擴散模型等級的真實感而不捏造內容，以及如何讓使用者看出哪些細節是量測到的、哪些是猜的。
- **評估。** PSNR 獎勵模糊，無參考指標可以被刻意迎合，幻覺指標才剛出現。對沒有真值的真實影像，還沒有公認的評估協定。
- **真實的退化。** 合成流程仍然漏掉相機的影像處理流程與隨位置變化的模糊；實拍資料集規模小，而且只適用於特定相機。
- **成本。** 一步式擴散仍比高效率 SR 挑戰賽中的網路重得多，影片還多了時間一致性的問題。
- **任意倍率與極端倍率。** 遠超出訓練倍率時的行為，以及在幾乎一切都是生成出來的倍率下的行為，目前都還了解不多。

## 重點整理

- SR 是病態問題：在 ×4 時，每個 LR 像素只限制了 16 個 HR 值的一個組合，其餘由先驗決定。像素損失給出**後驗平均**，它本質上就是模糊的；後驗樣本看起來真實，MSE 至多是兩倍。
- **退化模型**定義了任務。雙三次基準乾淨但不真實；模糊不匹配會讓模型銳化不足或過度銳化，那個小小的線性迴歸器就展示了這一點。
- 混疊把高於 $1/(2s)$ 的頻率摺進 LR 影像；模糊則把它們移除。實務上的 SR 大多是在 LR 奈奎斯特極限以下去模糊，再加上極限以上由先驗驅動的猜測。
- 現代網路在最後以 **pixel shuffle** 上取樣：$X[c, sh + i, sw + j] = T[cs^2 + si + j, h, w]$，這是一個精確的排列，也有精確的反運算（space-to-depth）。
- 殘差學習、不用批次正規化、殘差縮放與注意力（EDSR、RCAN、SwinIR、HAT）推升保真度；感知、對抗與擴散方法（SRGAN、ESRGAN、SR3、StableSR）推升真實感。**感知–失真權衡**告訴你必須做出選擇。
- 在 Y 通道上、裁去邊界後評估，寫明協定，使用標準測試集；生成式模型還要加上感知指標與使用者研究。
- 留意捏造的文字與人臉、紋理瑕疵、色偏、過度平滑與分塊接縫；檢查輸出與 LR 輸入是否一致。

<details>
<summary>提示</summary>

(a) $y = 0$ 與 $y = 1$ 完全確定了 $(a, b)$。當 $y = 0.5$（機率 1/2）時，後驗是 $(0, 1)$ 或 $(1, 0)$，機率相等，所以平均為 $(0.5, 0.5)$，樣本則是兩者之一。(b) 只有 $y = 0.5$ 有貢獻。平均在那裡每個像素的平方誤差為 $0.25$，所以它的 MSE 是 $0.5 \times 0.25 = 0.125$。樣本有一半的時間完全正確，另一半的時間兩個像素都錯 1，所以它的 MSE 是 $0.5 \times 0.5 \times 1 = 0.25$：剛好兩倍。(c) 只有樣本：真實像素是 0 或 1，0.5 這個值從不出現在 HR 資料中。

## 補充資料

這些補充資料是選讀的背景知識，正文與練習都不依賴它們。

### 以範例為基礎的 SR 與稀疏編碼細節

**白話版。** 傳統的範例式方法保存一個（模糊小區塊, 清晰區塊）配對的資料庫。稀疏編碼把這個資料庫壓縮成兩本互相對應的字典，於是每個模糊區塊都用少數幾個「原子」描述，而清晰字典中同樣那幾個原子，就畫出清晰的區塊。

Freeman、Jones 與 Pasztor 為新影像的每個 LR 區塊挑選一個 HR 訓練區塊，它既要與該 LR 區塊相符，也要與相鄰的區塊相容 [9]。Glasner、Bagon 與 Irani 觀察到區塊會在同一張影像的尺度內與尺度間重複出現，所以 LR 影像與它的縮小版本就能提供 LR–HR 範例，不需要外部資料 [10]；Huang、Singh 與 Ahuja 用透視與仿射轉換擴大了這種內部搜尋，對城市場景特別有幫助 [61]。零樣本 SR（Zero-Shot SR, ZSSR）把這種內部學習的想法帶進深度學習：它在測試時，只用從輸入影像本身擷取的範例，訓練一個專屬於這張影像的小型 CNN [69]。

Yang 等人學習一本 LR 字典 $D_\ell$ 與一本 HR 字典 $D_h$，兩者的行是成對的原子 [11]。對一個 LR 區塊特徵 $p_\ell$，他們求解

$$
\min_{\alpha} \; \bigl\| D_\ell\, \alpha - p_\ell \bigr\|_2^2 + \lambda \|\alpha\|_1,
\qquad \hat p_h = D_h\, \alpha,
$$

其中 $\alpha$ 是稀疏碼，$\|\alpha\|_1$ 鼓勵非零係數越少越好，$\lambda > 0$ 設定稀疏程度，$\hat p_h$ 是 HR 區塊的估計；重疊的區塊會取平均。Zeyde、Elad 與 Protter 簡化並加速了這條流程 [59]，錨定迴歸（ANR、A+）則以預先算好的嶺迴歸器取代稀疏編碼步驟 [13], [14]，也就是正文程式所用的模型。

### 三個利用模糊核的方法

**白話版。** 這些方法要嘛告訴網路模糊是什麼，要嘛從影像本身推算出模糊。

- **SRMD** 把模糊核（縮減成一個短向量）與雜訊強度交給同一個網路：把它們延展成與 LR 影像同尺寸的圖，再與影像串接，所以只要有人提供退化參數，一個模型就能處理許多種退化 [70]。
- **IKC** 從一個猜測的模糊核出發，分幾輪修正它，依據的是錯誤模糊核產生的瑕疵（太寬會過度銳化，太窄會過度平滑）[71]。
- **KernelGAN** 在單一測試影像上訓練一個小型 GAN：它的生成器學習把影像縮小，使結果的區塊與原圖的區塊無法區分，學到的縮小器就是模糊核的估計 [72]。

### LIIF 的三項改良

**白話版。** LIIF 為每個查詢點找出最近的已存特徵。三個小小的增補讓這個查找更豐富、更平滑，也知道輸出像素有多大。

在正文的 LIIF 公式中，**特徵展開**（feature unfolding）把每個潛在碼周圍 $3 \times 3$ 的鄰域串接成一個向量，讓每個碼描述一小塊區域。**局部集成**（local ensemble）用 $x_q$ 周圍的四個潛在碼分別評估 MLP，再以面積權重混合這四個預測，這樣最近的碼 $z^{*}$ 改變時，輸出才不會跳動。**像素格解碼**（cell decoding）還把正在算繪的輸出像素的高與寬交給 MLP，讓它知道自己預測的是細緻還是粗略的取樣 [47]。

### 為什麼後驗樣本的誤差是 MMSE 的兩倍

**白話版。** 後驗平均正好位於所有合理答案的中心。真實影像是那團雲中的一個隨機點，後驗樣本則是同一團雲中另一個獨立的隨機點。兩個隨機點之間的平均（平方）距離，是一個隨機點到中心距離的兩倍。

**精確版。** 設 $X$ 為 HR 影像，$Y$ 為 LR 觀測，$\mu(Y) = \mathbb E[X \mid Y]$ 為後驗平均，$\hat X$ 是在給定 $Y$ 下與 $X$ 獨立、從 $p(x \mid Y)$ 抽出的樣本。那麼在以 $Y$ 為條件下，

$$
\begin{aligned}
\mathbb E\bigl[\|X - \hat X\|^2 \mid Y\bigr]
&= \mathbb E\bigl[\|(X - \mu) - (\hat X - \mu)\|^2 \mid Y\bigr] \\
&= \mathbb E\bigl[\|X - \mu\|^2 \mid Y\bigr] + \mathbb E\bigl[\|\hat X - \mu\|^2 \mid Y\bigr] - 2\,\mathbb E\bigl[(X - \mu)^{\top}(\hat X - \mu) \mid Y\bigr] \\
&= 2\,\mathbb E\bigl[\|X - \mu\|^2 \mid Y\bigr],
\end{aligned}
$$

其中 $\|\cdot\|$ 是對所有像素的歐氏範數。第二行把平方展開。第三行中，兩個平方項相等，因為 $X$ 與 $\hat X$ 有相同的條件分布；交叉項為零，因為在給定 $Y$ 下兩者獨立，且平均都是 $\mu$。再對 $Y$ 取期望，得到 $\mathbb E\|X - \hat X\|^2 = 2\,\mathbb E\|X - \mu(Y)\|^2$：取樣器的 MSE 剛好是最小 MSE 的兩倍，也就是 PSNR 差 3 dB。它的輸出分布等於真實影像的分布，所以感知品質是完美的。Blau 與 Michaeli 用這個構造證明，完美的感知品質付出的 MSE 代價永遠不超過 2 倍 [2]。

同樣的代數也給出圖 1 的曲線。對於混合 $X_\alpha = \mu + \alpha(\hat X - \mu)$，$0 \le \alpha \le 1$，

$$
\mathbb E\|X - X_\alpha\|^2 = (1 + \alpha^2)\, \mathbb E\|X - \mu\|^2,
$$

其中交叉項基於同樣的理由為零。失真從 $\alpha = 0$ 時的 MMSE 值平滑地增加到 $\alpha = 1$ 時的兩倍，而混合的輸出則從模糊的後驗平均移向真實的樣本。在我們的小例子中，量到的 MSE 從 0.0072 增加到 0.0143。

```python
import numpy as np

rng = np.random.default_rng(1)
mu = rng.standard_normal((100000, 1))                  # posterior means for many observations y
X = mu + rng.standard_normal(mu.shape)                 # the truth: one draw from p(x | y) = N(mu, 1)
X_hat = mu + rng.standard_normal(mu.shape)             # an independent posterior sample
for a in (0.0, 0.5, 1.0):
    print(f"alpha {a:.1f}: MSE {np.mean((X - (mu + a * (X_hat - mu))) ** 2):.3f}  (theory {1 + a * a:.3f})")
```

```text
alpha 0.0: MSE 1.002  (theory 1.000)
alpha 0.5: MSE 1.250  (theory 1.250)
alpha 1.0: MSE 1.996  (theory 2.000)
```

## 論文導讀

這些導讀是選讀內容：每篇帶你讀一篇本篇依據的論文——它要解決的問題、核心想法、它呈現了什麼，以及閱讀時該檢查什麼。

### Wang、Chen 與 Hoi：Deep Learning for Image Super-Resolution（TPAMI 2021）

**要解決的問題。** 到了 2019 年，深度 SR 的論文已經很多，每篇都在上取樣、架構、損失函數與訓練上做了一組選擇，很難看出哪個選擇才是關鍵 [4]。

**核心想法。** 把這個領域分成監督式 SR、非監督式 SR 與特定領域 SR（人臉、高光譜影像、影片等），再把監督式模型拆成幾個獨立的軸：上取樣在哪裡發生（先、後、漸進、迭代上下取樣）、由哪種運算執行、網路如何設計（殘差、遞迴、密集、注意力等），以及使用哪些損失函數與訓練策略。

**它呈現了什麼。** 大多數已發表的模型，都是沿著這些軸所做選擇的組合；這篇綜述也把標準資料集整理成表（本篇測試集表中的影像數就來自它），並指出訓練或評估時所用的色彩空間，可能讓結果差到 4 dB。

**閱讀時要檢查什麼。** 它的比較早於 Transformer 與擴散模型。把這些軸當作描述任何新模型的詞彙來讀，並把未來方向一節（網路設計、學習策略、評估指標、非監督式 SR、真實世界情境）當作這個領域後來投入的問題清單來讀。

### Liu 等人：Blind Image Super-Resolution, a Survey and Beyond（TPAMI 2022）

**要解決的問題。** 為一種已知退化訓練的模型，遇到退化未知的影像就會失效，而各種盲 SR 方法所用的假設又互不相容 [44]。

**核心想法。** 沿著兩個軸為方法分類：明確建模（傳統的模糊核加雜訊模型，由估計或給定）對隱式建模（從資料分布學到的退化），以及外部訓練資料對單一輸入影像（內部統計，如 KernelGAN 與 ZSSR）。

**它呈現了什麼。** 這套分類把看似相近、實際假設卻不同的方法區分開來；它的比較涵蓋合成與真實影像，也整理了盲 SR 的資料集與過去的挑戰賽。

**閱讀時要檢查什麼。** 對每個方法，問它到底能表示哪些退化。一個在高斯核上表現優異的方法，可能根本無法建模 JPEG 或相機的影像處理。

### Chen 等人：Real-World Single Image Super-Resolution, a Brief Review（Information Fusion 2022）

**要解決的問題。** 合成資料上的結果，高估了方法對真實影像做超解析度的能力 [68]。

**核心想法。** 回顧真實世界 SR 的資料集與指標，並把方法分成四個家族：以退化建模為基礎、以影像配對為基礎（例如 RealSR 這類實拍資料）、以領域轉換為基礎（學習真實與合成領域之間的映射），以及以自學習為基礎（利用測試影像本身）。

**它呈現了什麼。** 一張精簡的真實世界 SR 地圖，並附上基準資料上的比較。

**閱讀時要檢查什麼。** 看每個比較用了哪些指標。在沒有真值的真實影像上，只能用無參考指標，而不同的指標可能給出不同的排名。

### Moser 等人：Diffusion Models, Image Super-Resolution, and Everything（TNNLS 2025）

**要解決的問題。** 擴散模型迅速改變了 SR，相關文獻龐大，不容易入門 [41]。

**核心想法。** 先說明擴散模型的理論，再依輸入領域（像素、潛在、小波）、條件方式、引導、損壞空間（corruption spaces），以及預訓練模型的零樣本使用來整理 SR 方法，並有一節談特定領域的應用。

**它呈現了什麼。** 擴散模型給出最逼真的 SR，但這篇綜述列出了具體的待解問題：運算量高、論文使用不同的資料與指標以致難以比較、可解釋性有限，以及色偏。

**閱讀時要檢查什麼。** 比較兩篇擴散 SR 論文時，先檢查取樣步數、測試資料與指標，再比較數字；這篇綜述中討論可比較性的一節解釋了它們為什麼會不同。
