## 先看全貌

影像分類對整張影像只問一個問題：*這些標籤裡，哪一個最符合？* 它是最早的深度學習基準任務，到今天仍是大多數骨幹網路誕生的地方。物體偵測、分割或影像復原網路，通常都從一個先以影像分類訓練、或至少以影像分類評估過的骨幹網路出發。

<Callout type="tip" title="用最簡單的話說">
想像一個小朋友看著圖畫書學認動物。一開始他只看到一團一團的顏色。翻過很多頁之後，他學會先注意耳朵，再注意臉，最後說出「這是貓」。深度分類器也是一層一層這樣做：前面的層注意邊緣和顏色，中間的層注意眼睛、輪子這類零件，最後一層投票選出標籤。訓練就是爸媽在旁邊說了幾千次「不對，那是狗」。這篇教學其餘的部分在講：怎麼做一本更好的圖畫書（資料）、一顆更好的腦袋（架構）、一套更好的教法（訓練配方），以及更好的考試（評估）。因為一個只看過「貓坐在沙發上」的小朋友，可能會以為「沙發」就代表「貓」。
</Callout>

## 分類問題的定義

**白話版。** 網路看一張影像，對每個類別輸出一個分數。我們把分數轉成機率，與真正的標籤比較，再輕輕推動網路，讓正確類別下一次得到更高的機率。

### 單標籤、多標籤與細粒度

令 $\mathbf{x} \in \mathbb{R}^{H \times W \times 3}$ 為一張 RGB 影像，$\mathcal{Y} = \{1, \dots, K\}$ 為 $K$ 個類別的集合。參數為 $\theta$ 的網路 $f_\theta$ 把影像映射到一個 **logits** 向量 $\mathbf{z} = f_\theta(\mathbf{x}) \in \mathbb{R}^K$，每個類別一個未正規化的分數。

- **單標籤（多類別）**分類假設恰好有一個正確類別 $y \in \mathcal{Y}$。以 softmax 把 logits 轉成機率向量：

$$
p_k = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}, \qquad k = 1, \dots, K,
$$

其中 $p_k$ 是模型對 $P(y = k \mid \mathbf{x})$ 的估計。訓練時最小化**交叉熵**，也就是正確類別機率的負對數，在一個小批次上取平均：

$$
\mathcal{L}_{\text{CE}} = -\frac{1}{B}\sum_{i=1}^{B} \log p_{y_i}(\mathbf{x}_i),
$$

其中 $B$ 是批次大小，$y_i$ 是影像 $\mathbf{x}_i$ 的標籤。它對 logits 的梯度（每張影像）是 $\partial \mathcal{L}/\partial \mathbf{z} = \mathbf{p} - \mathbf{e}_y$，$\mathbf{e}_y$ 是正確類別的 one-hot 向量；推導見 DIP 第 13 章。

- **多標籤**分類允許任意個標籤同時成立（一張街景可能同時有「汽車」、「行人」、「腳踏車」）。每個類別各自接一個 sigmoid $\sigma(z_k) = 1/(1 + e^{-z_k})$ 與二元交叉熵 $-\sum_k [t_k \log \sigma(z_k) + (1 - t_k)\log(1 - \sigma(z_k))]$，其中 $t_k \in \{0, 1\}$ 表示類別 $k$ 是否出現。評估指標也要換：以各類別的平均精確度（mean average precision）取代準確率。

- **細粒度**分類要分開外觀非常相近的子類別，例如 200 種鳥或 1,000 種飛機型號。損失函數與單標籤相同，但訊號藏在小地方（鳥喙形狀、翅膀上的條紋），類別通常呈長尾分佈，而且非專家標註者造成的標籤雜訊很常見。iNaturalist [6] 是標準的大型細粒度基準。

### 評估指標：top-1、top-5 與其他

**Top-1 準確率**是最高分類別恰好正確的影像比例。**Top-$k$ 準確率**則只要正確類別落在前 $k$ 高分之中就算對。ImageNet 挑戰賽回報 top-5 錯誤率，因為很多影像裡有好幾個物體，而有些類別幾乎無法區分 [2]。但 top-5 會掩蓋真正的錯誤，所以現代論文大多回報 top-1。資料不平衡時，請回報**平衡準確率**（各類別召回率的平均）或逐類別結果，因為分類器只要忽略稀有類別，也能拿到很高的準確率。

```python
import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 1.0, 0.1, -1.0],    # 2 images, 4 classes
                       [0.5, 2.5, 2.4, 0.0]])
y = torch.tensor([0, 2])

p = logits.softmax(dim=1)
ce = F.cross_entropy(logits, y)                       # mean of -log p[i, y_i]
ce_ls = F.cross_entropy(logits, y, label_smoothing=0.1)
top1 = (logits.argmax(1) == y).float().mean()
top2 = (logits.topk(2, dim=1).indices == y[:, None]).any(1).float().mean()
print(p.round(decimals=3))
print(f"CE {ce:.3f}  CE+LS {ce_ls:.3f}  top-1 {top1:.2f}  top-2 {top2:.2f}")

# multi-label: one independent sigmoid per class, binary cross-entropy
targets = torch.tensor([[1., 0., 1., 0.], [0., 1., 1., 0.]])
print(f"BCE {F.binary_cross_entropy_with_logits(logits, targets):.3f}")
```

第二張影像在類別 1 和 2 之間幾乎平手。Top-1 算它錯，top-2 算它對。支持與反對 top-5 的理由，都在這一個例子裡。

### 混淆矩陣與由它衍生的指標

**白話版。** 準確率把所有錯誤壓成一個數字。混淆矩陣（confusion matrix）則把錯誤分開來記：對每一個真實類別，數一數模型分別回答了什麼。幾乎所有其他分類指標，都是這張表裡某些格子的比值，而每一種比值回答的是不同的問題。

#### 二元情況：TP、FP、FN、TN

把某一類當作**陽性**（positive，例如「生病」），其餘當作**陰性**（negative）。每一個預測都會落在四個格子之一：

| | 預測為陽性 | 預測為陰性 |
| --- | --- | --- |
| **實際為陽性** | 真陽性（true positive, TP） | 偽陰性（false negative, FN） |
| **實際為陰性** | 偽陽性（false positive, FP） | 真陰性（true negative, TN） |

<Callout type="tip" title="用最簡單的話說">
煙霧警報器就是一個分類器。真的失火、它響了，是真陽性。你只是把吐司烤焦、它也響了，是偽陽性：很吵，但沒有人受傷。真的失火、它卻沒響，是偽陰性：這才是危險的那一種。什麼事都沒有、它也安靜，是真陰性。好的警報器不只是「大部分時間都對」（它幾乎每天都安靜，要做到這點太容易了），而是要在失火時響、在烤吐司時安靜。不同的指標，對這兩個目標的看重程度不一樣。
</Callout>

設測試樣本共 $N = \text{TP} + \text{FP} + \text{FN} + \text{TN}$ 個，標準的比值為

$$
\begin{aligned}
\text{accuracy} &= \frac{\text{TP} + \text{TN}}{N}, &
\text{precision} &= \frac{\text{TP}}{\text{TP} + \text{FP}}, &
\text{recall (TPR)} &= \frac{\text{TP}}{\text{TP} + \text{FN}}, \\[4pt]
\text{specificity (TNR)} &= \frac{\text{TN}}{\text{TN} + \text{FP}}, &
\text{FPR} &= \frac{\text{FP}}{\text{FP} + \text{TN}} = 1 - \text{TNR}. &&
\end{aligned}
$$

- **精確率（precision）**回答「模型說是陽性的時候，有多常是對的？」當誤報代價很高時它最重要：會把正常信件藏起來的垃圾郵件過濾器、自動觸發的產品召回。
- **召回率（recall）**，又稱**敏感度**（sensitivity）或**真陽性率**（true positive rate, TPR），回答「所有真正的陽性中，我們抓到了多少？」當漏抓代價很高時它最重要：癌症篩檢、產線上的瑕疵偵測。
- **特異度**（specificity），即**真陰性率**（true negative rate, TNR），是陰性類別的召回率。**偽陽性率**（false positive rate, FPR）是它的補數，也就是被錯誤標記的陰性樣本比例。

精確率與召回率互相拉扯：降低決策門檻會標記更多樣本，召回率上升，精確率通常下降。把兩者合成一個數字的指標是：

$$
F_1 = \frac{2\,\text{P}\,\text{R}}{\text{P} + \text{R}} = \frac{2\,\text{TP}}{2\,\text{TP} + \text{FP} + \text{FN}}, \qquad
F_\beta = \frac{(1 + \beta^2)\,\text{P}\,\text{R}}{\beta^2\,\text{P} + \text{R}},
$$

其中 $\text{P}$ 是精確率，$\text{R}$ 是召回率，$\beta > 0$ 表示召回率比精確率重要幾倍（$F_2$ 偏重召回率，$F_{0.5}$ 偏重精確率）。$F_1$ 是調和平均，所以只有*兩者*都高時它才會高。也請注意 $F_1$ 忽略了什麼：真陰性完全沒有出現在式子裡。

另外兩個總結指標用到了全部四格：

$$
\text{balanced accuracy} = \frac{\text{TPR} + \text{TNR}}{2}, \qquad
\text{MCC} = \frac{\text{TP}\cdot\text{TN} - \text{FP}\cdot\text{FN}}{\sqrt{(\text{TP}+\text{FP})(\text{TP}+\text{FN})(\text{TN}+\text{FP})(\text{TN}+\text{FN})}} .
$$

**平衡準確率**（balanced accuracy）是各類別召回率的平均，所以一個忽略某一類的分類器，不論那一類多稀有，都只能拿到 0.5。**Matthews 相關係數**（Matthews correlation coefficient, MCC）是真實與預測二元標籤之間的 Pearson 相關係數：$+1$ 表示完美，$0$ 表示不比隨機好，$-1$ 表示完全相反。Chicco 與 Jurman [57] 主張在二元評估中應優先使用 MCC，而不是準確率與 $F_1$，因為只有分類器在四個格子上都表現好時，它才會高。Sokolova 與 Lapalme [58] 系統性地比較了這些指標，以及它們各自如何隨混淆矩陣的變化而反應。

**為什麼 99:1 時準確率會誤導。** 假設 1,000 張掃描影像中有 10 張是生病的。一個永遠回答*健康*的「模型」可以拿到 99.0% 的準確率。模型 B 標記了 30 張，抓到 10 張中的 8 張；它的準確率*較低*（97.6%），卻是唯一有用的那一個：

```python
import numpy as np
from sklearn.metrics import (accuracy_score, balanced_accuracy_score, confusion_matrix,
                             f1_score, matthews_corrcoef, precision_score, recall_score)

# 1,000 scans, 10 sick (label 1). Model A says "healthy" to everyone.
# Model B flags 30 scans and catches 8 of the 10 sick ones.
y = np.r_[np.ones(10), np.zeros(990)].astype(int)
pred_a = np.zeros(1000, dtype=int)
pred_b = np.r_[np.ones(8), np.zeros(2), np.ones(22), np.zeros(968)].astype(int)

for name, p in [("all-negative", pred_a), ("model B", pred_b)]:
    tn, fp, fn, tp = confusion_matrix(y, p).ravel()
    print(f"{name:12s} TP={tp} FP={fp} FN={fn} TN={tn}  "
          f"acc={accuracy_score(y, p):.3f} bal-acc={balanced_accuracy_score(y, p):.3f} "
          f"P={precision_score(y, p, zero_division=0):.3f} R={recall_score(y, p):.3f} "
          f"F1={f1_score(y, p, zero_division=0):.3f} MCC={matthews_corrcoef(y, p):.3f}")
# all-negative TP=0 FP=0 FN=10 TN=990  acc=0.990 bal-acc=0.500 P=0.000 R=0.000 F1=0.000 MCC=0.000
# model B      TP=8 FP=22 FN=2 TN=968  acc=0.976 bal-acc=0.889 P=0.267 R=0.800 F1=0.400 MCC=0.454
```

平衡準確率、$F_1$ 與 MCC 都把模型 B 排在第一；準確率卻把它排在最後。經驗法則：只有在類別大致平衡、所有錯誤代價相同時才用準確率；當某一種錯誤比較嚴重時，回報精確率與召回率（或依實際代價選定 $\beta$ 的 $F_\beta$）；需要一個能反映不平衡的單一總結數字時，用平衡準確率或 MCC。

#### 多類別混淆矩陣

有 $K$ 個類別時，混淆矩陣 $C \in \mathbb{N}^{K \times K}$ 的元素 $C_{ij}$ 是**真實**類別為 $i$（列）、**預測**類別為 $j$（行）的測試影像數；這是 scikit-learn [62] 的慣例。對角線是預測正確的數量。把每一列除以該列總和，得到**依列正規化**的矩陣：它的對角線就是各類別的召回率，非對角元素則顯示*哪些*類別被搞混。圖 1 是一個只用 scikit-learn $8 \times 8$ 手寫數字中 200 張訓練的邏輯迴歸所得到的結果：大部分錯誤是 3 → 8、4 → 1 與 7 → 9，都是筆畫相似的組合。

<Figure src={cmFig} alt="數字 0 到 9 的 10×10 熱圖，列為真實類別、行為預測類別，對角線介於 0.85 與 1.00 之間，最大的非對角格是真實 3 預測 8（0.08）、真實 4 預測 1（0.07）與真實 7 預測 9（0.06）" caption="圖 1 — 以 200 張數字訓練、在 899 張上測試的邏輯迴歸之依列正規化混淆矩陣（準確率 91.1%）。每一列總和為 1；對角線是各類別的召回率，較亮的非對角格指出值得修正的混淆。" />

輪流把每個類別 $k$ 當作「陽性」、其他類別當作「陰性」，就得到逐類別的計數：$\text{TP}_k = C_{kk}$，$\text{FP}_k = \sum_{i \neq k} C_{ik}$（第 $k$ 行的其餘部分），$\text{FN}_k = \sum_{j \neq k} C_{kj}$（第 $k$ 列的其餘部分）。因此逐類別精確率 $\text{P}_k = C_{kk} / \sum_i C_{ik}$，召回率 $\text{R}_k = C_{kk} / \sum_j C_{kj}$。把 $K$ 個逐類別數字合成一個，常見的有三種做法：

- **巨觀平均**（macro average）：對類別直接取平均，$\text{F}_1^{\text{macro}} = \tfrac{1}{K}\sum_k \text{F}_{1,k}$。每個類別權重相同，所以稀有類別和常見類別一樣重要。
- **微觀平均**（micro average）：先把各類別的 $\text{TP}_k$、$\text{FP}_k$、$\text{FN}_k$ 加總，再算一次指標。在單標籤多類別問題中，每一個錯誤都同時是一個 FP（對預測的類別）和一個 FN（對真實的類別），所以微觀精確率 = 微觀召回率 = 微觀 $F_1$ = 準確率。
- **加權平均**（weighted average）：以各類別的**支持數**（support）$n_k$（真實樣本數）為權重，對逐類別數值取平均。它很接近微觀平均，幾乎一樣會掩蓋稀有類別的失敗。

在不平衡的測試集上，幾種平均可能差很多。如果模型在常見類別上很好、在稀有類別上很差，微觀平均（被常見類別主導）會給出高分，巨觀平均則低得多；這個差距本身就是訊號。當每個類別都重要時（罕見疾病、稀有物種）回報巨觀平均；當每一張*影像*同等重要時，回報微觀平均／準確率。

*選讀：[巨觀與微觀平均的計算實例](#巨觀與微觀平均的計算實例)（見「補充資料」頁）。用一個小型三類別混淆矩陣一步步手算。*

**Cohen's kappa** [59] 是扣除巧合後的準確率：它把預測與標籤之間觀察到的一致程度，和一個只依觀察到的比例隨機猜各類別的分類器所能達到的一致程度相比。完全一致時為 1，與隨機相當時為 0；在比較模型與人類標註者時很常見。

*選讀：[Cohen's kappa：扣除巧合的一致性](#cohens-kappa扣除巧合的一致性)（見「補充資料」頁）。公式，以及它在下方手寫數字分類器上的數值。*

```python
from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import (average_precision_score, classification_report,
                             confusion_matrix, precision_recall_fscore_support, roc_auc_score)
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import label_binarize

X, y = load_digits(return_X_y=True)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.5, stratify=y, random_state=0)
clf = LogisticRegression(max_iter=2000).fit(X_tr[:200], y_tr[:200])   # only 200 labels
pred, prob = clf.predict(X_te), clf.predict_proba(X_te)

cm = confusion_matrix(y_te, pred)                     # rows = true, columns = predicted
cm_norm = confusion_matrix(y_te, pred, normalize="true")   # each row sums to 1 (Figure 1)
print(classification_report(y_te, pred, digits=3))    # per-class P, R, F1, support + averages
for avg in ["macro", "micro", "weighted"]:
    p, r, f, _ = precision_recall_fscore_support(y_te, pred, average=avg)
    print(f"{avg:8s} P={p:.3f} R={r:.3f} F1={f:.3f}")
print(f"ROC-AUC (one-vs-rest, macro) {roc_auc_score(y_te, prob, multi_class='ovr'):.4f}")
Y = label_binarize(y_te, classes=range(10))           # one binary column per class
print(f"mean AP over classes {average_precision_score(Y, prob, average='macro'):.4f}")
# macro    P=0.914 R=0.911 F1=0.912
# micro    P=0.911 R=0.911 F1=0.911
# weighted P=0.915 R=0.911 F1=0.912
# ROC-AUC (one-vs-rest, macro) 0.9958
# mean AP over classes 0.9742
```

這裡巨觀與微觀平均幾乎相同，因為手寫數字的各類別是平衡的；換成不平衡的測試集就不會如此。

#### 不依賴門檻的評估：ROC 曲線與精確率–召回率曲線

上面每一個指標都需要一條決策規則（argmax，或「分數超過 $t$ 就是陽性」）。會輸出分數的分類器，可以一次在*所有*門檻上評估：把 $t$ 從高掃到低，每個門檻記下一個點。

- **ROC 曲線**畫的是 TPR 對 FPR。曲線下面積 **ROC-AUC** 等於「隨機取一個陽性樣本，它的分數高於隨機取的一個陰性樣本」的機率；0.5 是隨機，1.0 是完美分開。Fawcett [54] 是標準的入門文獻。
- **精確率–召回率（PR）曲線**畫的是精確率對召回率。它的總結指標**平均精確度**（average precision, AP），是在每次多找回一個陽性樣本的召回率位置上，對精確率取平均：

$$
\text{AP} = \sum_{n} (\text{R}_n - \text{R}_{n-1})\,\text{P}_n ,
$$

其中 $\text{P}_n$ 與 $\text{R}_n$ 是依分數由高到低排序後、第 $n$ 個門檻的精確率與召回率（這是 scikit-learn [62] 的定義；PASCAL VOC [61] 等基準用過內插的變體，所以要確認論文回報的是哪一種）。

**為什麼嚴重不平衡時要看 PR。** FPR 的分母是陰性樣本數。當陰性樣本是陽性的 99 倍時，即使有上千個誤報，FPR 也幾乎不動，所以 ROC 曲線看起來很漂亮，精確率卻很差。精確率的分母是*被標記*的樣本數，誤報會直接打擊它，而 AP 的隨機基準線等於陽性比例，而不是 0.5。Davis 與 Goadrich [55] 證明：一條曲線在 ROC 空間中占優勢，若且唯若它在 PR 空間中也占優勢；並指出最佳化 ROC-AUC 並不等於最佳化 AP。Saito 與 Rehmsmeier [56] 以模擬與文獻回顧顯示，在不平衡資料上，PR 圖比 ROC 圖更有資訊量。圖 2 把這件事具體化：在陽性只占 1% 的任務上，兩個 ROC-AUC 相同（0.95）的分類器，AP 卻明顯不同（0.45 對 0.36）。

<Figure src={rocPr} alt="左圖：邏輯迴歸與高斯單純貝氏兩條幾乎重合的 ROC 曲線，AUC 皆為 0.95，遠高於對角線。右圖：兩者的精確率–召回率曲線明顯分開，AP 分別為 0.45 與 0.36，都遠高於精確率 0.01 的隨機基準線" caption="圖 2 — 在陽性只占 1% 的合成任務上（10,000 個測試點中有 100 個陽性），兩個分類器的 ROC 曲線（左）與精確率–召回率曲線（右）。兩者 ROC-AUC 都是 0.95，但邏輯迴歸在每個召回率下的精確率都高得多（AP 0.45 對 0.36）。在這個任務上，一個全部判為陰性的分類器可以拿到 99% 的準確率。" />

當類別數 $K > 2$ 時，兩種曲線都以**一對其餘**（one-vs-rest）的方式計算：類別 $k$ 為陽性、其他全部為陰性，使用分數 $p_k$。再把 $K$ 個面積做巨觀平均（`roc_auc_score(..., multi_class="ovr")`），或把所有（類別, 影像）配對合併後做微觀平均。

#### 多標籤指標

在多標籤分類中，每個標籤都是自己的一個「有／沒有」問題，所以標準的總結指標是**逐類別的平均精確度**，再對類別平均成 **mAP**，就像 PASCAL VOC 分類任務 [61] 的做法。需要門檻的指標，要嘛對每個標籤算二元指標再對標籤平均（巨觀或微觀，如上），要嘛對每張影像的預測標籤集合評分，再對影像取平均。

### 校準：機率說的是實話嗎？

準確率只檢查 argmax。**校準**（calibration）檢查信心值是否名副其實：在所有信心為 0.8 的預測中，應該大約有 80% 是對的。正式地說，若對每個信心值 $c$ 都有 $P(\hat{y} = y \mid \hat{p} = c) = c$，分類器就是校準良好的，其中 $\hat{y}$ 是預測類別，$\hat{p} = \max_k p_k$ 是它的機率。常用的總結指標是**期望校準誤差**（expected calibration error, ECE）：把預測依信心分到 $M$ 個區間 $B_m$，計算

$$
\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{n}\,\big|\operatorname{acc}(B_m) - \operatorname{conf}(B_m)\big|,
$$

其中 $n$ 是測試影像數，$\operatorname{acc}(B_m)$ 是第 $m$ 個區間內的準確率，$\operatorname{conf}(B_m)$ 是區間內的平均信心。Guo 等人 [47] 發現，用交叉熵長時間訓練的現代深度網路傾向**過度自信**，而只用一個純量就能修正得相當好。我們會在穩健性一節回來談。

## 資料集與它們的角色

**白話版。** 基準資料集是一份凍結的考卷。它讓大家能公平比較方法；但當整個領域都在準備同一份考卷，分數衡量的就不只是能力，也包括這份考卷本身。把兩種角色分開會比較清楚：用來*訓練*模型的資料集，以及只用來*評估*模型的資料集。

### 訓練用資料集

| 資料集 | 影像數 | 類別數 | 解析度 | 角色 |
| --- | --- | --- | --- | --- |
| MNIST [3] | 訓練 6 萬／測試 1 萬 | 10 個數字 | 28×28 灰階 | 健全性檢查、教學 |
| CIFAR-10 / CIFAR-100 [4] | 訓練 5 萬／測試 1 萬 | 10／100（20 個超類別） | 32×32 RGB | 小規模的架構與配方研究 |
| ImageNet-1k（ILSVRC 2012）[2] | 約 128 萬訓練／5 萬驗證 | 1,000 | 不固定，通常以 224×224 訓練 | 骨幹網路的標準基準 |
| ImageNet-21k [5] | 約 1,300–1,400 萬（版本不同） | 約 2.1 萬 | 不固定 | 更大規模的監督式預訓練 |
| iNaturalist [6] | 數十萬，依年份而異 | 數千個物種 | 不固定 | 細粒度、長尾 |

MNIST 已經被解決，現在只用來抓程式錯誤。CIFAR 小到可以跑大量受控實驗，所以正則化論文特別愛用。ImageNet-1k 在 2012 年挑戰賽之後成為參考標準 [2], [10]：架構通常以「ImageNet-1k 驗證集、224×224 的 top-1」來回報，模型庫裡幾乎每個預訓練骨幹都附有一個 ImageNet 分數。ImageNet-21k 是 ImageNet-1k 所取自的更大階層；Ridnik 等人 [5] 以清理過、考慮語意階層的配方，讓在它上面預訓練變得實際可行。

### 評估用基準資料集

**白話版。** 訓練資料負責教，評估資料負責考。只考過一份考卷的模型，可能只是學會了那份考卷。所以現代論文會用*一整組*測試集來評估骨幹網路，每一個都設計來探測一件事：原始分佈、從同一分佈重新抽的樣本、損壞或風格化的影像、不尋常的視角、細粒度類別、很少的標註預算，或稀有類別。

最常見的評估集可以分成五組：

- **分佈內。** ImageNet-1k 驗證集 [2] 是實質上的測試集；**ImageNet-ReaL** [8] 為同一批影像重新標註，允許一張影像有多個標籤。
- **重新抽樣。** **ImageNetV2** [7] 依原始收集流程重做一次，得到新的測試影像。
- **分佈偏移。** **ImageNet-C** [42] 加上合成損壞，**ImageNet-R** [43] 收錄藝術、卡通等各種表現形式，**ImageNet-A** [44] 收集會騙倒 ResNet-50 的自然照片，**ImageNet-Sketch** [63] 是素描，**ObjectNet** [64] 則呈現不尋常旋轉、背景與視角下的物體。
- **長尾與細粒度。** **ImageNet-LT** [73] 在長尾子集上訓練、在平衡資料上測試；iNaturalist [6]、CUB-200-2011 [65] 與 Stanford Cars [66] 測試細粒度辨識。
- **遷移。** Kornblith 等人 [33] 的 12 個資料集與 **VTAB** [72] 這類測試組，衡量凍結或微調後的特徵能多好地適應小型、專門的任務。

兩點實務提醒。好幾個細粒度基準回報的是**各類別平均準確率**，而不是一般的準確率，不要在同一個比較裡混用兩者。另外，CLIP [40] 這類影像–文字模型常以**零樣本**方式評估，完全不在目標資料上訓練：這時提示的寫法就成了超參數，不能在測試集上調整；而網路規模的預訓練資料也可能早已包含測試影像。

*選讀：[評估用基準資料集細說](#評估用基準資料集細說)（見「補充資料」頁）。各基準的大小、用途與常用指標、兩個遷移測試組，以及 CLIP 回報的零樣本結果。*

有三條研究路線改變了我們解讀 ImageNet 準確率的方式。照原始流程重建測試集（ImageNetV2 [7]）讓所有模型都掉分，但排名大致保持。重新標註的研究 [8], [9] 顯示，單一標籤與標籤錯誤都可能改變哪個模型看起來最好。而每個資料集在視角與背景上都有自己的偏差，所以只要可能，就用獨立收集的資料來測試。

### 評估流程

基準分數有多誠實，取決於背後的評估流程。

- **三種切分，三種任務。** 在**訓練集**上擬合參數。在**驗證集**上（或在訓練資料內做交叉驗證）選擇超參數、提前停止點、溫度、門檻與提示。**測試集**只在最後碰一次。若基準只公開驗證集（如 ImageNet-1k），就從訓練集中切出一部分用來調整。
- **絕不在測試集上調整。** 每一個看過測試結果之後才做的決定（多加一種擴增、多訓練一個 epoch、換一個檢查點），都會讓模型稍微擬合測試集。整個領域的論文累積起來，就是**測試集重複使用**（test-set reuse），也就是對基準的適應性過擬合。ImageNetV2 [7] 發現在新樣本上排名大致保持，這令人安心；但同一份研究也顯示絕對數字無法直接轉移，而新的測試集是唯一直接的檢驗方法。
- **回報變異。** 用多個隨機種子訓練（至少三個，小資料集要更多），回報平均 ± 標準差，或信賴區間。在 10,000 張測試影像上，ImageNetV2 [7] 給出的 95% 信賴區間約為 ±1%；在這樣的測試集上進步 0.3 個百分點，算不上結果。
- **回報完整配方。** 解析度、裁切數、額外資料、蒸餾、指標的哪一種變體（top-1 或各類別平均準確率、哪一種 AP 定義），以及標籤集的哪一個版本（原始或 ReaL）。

## CNN 架構與其背後的理由

**白話版。** 每一個著名的 CNN 都修正了前一代的某個具體問題：訓練太慢、參數太多、太深就難以最佳化、在手機上太昂貴。知道每個架構解決了什麼問題，比背它們的層表更有用。

### AlexNet：深度變得可訓練

2012 年以前，最好的 ImageNet 系統使用手工特徵（SIFT、Fisher 向量）加線性分類器。AlexNet [10] 是一個五層卷積、三層全連接的網路，在 ImageNet 上端到端訓練。讓它能在這個規模上成功的有三個要素。**ReLU** 激活函數 $\max(0, z)$ 對正輸入不會飽和，梯度不會像 tanh 那樣消失，論文回報訓練速度快了好幾倍。**Dropout** 用在大型全連接層上對抗過擬合，那些層占了大部分參數。**GPU** 讓這一切可行：模型被拆在兩張 GPU 上。大量的資料擴增（隨機裁切與翻轉、顏色擾動）是第四個、常被忘記的要素。設計上的教訓是：只要資料和算力足夠，學出來的特徵勝過設計出來的特徵。

### VGG：小卷積核，疊起來

VGG [11] 問了一個更乾淨的問題：如果只用 $3 \times 3$ 卷積，然後一直加深（16–19 個有權重的層），會怎樣？兩層 $3 \times 3$ 疊起來看到的是 $5 \times 5$ 區域，三層是 $7 \times 7$。對 $C$ 個輸入與輸出通道而言，

$$
\underbrace{2 \cdot 3^2 C^2}_{\text{two } 3\times 3} = 18C^2 \;\lt\; \underbrace{5^2 C^2}_{\text{one } 5\times 5} = 25C^2 ,
$$

（忽略偏差項）。所以同樣的感受野，疊層的參數更少，而且兩層之間多了一個非線性。VGG 的一致設計讓它多年來都是熱門的特徵擷取器。它的弱點是成本：全連接頭與寬大的前幾層讓它很笨重。

### GoogLeNet／Inception：寬度、分支與 $1 \times 1$ 瓶頸

GoogLeNet [12] 則改攻成本。每個 **Inception 模組**平行執行 $1 \times 1$、$3 \times 3$、$5 \times 5$ 卷積與池化，再把輸出串接起來，讓下一層自己挑選適合的尺度。在很多通道上跑大卷積核很昂貴，所以先用 **$1 \times 1$ 卷積**減少通道數。$1 \times 1$ 卷積就是在每個像素上做一次跨通道的線性映射：它混合通道而不看鄰居，是改變寬度最便宜的方法。GoogLeNet 也用**全域平均池化**取代龐大的全連接頭。後續的 Inception-v3 論文 [13] 把大卷積核分解成小卷積的堆疊，或 $1 \times n$ 與 $n \times 1$ 的組合，並提出了**標籤平滑**（label smoothing），我們會在訓練一節再見到它。

### ResNet：學習殘差

**問題。** 一直疊加普通的層，最後網路反而變*差*，連訓練集上都一樣。這種「退化」是最佳化問題，不是過擬合：更深的網路原則上可以複製較淺的網路，再把多出來的層設成恆等映射，但 SGD 就是找不到這個解。

**想法。** He 等人 [14] 讓一個區塊學習殘差 $\mathcal{F}$，再把輸入加回去：

$$
\mathbf{y} = \mathcal{F}(\mathbf{x}; \{W_i\}) + \mathbf{x},
$$

其中 $\mathbf{x}$ 是區塊輸入，$\mathcal{F}$ 是權重為 $W_i$ 的兩到三層卷積，$\mathbf{y}$ 是輸出。如果最佳映射接近恆等，區塊只需要把 $\mathcal{F}$ 推向零，這很容易。當形狀改變（通道變多、步幅為 2）時，捷徑改成 $1 \times 1$ 投影。

**為什麼好訓練。** 因為每個區塊都把輸入加回去，深層堆疊的輸出等於任何一個較早區塊的輸入，再加上一串殘差的總和。損失的梯度因此能沿著捷徑直接抵達每一個區塊，不會因為許多小因子連乘而消失。後續一篇論文 [15] 也發現，讓捷徑保持*純粹*的恆等（把 BN 與 ReLU 移進殘差分支，即「預激活」）能讓更深的網路更容易訓練。

*選讀：[殘差網路為什麼好訓練：展開後的梯度](#殘差網路為什麼好訓練展開後的梯度)（見「補充資料」頁）。這個論證背後的兩行推導。*

*選讀：[批次正規化](/zh-tw/learn/deep-learning/dl-01-deep-learning-for-image-processing/notes/#批次正規化在網路內部做標準化)（DLCV 01 的補充資料）。本頁處處用到的 BN 層在計算什麼，以及訓練與推論為何使用不同的統計量。*

**瓶頸結構。** 對更深的 ResNet（50 層以上），每個區塊變成 $1 \times 1$（降維）→ $3 \times 3$ → $1 \times 1$（升維），如圖 4(c)。在 256 通道時，兩層 $3 \times 3$ 的基本區塊有 $2 \cdot 9 \cdot 256^2 \approx 118$ 萬個權重；降到 64 通道的瓶頸區塊則有 $256 \cdot 64 + 9 \cdot 64^2 + 64 \cdot 256 \approx 7$ 萬個。昂貴的 $3 \times 3$ 跑在很薄的張量上，這正是 50–152 層負擔得起的原因。

<Figure src={blocks} alt="三種區塊示意圖：普通的兩層區塊；基本殘差區塊，在最後的 ReLU 前加上恆等捷徑；瓶頸區塊，依序為 1x1 降維、3x3、1x1 升維並帶有捷徑" caption="圖 4 — (a) 普通區塊必須學習完整的映射 H(x)。(b) 殘差區塊學習 F(x) = H(x) − x，再透過恆等捷徑把輸入加回去。(c) 瓶頸區塊在縮減後的寬度 d 上做 3×3 卷積，再升回 4d。" />

本篇實驗所用的基本區塊，以 PyTorch 寫成：

```python
import torch.nn as nn
import torch.nn.functional as F

class BasicBlock(nn.Module):
    def __init__(self, cin, cout, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(cin, cout, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(cout)
        self.conv2 = nn.Conv2d(cout, cout, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(cout)
        self.short = nn.Identity()
        if stride != 1 or cin != cout:   # projection shortcut when shapes change
            self.short = nn.Sequential(nn.Conv2d(cin, cout, 1, stride, bias=False), nn.BatchNorm2d(cout))

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + self.short(x))   # y = F(x) + x
```

之後有兩種 CNN 設計進一步發展了這些想法。**DenseNet** [16] 讓區塊內每一層接收*所有*前面各層輸出的串接，以很少的參數再利用特徵，代價是記憶體。**RegNet** [19] 研究的是一整群類 ResNet 網路，發現好的網路在「各階段寬度如何遞增」上遵循簡單的規則。

### MobileNet：把卷積拆開

MobileNet [17] 的目標是手機。在 $H \times W$ 的特徵圖上，從 $M$ 個通道到 $N$ 個通道的標準 $K \times K$ 卷積需要 $H W K^2 M N$ 次乘加。**深度可分離**（depthwise separable）卷積把它拆成兩步：**逐通道**（depthwise）$K \times K$ 卷積，每個通道各自濾波（$H W K^2 M$）；以及**逐點**（pointwise）$1 \times 1$ 卷積，負責混合通道（$H W M N$）。兩者的成本比為

$$
\frac{H W K^2 M + H W M N}{H W K^2 M N} = \frac{1}{N} + \frac{1}{K^2},
$$

所以當 $K = 3$、輸出通道很多時，可分離版本大約便宜 8–9 倍。它押注的是：空間濾波與通道混合不需要一起學。這個賭注押得很成功，深度卷積後來在 EfficientNet 與 ConvNeXt 中再次出現。

<Figure src={depthwise} alt="比較標準卷積與深度可分離卷積的示意圖：標準卷積有 N 個跨越全部 M 個輸入通道的卷積核；深度可分離卷積則是每個輸入通道一個 K×K 卷積核，再接 N 個 1×1 卷積核" caption="圖 5 — 標準卷積在同一步裡完成濾波與通道混合。深度可分離卷積先對每個通道各自濾波（depthwise），再用 1×1 卷積核混合通道（pointwise）。" />

```python
import torch.nn as nn

def n_params(m):
    return sum(p.numel() for p in m.parameters())

M, N, K = 128, 128, 3
standard = nn.Conv2d(M, N, K, padding=1, bias=False)
separable = nn.Sequential(nn.Conv2d(M, M, K, padding=1, groups=M, bias=False),   # depthwise
                          nn.Conv2d(M, N, 1, bias=False))                          # pointwise
print("standard:", n_params(standard), " separable:", n_params(separable),
      f" ratio {n_params(separable) / n_params(standard):.3f} vs 1/N + 1/K^2 = {1/N + 1/K**2:.3f}")
# standard: 147456  separable: 17536  ratio 0.119 vs 1/N + 1/K^2 = 0.119
```

### EfficientNet：深度、寬度、解析度一起放大

手上有一個好的小網路，要怎麼把它變大？加深、加寬，還是提高輸入解析度？Tan 與 Le [18] 主張這三者互相影響：解析度更高的影像需要更深（更大的感受野）與更寬（更細的圖樣）。**複合縮放**（compound scaling）用一個係數 $\phi$ 同時放大三者：

$$
d = \alpha^{\phi}, \quad w = \beta^{\phi}, \quad r = \gamma^{\phi}, \qquad \text{s.t. } \alpha \beta^2 \gamma^2 \approx 2, \;\; \alpha, \beta, \gamma \ge 1,
$$

其中 $d$、$w$、$r$ 分別是深度、寬度與解析度的倍率。FLOPs 大約與 $d\,w^2 r^2$ 成正比，所以 $\phi$ 每加 1，成本大約加倍。常數是在基礎網路上做小型網格搜尋得到的（基礎網路本身由架構搜尋找出，使用帶深度卷積與 squeeze-and-excitation 的反向瓶頸區塊）。「平衡地放大」這個想法，比那些特定常數活得更久。

### ConvNeXt：一步一步現代化的 CNN

在視覺 Transformer 拿下排行榜之後，Liu 等人 [20] 問：它們的優勢有多少來自注意力機制，又有多少來自其他一切？他們從一個用 Transformer 風格配方訓練的 ResNet-50 出發，一次只改一件事：仿照 Swin 的階段比例、「patchify」主幹（$4 \times 4$、步幅 4 的卷積）、用更大的 $7 \times 7$ 深度卷積、反向瓶頸、更少的激活與正規化層、GELU 與 LayerNorm。結果 ConvNeXt 在 ImageNet 與下游任務上，追平了相近成本的 Swin 類 Transformer。教訓是：架構家族的差異，沒有伴隨而來的許多小設計與訓練選擇那麼重要。

## 注意力機制與 Transformer

**白話版。** 卷積只用固定的權重看一個小鄰域。注意力機制讓每個位置根據內容，自己決定要聽哪些其他位置的話。視覺 Transformer 把這個機制套用到影像小塊上。

注意力最早以輕量的形式進入 CNN。**Squeeze-and-excitation（SE）**區塊 [21] 用全域平均把特徵圖的每個通道濃縮成一個數字，再由一個小網路把這些摘要轉成介於 0 與 1 之間的權重，重新縮放各通道。網路因此能在整張影像看起來像動物時，加強「毛皮」相關的通道。SE 區塊是 EfficientNet 與許多行動裝置網路的一部分。

*選讀：[Squeeze-and-excitation：CNN 裡的注意力](#squeeze-and-excitationcnn-裡的注意力)（見「補充資料」頁）。SE 的公式與幾行 PyTorch 程式。*

### ViT：把影像當成一串小塊

視覺 Transformer（Vision Transformer, ViT）[22] 幾乎完全拿掉卷積。影像 $\mathbf{x} \in \mathbb{R}^{H \times W \times C}$ 被切成 $N = HW/P^2$ 個不重疊的 $P \times P$ 小塊（patch）。每個小塊攤平後線性投影成 $D$ 維的 **token**。前面再加上一個可學習的**類別 token**，並加上可學習的**位置嵌入**：

$$
\mathbf{z}_0 = [\,\mathbf{x}_{\text{class}};\; \mathbf{x}_p^1 \mathbf{E};\; \dots;\; \mathbf{x}_p^N \mathbf{E}\,] + \mathbf{E}_{\text{pos}},
$$

其中 $\mathbf{x}_p^i \in \mathbb{R}^{P^2 C}$ 是第 $i$ 個攤平的小塊，$\mathbf{E} \in \mathbb{R}^{P^2 C \times D}$ 是小塊嵌入矩陣，$\mathbf{E}_{\text{pos}} \in \mathbb{R}^{(N+1) \times D}$ 是位置嵌入。接著由 $L$ 層標準 Transformer 編碼器（多頭自注意力與 MLP，各自帶 LayerNorm 與殘差連接）處理這個序列，最後由一個小型分類頭讀取類別 token 的最終狀態，輸出 logits。單一個注意力頭的自注意力為

$$
\operatorname{Attn}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \operatorname{softmax}\!\Big(\frac{\mathbf{Q}\mathbf{K}^\top}{\sqrt{d}}\Big)\mathbf{V},
$$

其中 $\mathbf{Q} = \mathbf{Z}\mathbf{W}_Q$、$\mathbf{K} = \mathbf{Z}\mathbf{W}_K$、$\mathbf{V} = \mathbf{Z}\mathbf{W}_V$ 是 token 矩陣 $\mathbf{Z}$ 的線性投影，$d$ 是 key 的維度。注意力矩陣大小為 $(N+1) \times (N+1)$：從第一層開始，每個小塊就能注意到所有其他小塊，所以感受野一開始就是全域的。

<Figure src={vitPatches} alt="一張太空人影像被切成 4×4 網格，16 個小塊排成一列，各自投影成 token z1 到 z16，前面接一個類別 token，加上位置嵌入，再送進 Transformer 編碼器，類別 token 的輸出接到 MLP 分類頭" caption="圖 6 — ViT 的輸入流程。所有小塊共用同一個線性投影變成 token（等價於核大小 P×P、步幅 P 的卷積）。加上類別 token 與可學習的位置嵌入後，用類別 token 的最終狀態來分類。" />

```python
import torch
import torch.nn as nn

B, C, H, W, P, D = 2, 3, 32, 32, 8, 64
img = torch.randn(B, C, H, W)

# 1) patchify: (B, C, H, W) -> (B, N, P*P*C) with N = (H/P)*(W/P)
patches = img.unfold(2, P, P).unfold(3, P, P)                 # (B, C, H/P, W/P, P, P)
patches = patches.permute(0, 2, 3, 1, 4, 5).reshape(B, -1, C * P * P)
N = patches.shape[1]

# 2) linear patch embedding + class token + learned position embedding
embed = nn.Linear(C * P * P, D)          # same as nn.Conv2d(C, D, kernel_size=P, stride=P)
cls = nn.Parameter(torch.zeros(1, 1, D))
pos = nn.Parameter(torch.randn(1, N + 1, D) * 0.02)
z = torch.cat([cls.expand(B, -1, -1), embed(patches)], dim=1) + pos   # (B, N+1, D)

# 3) one head of scaled dot-product self-attention
Wq, Wk, Wv = (nn.Linear(D, D, bias=False) for _ in range(3))
q, k, v = Wq(z), Wk(z), Wv(z)
A = (q @ k.transpose(1, 2) / D ** 0.5).softmax(dim=-1)        # (B, N+1, N+1), rows sum to 1
out = A @ v
print("tokens:", N + 1, " attention:", tuple(A.shape), " class-token output:", tuple(out[:, 0].shape))
```

**為什麼 ViT 需要大量資料。** CNN 內建了一些假設，稱為**歸納偏差**（inductive bias）：局部性（一個像素主要和鄰居有關）與平移等變性（同一個濾波器用在每個位置）。ViT 幾乎沒有這些；除了切小塊與位置嵌入之外，空間結構都得從資料中學。ViT 論文 [22] 回報：只在 ImageNet-1k 上訓練時，ViT 落後於規模相近的 ResNet；但在大得多的資料集上預訓練（ImageNet-21k，或 3 億張影像的 JFT）之後，就能追平甚至超越。弱先驗在小規模時要付出資料的代價，到了大規模就不再是限制。同一篇論文也嘗試了**混合**（hybrid）模型：把 ResNet 主幹的特徵圖、而不是原始小塊，送進 Transformer；混合模型在計算預算小時較有幫助，模型變大後差距就消失了。

### DeiT：只用 ImageNet 訓練 ViT

DeiT [23] 證明「ViT 需要巨量資料」這個結論，有一部分其實是關於訓練配方。用強力的資料擴增（RandAugment、Mixup、CutMix、random erasing）、隨機深度、重複擴增與 AdamW，只在 ImageNet-1k 上訓練的 ViT-B 就達到 83.1% top-1。DeiT 還加入了**蒸餾 token**：第二個可學習的 token，和類別 token 一樣，但它的輸出被訓練去匹配教師網路的預測（他們發現卷積網路當教師效果最好），而類別 token 則以真實標籤訓練。這是知識蒸餾 [51] 的一種 Transformer 專屬形式。測試時把兩個頭的輸出結合起來。

*選讀：[知識蒸餾](/zh-tw/learn/deep-learning/dl-01-deep-learning-for-image-processing/notes/#知識蒸餾向老師模型的軟答案學習)（DLCV 01 的補充資料）。蒸餾損失與溫度的作用。*

### Swin：視窗、位移與階層

全域注意力的成本隨 token 數量呈平方成長，對高解析度輸入與密集預測任務是個問題。Swin [24] 只在不重疊的 $M \times M$ 視窗內計算注意力，並在相鄰層之間把視窗網格位移半個視窗，讓資訊能跨越視窗邊界。各階段之間合併 $2 \times 2$ 相鄰小塊來減少 token 數，形成步幅為 4、8、16、32 的類 CNN 金字塔。對 $h \times w$ 個 token、$C$ 個通道，論文給出

$$
\Omega(\text{MSA}) = 4hwC^2 + 2(hw)^2 C, \qquad \Omega(\text{W-MSA}) = 4hwC^2 + 2M^2 hwC,
$$

所以在視窗大小 $M$ 固定時，視窗注意力對 token 數 $hw$ 是線性的。Swin 帶回了兩個 CNN 先驗：局部性與階層性，成為偵測與分割也通用的骨幹。視覺 Transformer 的整體版圖可參考 Khan 等人的綜述 [25]。

## 訓練配方

**白話版。** 同一個網路，訓練方法不同，準確率可以差好幾個百分點。現代訓練配方是一組小技巧，每一個都讓「死背」更難，或讓最佳化更平順。

### 資料擴增

- **隨機縮放裁切**（random resized crop）隨機取一塊占原圖面積一定比例、長寬比隨機的區域，再縮放到訓練解析度。它教會網路尺度與位置不變性，是 ImageNet 訓練的預設做法。**水平翻轉**只在不改變標籤時使用（大多數照片可以，文字或數字不行）。
- **Mixup** [26] 混合兩張影像與它們的標籤：$\tilde{\mathbf{x}} = \lambda \mathbf{x}_i + (1 - \lambda)\mathbf{x}_j$、$\tilde{\mathbf{y}} = \lambda \mathbf{y}_i + (1 - \lambda)\mathbf{y}_j$，其中 $\lambda \sim \operatorname{Beta}(\alpha, \alpha)$，$\mathbf{y}$ 為 one-hot。它鼓勵模型在訓練樣本之間呈線性行為。
- **CutMix** [27] 把影像 $j$ 的一個隨機矩形貼到影像 $i$ 上，並依貼上的面積比例混合標籤。和 Mixup 不同，每個像素都仍是自然的，網路必須從局部視野辨認物體。
- **RandAugment** [28] 用兩個數字取代學出來的擴增策略：隨機套用 $N$ 個操作（旋轉、剪切、色階分離、對比……），共用同一個強度 $M$。論文回報這個極小的搜尋空間就能追平或超越先前的自動化策略，而合適的強度取決於模型與資料集大小。

```python
import numpy as np
import torch
import torch.nn.functional as F

def mixup(x, y, num_classes, alpha=0.2):
    lam = float(np.random.beta(alpha, alpha))
    idx = torch.randperm(x.size(0))
    y1 = F.one_hot(y, num_classes).float()
    return lam * x + (1 - lam) * x[idx], lam * y1 + (1 - lam) * y1[idx]

def cutmix(x, y, num_classes, alpha=1.0):
    lam = float(np.random.beta(alpha, alpha))
    idx = torch.randperm(x.size(0))
    H, W = x.shape[-2:]
    h, w = int(H * np.sqrt(1 - lam)), int(W * np.sqrt(1 - lam))
    cy, cx = np.random.randint(H), np.random.randint(W)
    y0, y1_, x0, x1_ = max(cy - h // 2, 0), min(cy + h // 2, H), max(cx - w // 2, 0), min(cx + w // 2, W)
    x = x.clone()
    x[..., y0:y1_, x0:x1_] = x[idx][..., y0:y1_, x0:x1_]
    lam = 1 - (y1_ - y0) * (x1_ - x0) / (H * W)            # actual area kept
    y1 = F.one_hot(y, num_classes).float()
    return x, lam * y1 + (1 - lam) * y1[idx]

def soft_ce(logits, soft_targets):
    return -(soft_targets * logits.log_softmax(1)).sum(1).mean()
```

### 標籤平滑

以 one-hot 為目標的交叉熵會永遠把正確 logit 往上推；只有在間距無限大時，損失才會到零。**標籤平滑** [13] 把目標換成

$$
\mathbf{q} = (1 - \varepsilon)\,\mathbf{e}_y + \frac{\varepsilon}{K}\mathbf{1},
$$

其中 $\varepsilon$（常用 0.1）是平滑強度，$\mathbf{e}_y$ 是 one-hot 向量，$\mathbf{1}$ 是全 1 向量。此時最佳解是有限的 logit 間距，對網路有正則化效果，通常也會減少過度自信。在 PyTorch 裡只是一個參數：`F.cross_entropy(logits, y, label_smoothing=0.1)`。

### 最佳化器、排程與正則化

- **AdamW** [29] 把權重衰減與自適應梯度步驟解耦：不是把 $\lambda \theta$ 加到梯度上（Adam 會再對每個參數重新縮放），而是直接縮小權重，$\theta \leftarrow \theta - \eta(\hat{\mathbf{m}}/(\sqrt{\hat{\mathbf{v}}} + \epsilon) + \lambda \theta)$，其中 $\eta$ 是學習率，$\hat{\mathbf{m}}, \hat{\mathbf{v}}$ 是 Adam 的動差估計，$\lambda$ 是衰減係數。它是 Transformer 與現代 CNN 配方的預設選擇。偏差與正規化層的參數通常不做衰減。
- **暖身＋餘弦排程。** 訓練最初幾步，正規化統計量與 Adam 的動差估計都還不準，大學習率會不穩定，所以先讓學習率在幾個 epoch 內線性上升，接著沿半個餘弦曲線降到接近零，$\eta_t = \tfrac{1}{2}\eta_{\max}(1 + \cos(\pi t / T))$，$t$ 是暖身後的步數，$T$ 是剩餘步數；這個想法由 SGDR [30] 推廣開來。
- **隨機深度**（stochastic depth）[31] 在訓練時隨機跳過整個殘差分支（區塊變成恆等映射），跳過機率隨深度增加。它縮短了訓練時的有效深度，效果類似一群較淺網路的集成。
- **權重的 EMA** 維護一個指數移動平均 $\bar{\theta} \leftarrow \mu \bar{\theta} + (1 - \mu)\theta$（$\mu$ 接近 1，例如 0.999），評估時使用 $\bar{\theta}$。它把最後幾步 SGD 的雜訊平滑掉。

```python
import math
import torch

def warmup_cosine(step, total, warmup):
    if step < warmup:
        return (step + 1) / warmup                      # linear warmup
    p = (step - warmup) / max(1, total - warmup)
    return 0.5 * (1 + math.cos(math.pi * p))            # cosine decay to 0

model = torch.nn.Linear(10, 3)
decay = [p for n, p in model.named_parameters() if p.ndim > 1]      # weights
no_decay = [p for n, p in model.named_parameters() if p.ndim <= 1]  # biases, norm scales
opt = torch.optim.AdamW([{"params": decay, "weight_decay": 0.05},
                         {"params": no_decay, "weight_decay": 0.0}], lr=1e-3)
total = 1000
sched = torch.optim.lr_scheduler.LambdaLR(opt, lambda s: warmup_cosine(s, total, warmup=50))
ema = torch.optim.swa_utils.AveragedModel(model, multi_avg_fn=torch.optim.swa_utils.get_ema_multi_avg_fn(0.999))
for step in range(total):
    loss = model(torch.randn(16, 10)).pow(2).mean()
    opt.zero_grad(); loss.backward(); opt.step(); sched.step(); ema.update_parameters(model)
```

### 「ResNet strikes back」

配方重要性最驚人的證據，來自 Wightman、Touvron 與 Jégou [32]。他們保持 2015 年的 ResNet-50 架構不變，用現代配方重新訓練：隨機縮放裁切與翻轉、RandAugment、Mixup 與 CutMix、LAMB 最佳化器配餘弦排程、二元交叉熵損失，以及更長的訓練。原汁原味的 ResNet-50 在 $224 \times 224$ 的 ImageNet 上，不用額外資料或蒸餾就達到 **80.4% top-1**，而他們比較的標準 torchvision 權重是 76.1%。這帶來兩個結論。第一，許多「新架構打敗 ResNet-50」的宣稱，其實是拿用新配方訓練的新模型，去比用舊配方訓練的舊模型。第二，比較架構時，要用相同且調好的配方訓練它們，就像 ConvNeXt [20] 與 RegNet [19] 的做法。

## 遷移學習與微調

**白話版。** 從頭訓練一個骨幹網路需要大量資料。比較好的做法是：從一個已經在大型資料集上訓練好的網路出發，再把它調整到你的任務上。你可以凍結它的特徵、只訓練新的最後一層，也可以溫和地重新訓練所有參數。

令 $g_\phi$ 為一個預訓練骨幹，把影像映射成特徵向量 $\mathbf{h} = g_\phi(\mathbf{x}) \in \mathbb{R}^{D}$，$\mathbf{W} \in \mathbb{R}^{K \times D}$ 為新的線性分類頭。

- **線性探測**（linear probe）。凍結 $\phi$，只訓練 $\mathbf{W}$（等於在固定特徵上做邏輯迴歸）。它便宜、需要的標籤少，也是*衡量*表徵好壞的標準方法。
- **完整微調**（full fine-tuning）。同時更新 $\phi$ 與 $\mathbf{W}$，通常骨幹的學習率比分類頭小 10–100 倍，搭配短暫的暖身，有時還會用逐層學習率衰減（越前面的層學習率越小）。它讓特徵適應新的領域，標註資料夠多時通常勝出。
- 介於兩者之間的，有部分微調（只調最後幾個階段），以及在凍結骨幹上加入小型可訓練模組的參數高效方法。

Kornblith 等人 [33] 量測了 ImageNet 準確率能多好地預測遷移表現。對微調而言，ImageNet 上越好的模型通常遷移得越好，相關性很強。對固定特徵而言，相關性較弱，而且取決於正則化選擇：有些提升 ImageNet 準確率的設定（例如標籤平滑與 dropout），反而產生了在其他任務上*更差*的凍結特徵。好的分類器與好的特徵擷取器相關，但不是同一件事。

```python
import torch
import torch.nn as nn

backbone = nn.Sequential(nn.Conv2d(3, 32, 3, 2, 1), nn.ReLU(), nn.Conv2d(32, 64, 3, 2, 1), nn.ReLU(),
                         nn.AdaptiveAvgPool2d(1), nn.Flatten())          # stand-in for a pre-trained model
head = nn.Linear(64, 5)

# linear probe: freeze the backbone, train only the head
for p in backbone.parameters():
    p.requires_grad = False
probe_opt = torch.optim.AdamW(head.parameters(), lr=1e-3)

# full fine-tuning: unfreeze, use a smaller learning rate for the backbone than for the head
for p in backbone.parameters():
    p.requires_grad = True
ft_opt = torch.optim.AdamW([{"params": backbone.parameters(), "lr": 1e-5},
                            {"params": head.parameters(), "lr": 1e-3}], weight_decay=0.05)
```

## 自監督學習與基礎模型分類器

**白話版。** 標籤很貴，影像很便宜。自監督學習自己發明一個答案就藏在影像裡的任務（這兩塊裁切是不是來自同一張照片？被遮住的地方原本是什麼？），透過解這個任務學到特徵，最後才用少量標籤。

### 對比式學習：SimCLR 與 MoCo

對比式方法把同一張影像的兩個擴增**視圖**的嵌入拉近，把不同影像的視圖推遠。在 SimCLR [34] 中，每個視圖都要在批次裡所有其他視圖中找出自己的搭檔，這是一個「錯誤答案」就是其他影像的分類任務；強力擴增（特別是裁切加上顏色扭曲）與大批次被證明不可或缺。MoCo [35] 則維護一個由緩慢更新的編碼器副本所產生的嵌入佇列，不需超大批次也能有大量負樣本。

*選讀：[對比式學習細說：SimCLR 與 MoCo](#對比式學習細說simclr-與-moco)（見「補充資料」頁）。逐一定義符號的 InfoNCE 損失，以及 MoCo 的動量編碼器如何運作。*

### DINO 與 DINOv2：自我蒸餾

DINO [36] 不再使用明確的負樣本。學生網路看幾個裁切（包括小的局部裁切），被訓練去匹配看全域裁切的教師網路的輸出分佈。教師是學生的 EMA；對教師輸出做中心化與銳化，可以防止崩塌成常數。用 ViT 時，DINO 特徵展現出驚人的性質：類別 token 的注意力圖不需任何分割標籤就能把物體分割出來，而在凍結特徵上用簡單的 $k$-NN 分類器效果就很好。DINOv2 [38] 以自動篩選的資料集與一個大型 ViT（再蒸餾成較小的模型）擴大規模，產生通用的**凍結特徵**，不需微調就能用於分類、分割與深度估計。DINOv3 [39] 繼續擴大規模，並提出「Gram anchoring」，避免密集的小塊特徵在長時間訓練中劣化。

### MAE：遮罩影像建模

MAE [37] 借用了遮罩語言模型的想法。它遮掉大比例的小塊（論文中為 75%），只把看得見的小塊送進 ViT 編碼器，再讓一個輕量解碼器重建被遮掉的像素。因為編碼器跳過被遮掉的 token，預訓練很便宜。MAE 特徵的線性可分性不如對比式特徵（線性探測較弱），但**微調**效果非常好。這是一再出現的模式：不同的預訓練目標，適合不同的適應方式。

### CLIP：用語言做零樣本分類

CLIP [40] 用數億組影像與說明文字，以對稱的對比損失同時訓練影像編碼器 $g$ 與文字編碼器 $h$，讓配對的影像與文字有高的餘弦相似度。之後**不需要任何訓練影像**就能建立分類器：為每個類別寫一句提示，例如 `a photo of a dog.`，將它嵌入，然後預測

$$
\hat{y} = \arg\max_{k} \; \frac{g(\mathbf{x})^\top h(t_k)}{\lVert g(\mathbf{x}) \rVert\, \lVert h(t_k) \rVert},
$$

其中 $t_k$ 是類別 $k$ 的提示。文字嵌入扮演線性分類器權重的角色，只是它們是從文字算出來的。論文回報零樣本 CLIP 的準確率追平了一個用 ImageNet 128 萬張標註影像訓練的 ResNet-50，而平均多個提示模板（「a photo of a …」、「a blurry photo of a …」）會有幫助。零樣本準確率高度依賴提示的用字、類別名稱在視覺上是否有意義，以及網路資料對該領域的涵蓋程度。

## 穩健性與評估陷阱

**白話版。** 一個在測試集上拿 90% 的分類器，碰到不同相機拍的照片、有人刻意加上肉眼看不見的雜訊，或它學到的「簡單線索」（背景、浮水印）不見時，可能會錯得一塌糊塗。而且就算答對了，它的信心也可能不對。

### 分佈偏移：ImageNet-C、-R 與 -A

Hendrycks 等人為 ImageNet 分類器建立了三個廣泛使用的偏移測試集。**ImageNet-C** [42] 套用 15 種演算法產生的損壞（雜訊、模糊、天氣、數位瑕疵），各有五個嚴重程度，並以相對於基準模型的錯誤率總結（mean corruption error）。**ImageNet-R** [43] 收集了 200 個 ImageNet 類別的各種表現形式（藝術、卡通、雕塑、素描、玩具），測試模型理解的是形狀與概念，還是照片的紋理。**ImageNet-A** [44] 收錄未經修改的自然照片，這些照片經過篩選、專門騙倒 ResNet-50；標準模型在上面表現非常差。這三個測試集揭露不同的弱點，改善其中一個不保證改善其他。大規模預訓練（如 CLIP 與 DINOv2）對這類自然偏移的穩健性提升，往往遠大於在相同資料下更換架構。

### 對抗樣本：FGSM

Goodfellow 等人 [45] 用網路在高維空間中的**線性**來解釋對抗樣本：對每一個輸入維度做一點點、與權重方向一致的改變，累加起來就是輸出的巨大變化。**快速梯度符號法**（fast gradient sign method, FGSM）一步就完成擾動：

$$
\mathbf{x}_{\text{adv}} = \operatorname{clip}\big(\mathbf{x} + \varepsilon\, \operatorname{sign}(\nabla_{\mathbf{x}} \mathcal{L}(f_\theta(\mathbf{x}), y))\big),
$$

其中 $\varepsilon$ 限制每個像素的改變量（$\ell_\infty$ 範數），$\mathcal{L}$ 是損失函數，$\operatorname{clip}$ 把像素值限制在有效範圍內。

```python
import torch.nn.functional as F

def fgsm(model, x, y, eps):
    x = x.clone().requires_grad_(True)
    F.cross_entropy(model(x), y).backward()
    return (x + eps * x.grad.sign()).clamp(-1, 1).detach()
```

關於圖 8 有兩點要注意。第一，擴增模型在小 $\varepsilon$ 時看起來比較穩健，但已知標籤平滑會讓訓練點附近的損失曲面變平，可能削弱單步梯度攻擊，卻沒有帶來真正的穩健性；正確的檢驗是更強的迭代攻擊。第二，在 $[-1, 1]$ 範圍內 $\varepsilon = 0.05$ 對 8×8 的數字來說是看得見的；在自然影像上，肉眼無法察覺的擾動就足以騙過標準的 ImageNet 模型。

### 捷徑學習

Geirhos 等人 [46] 把許多失敗案例歸在同一個名字下：**捷徑學習**（shortcut learning）。網路會用最容易的線索來最小化訓練損失，而那常常不是我們想要的線索：看背景而不是動物、看醫院的標記而不是病灶、看紋理而不是形狀。捷徑在獨立同分佈的測試集上看起來沒問題，因為測試集裡也有同樣的捷徑；一遇到分佈偏移就會失敗。對策是：刻意在分佈外測試、設計能打破可疑捷徑的測試，並用 Grad-CAM（見下文）這類可解釋性工具檢查模型在看哪裡。

### 校準與溫度縮放

**溫度縮放**（temperature scaling）[47] 在 softmax 之前把所有 logits 除以同一個純量 $T > 0$：$\mathbf{p} = \operatorname{softmax}(\mathbf{z}/T)$。$T$ 是在保留的**校準**集（絕不是測試集）上最小化負對數概似而得。$T > 1$ 讓過度自信的預測變柔和；$T \lt 1$ 讓信心不足的預測變銳利。因為除以 $T$ 不改變 argmax，準確率不變。

```python
import torch
import torch.nn.functional as F

def fit_temperature(logits, y, iters=300):
    """Learn one scalar T > 0 on a held-out calibration split."""
    log_t = torch.zeros(1, requires_grad=True)
    opt = torch.optim.Adam([log_t], lr=0.05)
    for _ in range(iters):
        loss = F.cross_entropy(logits / log_t.exp(), y)
        opt.zero_grad(); loss.backward(); opt.step()
    return log_t.exp().item()

def ece(probs, y, n_bins=10):
    conf, pred = probs.max(1)
    correct = (pred == y).float()
    edges = torch.linspace(0, 1, n_bins + 1)
    total = 0.0
    for lo, hi in zip(edges[:-1], edges[1:]):
        m = (conf > lo) & (conf <= hi)
        if m.any():
            total += m.float().mean() * (correct[m].mean() - conf[m].mean()).abs()
    return float(total)

# toy check: an over-confident "model" = true logits multiplied by 3
torch.manual_seed(0)
true_logits = torch.randn(4000, 10)
y = torch.distributions.Categorical(logits=true_logits).sample()
over = 3 * true_logits
T = fit_temperature(over[:2000], y[:2000])
print(f"T = {T:.2f}  ECE {ece(over[2000:].softmax(1), y[2000:]):.3f} -> "
      f"{ece((over[2000:] / T).softmax(1), y[2000:]):.3f}")
# T = 2.90  ECE 0.345 -> 0.018
```

在這個玩具例子裡，logits 被放大了三倍，擬合出的溫度（2.90）找回了這個倍數。而在我們真正的 TinyResNet（未擴增的那個模型）上，校準誤差的方向*相反*。

為什麼信心不足？我們的小模型訓練時間短、權重衰減又強，使 logits 保持很小。Guo 等人 [47] 觀察到的是大型、長時間訓練的現代網路過度自信，並指出深度、寬度、批次正規化與*較小*的權重衰減都是成因。校準誤差沒有固定的方向；要量測它。另外也要注意，校準本身在分佈偏移下很脆弱：在分佈內資料上擬合的溫度，不保證在 ImageNet-C 式的偏移上仍然校準良好。

## 效率

**白話版。** 模型必須放得進裝置、跑得進時間預算。參數量、計算量與實際速度是三種不同的量測，而使用者感受到的只有最後一種。

- **參數量**決定模型在磁碟與記憶體中的大小。一個 float32 參數占 4 個位元組。
- **FLOPs**（或乘加運算 MACs；一次 MAC 通常算作兩個 FLOPs）衡量每張影像的運算量。對核大小 $K \times K$、輸入 $C_{\text{in}}$ 通道、輸出 $C_{\text{out}}$ 通道、輸出特徵圖為 $H' \times W'$ 的卷積，MACs $= H' W' K^2 C_{\text{in}} C_{\text{out}}$。計算量隨解析度的平方成長。
- **延遲與吞吐量**要在目標硬體上量測。深度卷積的 FLOPs 很少，但運算密度低，所以在 GPU 上常比 FLOPs 所暗示的還慢；DenseNet 的串接則耗費記憶體頻寬。一定要實測。
- **量化**（quantization）把權重與激活值存成 8 位元整數，而不是 32 位元浮點數。Jacob 等人 [50] 描述了只用整數運算的推論，搭配量化感知訓練：在訓練時模擬捨入，讓網路學會容忍它。用少量校準資料做訓練後量化，則是較便宜的替代方案。
- **蒸餾** [51] 訓練一個小的學生網路去匹配大型教師網路的軟預測，就像 DeiT 用蒸餾 token 所做的那樣。

## 可解釋性：CAM 與 Grad-CAM

**白話版。** 疊在影像上的熱圖，顯示哪些區域把某個類別的分數推高了。它是健全性檢查，不是推理過程的證明。

**類別激活映射**（class activation mapping, CAM）[48] 適用於以全域平均池化加一層線性層結尾的網路。若 $A^k$ 是最後一個卷積層的第 $k$ 個特徵圖，$w^c_k$ 是它連到類別 $c$ 的權重，則類別分數為 $\sum_k w^c_k \cdot \operatorname{mean}(A^k)$，而 $\sum_k w^c_k A^k$ 這張圖顯示分數來自哪裡。**Grad-CAM** [49] 用空間平均的梯度取代這些權重，把方法推廣到任何可微分的架構：

$$
\alpha_k^c = \frac{1}{Z}\sum_{i,j} \frac{\partial y^c}{\partial A^k_{ij}}, \qquad
L^c_{\text{Grad-CAM}} = \operatorname{ReLU}\Big(\sum_k \alpha_k^c A^k\Big),
$$

其中 $y^c$ 是類別 $c$ 的 logit，$A^k_{ij}$ 是通道 $k$ 在位置 $(i, j)$ 的激活值，$Z$ 是位置總數。ReLU 只保留對該類別有正面影響的區域。粗糙的熱圖（我們的網路中是 $8 \times 8$）再上採樣到影像大小。

```python
import torch.nn.functional as F

def grad_cam(model, x, target=None):
    model.eval()
    feats = model.features(x)                          # (1, K, h, w) last conv stage
    feats.retain_grad()
    logits = model.fc(feats.mean(dim=(2, 3)))
    c = logits.argmax(1).item() if target is None else target
    logits[0, c].backward()
    alpha = feats.grad.mean(dim=(2, 3), keepdim=True)  # channel importance weights
    cam = F.relu((alpha * feats).sum(1, keepdim=True))
    cam = F.interpolate(cam, size=x.shape[-2:], mode="bilinear", align_corners=False)
    return (cam / (cam.max() + 1e-8))[0, 0].detach(), c
```

解釋方法在模型出錯時最有用，就像圖 10：它們顯示了哪些筆畫看起來像錯誤的類別。但對顯著圖要謹慎。它們很粗糙（受限於最後一層特徵圖的解析度），而且只解釋單一輸入的單一類別分數，不是模型的一般推理方式。

## 現代觀點

**值得一讀的綜述。** Li 等人 [1] 從基本構成元件到進階模型回顧 CNN，並以實驗比較激活函數、損失函數與最佳化器。Khan 等人 [25] 綜述視覺 Transformer，強調它們對大規模預訓練的依賴，以及平方複雜度注意力的成本。Gui 等人 [41] 把自監督學習分成以脈絡為基礎、對比式、生成式與混合式方法。在基準可靠性方面，ImageNetV2 [7]、重新標註 [8] 與標籤錯誤 [9] 三項研究共同主張：使用多個測試集、多標籤評估，並回報變異。

*選讀：[現代觀點綜述導讀](#現代觀點綜述導讀)（見「論文導讀」頁）。每篇綜述涵蓋什麼，以及如何分類這個領域。*

**2023–2026 年的樣貌。** 五個趨勢定義了當前的實務。

1. **預訓練一次，便宜地適應。** 大多數新的分類器都不是從頭訓練。它們從一個以自監督（DINOv2 [38]、DINOv3 [39]）、影像–文字對比（CLIP [40] 及其開源重現）或遮罩建模（MAE [37]）訓練的大型骨幹出發，再以線性探測、$k$-NN 規則或短暫微調來適應。
2. **零樣本與開放詞彙分類。** 影像–文字模型把標籤集合變成文字。類別清單可以在測試時更換、不需重新訓練，模糊了分類與檢索之間的界線。
3. **視覺的縮放定律。** Zhai 等人 [52] 把 ViT 擴大到數十億參數，刻畫了錯誤率如何隨計算量、資料量與模型大小下降，並觀察到較大的模型在少樣本遷移中更有樣本效率。Cherti 等人 [53] 在公開資料上為開源 CLIP 訓練擬合出可重現的冪律，發現縮放行為取決於訓練資料分佈與下游任務。
4. **架構趨於收斂。** ConvNeXt [20] 與 Swin [24] 顯示，在相同配方與規模下，卷積與注意力會落在相近的位置。現在的選擇更多取決於硬體、解析度與下游任務（密集預測偏好階層式設計），而不是 top-1 準確率。
5. **評估不再只看 ImageNet-1k top-1。** 穩健性測試組（ImageNet-C/R/A [42]–[44] 與 ImageNetV2 [7]）、校準，以及遷移到大量下游資料集，現在都是骨幹論文的標準內容。

**開放問題。** 對自然分佈偏移的穩健性仍落後於乾淨資料上的準確率，而穩健訓練方法帶來的進步往往只針對它所瞄準的那種偏移。沒有反事實測試，捷徑學習 [46] 很難被發現。分佈偏移下的校準仍未解決。長尾與細粒度辨識依然困難，因為稀有類別的樣本最少。基準飽和與標籤雜訊，讓 ImageNet-1k 上的微小準確率差異失去意義。而主流的基礎模型是用網路規模的資料訓練的，其組成、授權與偏差都很難稽核，這直接影響「零樣本」分類器能認出什麼、認不出什麼。

## 重點整理

- 分類器輸出 logits；單標籤任務用 softmax＋交叉熵訓練，多標籤任務用獨立 sigmoid＋二元交叉熵訓練。回報 top-1 準確率，必要時也回報校準（ECE）與逐類別結果。
- 每個里程碑 CNN 都修正了一個瓶頸：ReLU／GPU（AlexNet）、疊加的小卷積核（VGG）、$1 \times 1$ 降維與多分支模組（Inception）、為最佳化而設的恆等捷徑（ResNet）、為成本而設的深度可分離卷積（MobileNet）、平衡縮放（EfficientNet）。
- ViT 用卷積的歸納偏差換取彈性；它需要更多資料或更強的配方（DeiT），而視窗加階層（Swin）讓它成為實用的骨幹。ConvNeXt 顯示配方解釋了大部分的差距。
- 訓練配方和架構一樣重要：資料擴增（隨機縮放裁切、Mixup、CutMix、RandAugment）、標籤平滑、AdamW、暖身＋餘弦、隨機深度與 EMA，讓架構不變的 ResNet-50 達到 80.4% top-1。
- 預訓練骨幹是預設的起點。線性探測衡量表徵；微調讓表徵適應任務。CLIP 把類別名稱變成分類器權重，實現零樣本辨識。
- 準確率會掩蓋模型犯的是*哪一種*錯。請看混淆矩陣；類別不平衡時回報精確率／召回率、平衡準確率或 MCC，並優先使用精確率–召回率曲線與 AP，而不是 ROC-AUC。說清楚平均是巨觀（每個類別同等）還是微觀（每張影像同等；在單標籤任務中等於準確率）。
- 把訓練資料與評估資料分開：用一整組測試集評估骨幹網路（ImageNet 驗證集與 ReaL、ImageNetV2、ImageNet-C/R/A/Sketch、ObjectNet、細粒度與遷移測試組），只在驗證資料上調整，並回報多個隨機種子的平均 ± 標準差。
- 基準準確率很脆弱：在偏移資料上測試、小心捷徑與對抗輸入、在保留資料上擬合溫度，並檢查 Grad-CAM 熱圖，特別是在出錯的樣本上。

1. **感受野與參數量。** 證明三層疊加的 $3 \times 3$ 卷積（步幅 1）感受野為 $7 \times 7$。在輸入與輸出都是 $C$ 通道、無偏差項的情況下，與單一 $7 \times 7$ 卷積比較參數量。

<details>
<summary>提示</summary>

每層 $3 \times 3$ 讓感受野增加 2 個像素：$3 \to 5 \to 7$。參數量：$3 \cdot 9C^2 = 27C^2$ 對 $49C^2$，少了約 45%，還多了兩個非線性。

</details>

2. **瓶頸區塊的算術。** 一個 ResNet 瓶頸區塊輸入有 $4d$ 個通道，降到 $d$。以 $d$ 表示 $1 \times 1$–$3 \times 3$–$1 \times 1$ 分支的權重數（無偏差），並與寬度 $4d$、兩層 $3 \times 3$ 的基本區塊比較。比值是多少？

<details>
<summary>提示</summary>

瓶頸：$4d \cdot d + 9d^2 + d \cdot 4d = 17d^2$。寬度 $4d$ 的基本區塊：$2 \cdot 9 \cdot 16d^2 = 288d^2$。比值為 $17/288 \approx 0.059$，權重少了約 17 倍。

</details>

3. **標籤平滑的最佳解。** 對一個有 $K$ 個類別、平滑強度 $\varepsilon$ 的樣本，假設所有錯誤類別的 logit 相等。證明平滑目標下的交叉熵在「正確類別與每個錯誤類別的 logit 差」為 $\log\big((1 - \varepsilon + \varepsilon/K)\,/\,(\varepsilon/K)\big)$ 時最小。代入 $K = 1000$、$\varepsilon = 0.1$ 計算。

<details>
<summary>提示</summary>

交叉熵對 $\mathbf{p}$ 的最小值發生在 $\mathbf{p} = \mathbf{q}$。所以 $p_y = 1 - \varepsilon + \varepsilon/K$，其他每個 $p_k = \varepsilon/K$，logit 差就是兩者比值的對數：$\log(0.9001 / 0.0001) \approx 9.1$。沒有平滑時，最佳間距是無限大。

</details>

4. **ViT 的 token 數。** 一個使用 $16 \times 16$ 小塊的 ViT 收到 $224 \times 224$ 的影像。有多少 token 進入編碼器？若以 $384 \times 384$ 微調，token 數是多少？注意力矩陣大小成長幾倍？位置嵌入又該怎麼處理？

$(224/16)^2 = 196$ 個小塊加一個類別 token：197。在 384 時：$24^2 + 1 = 577$。注意力矩陣成長 $(577/197)^2 \approx 8.6$ 倍。學到的位置嵌入是 $14 \times 14$ 的網格，要以二維內插放大到 $24 \times 24$；ViT 論文在較高解析度微調時正是這麼做的。

<details>
<summary>提示</summary>

### 巨觀與微觀平均的計算實例

本則補充以一個小型、不平衡的三類別例子，逐步計算正文介紹的巨觀、微觀與加權平均。

**計算範例。** 100 張測試影像，三個類別的支持數分別為 80（A）、15（B）、5（C）：

| 真實 \ 預測 | A | B | C |
| --- | --- | --- | --- |
| **A**（80） | 76 | 3 | 1 |
| **B**（15） | 4 | 10 | 1 |
| **C**（5） | 3 | 0 | 2 |

各行總和為 83、13、4，所以精確率為 $76/83 = 0.916$、$10/13 = 0.769$、$2/4 = 0.500$；召回率為 $76/80 = 0.950$、$10/15 = 0.667$、$2/5 = 0.400$；逐類別 $F_1$ 為 0.933、0.714、0.444。於是

$$
\text{F}_1^{\text{macro}} = \tfrac{1}{3}(0.933 + 0.714 + 0.444) = 0.697, \qquad
\text{F}_1^{\text{micro}} = \text{accuracy} = \tfrac{76 + 10 + 2}{100} = 0.880,
$$

而以支持數加權的 $F_1$ 為 $0.80 \cdot 0.933 + 0.15 \cdot 0.714 + 0.05 \cdot 0.444 = 0.875$。微觀與巨觀之間 18 個百分點的差距就是訊號：模型在常見類別上很好，在稀有類別上很差。當每個類別都重要時（罕見疾病、稀有物種）回報巨觀平均；當每一張*影像*同等重要時，回報微觀平均／準確率。

### Cohen's kappa：扣除巧合的一致性

本則補充定義正文提到的、扣除巧合後的一致性指標。

**Cohen's kappa** [59] 把觀察到的一致程度，扣掉純靠機率就會有的一致程度：

$$
\kappa = \frac{p_o - p_e}{1 - p_e}, \qquad p_o = \frac{1}{N}\sum_k C_{kk}, \qquad p_e = \frac{1}{N^2}\sum_k \Big(\sum_j C_{kj}\Big)\Big(\sum_i C_{ik}\Big),
$$

其中 $p_o$ 是準確率，$p_e$ 是一個與輸入無關、只依觀察到的比例隨機預測各類別的分類器所能得到的準確率。它原本是為兩位人類評分者之間的一致性設計的，在比較模型與標註者時仍很常見。

對正文的手寫數字分類器而言，$p_o = 0.911$、$p_e = 0.100$、$\kappa = 0.901$（scikit-learn 的 `cohen_kappa_score` [62] 給出相同的值）。十個類別彼此平衡時，巧合造成的一致很小，所以 kappa 與準確率很接近。

### 多標籤指標細說

本則補充給出正文摘要的多標籤指標之定義與一個小例子。

多標籤分類中，每張影像有一個二元目標向量 $\mathbf{t} \in \{0, 1\}^K$，模型則輸出一個分數向量。每個標籤都是自己的一個二元問題，所以自然的排序指標是**逐類別 AP** 及其對類別的平均 **mAP**；它隨 PASCAL VOC 分類任務 [61] 成為標準。需要門檻的指標分成兩大類，Zhang 與 Zhou [60] 有完整回顧：

- **以標籤為基礎**（label-based）的指標：對每個標籤算一個二元指標，再對標籤做巨觀或微觀平均，與多類別的情況完全相同。
- **以樣本為基礎**（example-based）的指標：對每一張*影像*算一個分數，再對影像取平均。以樣本為基礎的 $F_1$ 為 $\frac{1}{N}\sum_i \frac{2|\hat{Y}_i \cap Y_i|}{|\hat{Y}_i| + |Y_i|}$，其中 $Y_i$ 與 $\hat{Y}_i$ 是影像 $i$ 的真實與預測標籤集合。
- **Hamming loss** 是（影像, 標籤）位元中錯誤的比例，$\frac{1}{NK}\sum_i |\hat{Y}_i \,\triangle\, Y_i|$，其中 $\triangle$ 是對稱差。它很好解讀，但當稀有標籤很多時，什麼都不預測看起來也會很好。

```python
import numpy as np
from sklearn.metrics import average_precision_score, f1_score, hamming_loss

# 4 street photos, 3 labels: car, person, bicycle
T = np.array([[1, 1, 0], [1, 0, 0], [0, 1, 1], [1, 1, 1]])            # ground truth
S = np.array([[.9, .6, .2], [.8, .4, .3], [.3, .7, .4], [.6, .2, .7]])  # sigmoid scores
P = (S >= 0.5).astype(int)                                            # threshold 0.5

print("per-class AP:", average_precision_score(T, S, average=None).round(3))
print(f"mAP {average_precision_score(T, S, average='macro'):.3f}")
print(f"example-based F1 {f1_score(T, P, average='samples'):.3f}  "
      f"macro F1 {f1_score(T, P, average='macro'):.3f}  micro F1 {f1_score(T, P, average='micro'):.3f}")
print(f"Hamming loss {hamming_loss(T, P):.3f}")
# per-class AP: [1.    0.917 1.   ]
# mAP 0.972
# example-based F1 0.867  macro F1 0.822  micro F1 0.857
# Hamming loss 0.167
```

- **VTAB** [72] 包含 19 個任務，分成三組：7 個*自然*（一般相機影像）、4 個*專門*（衛星與醫學影像）、8 個*結構*（場景幾何，例如計數或距離，大多來自模擬環境）。在 **VTAB-1k** 中，每個任務只提供 1,000 個標註訓練樣本（800 個訓練、200 個驗證），因此它測試的是：一個表徵能否從很少的標籤，適應到與預訓練資料很不一樣的任務。

**零樣本評估。** CLIP [40] 這類影像–文字模型在評估時，完全不在目標資料集上訓練：把類別名稱寫成文字提示，再把影像歸到最相似的提示（見正文的 CLIP 一節）。CLIP 論文用這種方式在 30 多個既有資料集上做了評估，回報零樣本 CLIP 在 27 個資料集中的 16 個上勝過以 ResNet-50 特徵做的線性探測，並發現對 ImageNet 集成 80 個提示模板，比單一預設提示多了 3.5 個百分點。這帶來兩點提醒。第一，提示與類別名稱的寫法都是超參數；在測試集上調整它們，和在測試集上調學習率一樣，會洩漏測試資訊。第二，預訓練資料是網路規模、而且大多未公開，所以「零樣本」並不保證測試影像（或近乎重複的影像）從未被看過。

### ImageNet 的數字有多可靠？

有三條研究路線改變了我們解讀 ImageNet 準確率的方式。

- **重現。** Recht 等人 [7] 盡可能照原始收集流程，為 CIFAR-10 和 ImageNet 重建了新的測試集（ImageNetV2）。所有模型都掉分：CIFAR-10 掉 3–15%，ImageNet 掉 11–14%。但排名大致保持，舊測試集上的進步也轉移到新測試集上。他們的解讀是：掉分來自新舊樣本之間難度的細微偏移，而不是整個社群反覆使用測試集而過擬合（overfitting）。
- **標籤。** Beyer 等人 [8] 為 ImageNet 驗證集重新標註、允許一張影像有多個標籤，發現近年的部分「進步」其實是在擬合原始單一標籤標註的特殊習慣。Northcutt 等人 [9] 估計常見測試集中普遍存在標籤錯誤，而且這些錯誤足以改變哪個模型看起來最好。
- **偏差。** 每個資料集在視角、背景、拍攝者風格上都有自己的「指紋」。DIP 第 13 章回顧了資料集偏差的研究；實務上的教訓是：只要可能，就用獨立收集的資料來測試。

### 殘差網路為什麼好訓練：展開後的梯度

本則補充給出正文解釋殘差網路為何好訓練時背後的簡短推導。

**為什麼好訓練。** 把 $L$ 個預激活（pre-activation）形式的區塊 $\mathbf{x}_{l+1} = \mathbf{x}_l + \mathcal{F}(\mathbf{x}_l)$ 展開，如後續關於恆等映射的論文 [15] 所分析：

$$
\mathbf{x}_L = \mathbf{x}_l + \sum_{i=l}^{L-1} \mathcal{F}(\mathbf{x}_i), \qquad
\frac{\partial \mathcal{L}}{\partial \mathbf{x}_l} = \frac{\partial \mathcal{L}}{\partial \mathbf{x}_L}\Big(\mathbf{I} + \frac{\partial}{\partial \mathbf{x}_l}\sum_{i=l}^{L-1} \mathcal{F}(\mathbf{x}_i)\Big),
$$

其中 $\mathcal{L}$ 是損失函數，$\mathbf{I}$ 是單位矩陣。恆等項把梯度從頂端直接送到任何一個區塊，所以它不會因為許多小 Jacobian 連乘而消失。該論文也發現，讓捷徑保持*純粹*的恆等（把 BN 與 ReLU 移進殘差分支，即「預激活」）可以更容易地訓練更深的網路。

### 另外兩種 CNN 設計：DenseNet 與 RegNet

本則補充說明正文只用兩句話帶過的兩種 CNN 設計。

**DenseNet：把所有東西都再利用。** DenseNet [16] 把特徵再利用推得更遠：在一個密集區塊內，第 $\ell$ 層接收所有前面特徵圖的**串接**，$\mathbf{x}_\ell = H_\ell([\mathbf{x}_0, \mathbf{x}_1, \dots, \mathbf{x}_{\ell-1}])$，其中 $[\cdot]$ 表示通道串接，$H_\ell$ 是 BN–ReLU–卷積。每層只新增少量通道（「成長率」），所以參數效率高，每一層到損失函數都有一條短路徑。代價是記憶體：串接的激活值隨深度增長，使 DenseNet 在實務上比參數量所暗示的還慢。這是之後會一再出現的教訓：參數量、FLOPs 與實際執行時間是三件不同的事。

**RegNet：設計空間，而不是單一設計。** Radosavovic 等人 [19] 研究的是網路的族群，而不是單一贏家。他們從一個廣泛的類 ResNet 網路空間出發，反覆加上限制（例如共用瓶頸比例、各階段寬度遞增），並檢查錯誤率的*分佈*是否變好。最後留下的空間 RegNet，用一條簡單的量化線性規則描述各階段寬度。這是方法論上的教訓：好的架構遵循簡單的規律，而比較模型的分佈，比拿一個調好的模型去比另一個更可靠。

### Squeeze-and-excitation：CNN 裡的注意力

本則補充給出正文摘要的 squeeze-and-excitation 區塊之公式與程式。

SE 區塊 [21] 為任何 CNN 加上便宜、依內容而定的**通道**權重。它先用全域平均池化把每個通道「擠壓」成一個數字，經過一個小型兩層 MLP，再用 sigmoid 閘門乘回每個通道：

$$
\mathbf{s} = \sigma\big(W_2\, \delta(W_1\, \bar{\mathbf{u}})\big), \qquad \tilde{\mathbf{u}}_c = s_c\, \mathbf{u}_c ,
$$

其中 $\mathbf{u}_c$ 是特徵圖的第 $c$ 個通道，$\bar{\mathbf{u}}$ 是各通道平均值組成的向量，$\delta$ 是 ReLU，$W_1$ 以比例 $r$ 降維，$W_2$ 再升回原維度。網路因此能在整體脈絡顯示「動物」時，加強「毛皮」相關的通道。SE 區塊是 EfficientNet 與許多行動裝置網路的一部分。

```python
import torch
import torch.nn as nn

class SE(nn.Module):
    """Squeeze-and-excitation: reweight channels using global context."""
    def __init__(self, c, r=16):
        super().__init__()
        self.fc = nn.Sequential(nn.Linear(c, c // r), nn.ReLU(), nn.Linear(c // r, c), nn.Sigmoid())

    def forward(self, x):                      # x: (B, C, H, W)
        s = x.mean(dim=(2, 3))                 # squeeze: (B, C)
        w = self.fc(s)[:, :, None, None]       # excitation: (B, C, 1, 1) in (0, 1)
        return x * w

print(SE(64)(torch.randn(2, 64, 8, 8)).shape)
```

### 對比式學習細說：SimCLR 與 MoCo

本則補充給出正文摘要的對比式方法背後的損失函數。

對比式方法把同一張影像的兩個擴增**視圖**的嵌入拉近，把不同影像的視圖推遠。SimCLR [34] 取一個 $B$ 張影像的批次，為每張產生兩個隨機視圖，並對每一對正樣本 $(i, j)$ 最小化 InfoNCE（NT-Xent）損失：

$$
\ell_{i,j} = -\log \frac{\exp(\operatorname{sim}(\mathbf{z}_i, \mathbf{z}_j)/\tau)}{\sum_{k=1}^{2B} \mathbb{1}_{[k \neq i]} \exp(\operatorname{sim}(\mathbf{z}_i, \mathbf{z}_k)/\tau)},
$$

其中 $\mathbf{z}$ 是投影後的嵌入，$\operatorname{sim}$ 是餘弦相似度，$\tau$ 是溫度，批次中其他 $2B - 2$ 個視圖當作負樣本。這其實是一個 $2B - 1$ 類的 softmax 分類：「這些之中哪一個是我的搭檔？」SimCLR 發現強力擴增（特別是裁切加上顏色扭曲）、非線性投影頭與大批次都不可或缺。MoCo [35] 則維護一個由緩慢更新的**動量編碼器**（其權重是主編碼器的 EMA）編碼的負樣本**佇列**，避免了對超大批次的需求。
