## 你將學到

- 灰階與彩色影像如何對應到 NumPy 陣列
- `shape`、`dtype` 與通道順序的實際意義
- 每個人都會踩到的兩個坑：BGR 順序與 `uint8` 溢位

## 直覺

數位影像是一個取樣網格，每個取樣點（也就是*像素*）儲存一個亮度值。灰階影像是形狀為 $(H, W)$ 的二維陣列；彩色影像多了一個通道軸，形狀為 $(H, W, 3)$。

$$
I : \{0, \dots, H-1\} \times \{0, \dots, W-1\} \to \{0, \dots, 255\}
$$

第一個索引是**列**（$y$，由上往下），第二個索引是**行**（$x$，由左往右），和數學課上習慣的 $(x, y)$ 順序剛好相反。

## 程式碼

```python
import cv2
import numpy as np

img = cv2.imread("cat.jpg")          # 形狀 (H, W, 3)，dtype 為 uint8，通道順序為 B、G、R
print(img.shape, img.dtype)

rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)   # 用 matplotlib 顯示前先轉換
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) # 形狀 (H, W)

y, x = 120, 200
print(gray[y, x])                    # 先列、後行
```

<Callout type="warn" title="uint8 溢位">
`np.uint8(250) + np.uint8(10)` 會繞回 `4`。做運算前先轉成 `float32`，算完再裁切回 `[0, 255]`。
</Callout>
