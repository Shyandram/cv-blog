Convolution & Image Filtering

IMAGE PROCESSINGBEGINNER14 MIN Needs: Images as arrays ▶ Open in Colab
What you'll learn
  • What a kernel is and how it slides over an image
  • Why a box blur and a Gaussian blur look different
  • How the Sobel kernel turns brightness changes into edges

Intuition

Every output pixel is a weighted average of its neighbors. The weights form a small grid called a kernel. Change nine numbers and the same operation can blur, sharpen, or highlight edges.

The math

G(x,y)=∑i=−kk∑j=−kkK(i,j)I(x+i,y+j)

I is the input image, K is a (2k+1)×(2k+1) kernel, and G is the output. Strictly, this is cross-correlation. True convolution flips K first, which makes no difference for symmetric kernels.

OpenCV's cv2.filter2D computes correlation, not convolution. Flip the kernel with cv2.flip(K, -1) when that matters.

Code

import numpy as np

def conv2d(img, K):
    # img: (H, W) float32, K: (3, 3)
    H, W = img.shape
    p = np.pad(img, 1, mode="edge")
    out = np.zeros_like(img)
    for i in range(3):
        for j in range(3):
            out += K[i, j] * p[i:i+H, j:j+W]
    return out
import cv2, numpy as np

img = cv2.imread("cameraman.png", cv2.IMREAD_GRAYSCALE)
sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], np.float32)
edges = cv2.filter2D(img, cv2.CV_32F, sobel_x)
import torch, torch.nn.functional as F

x = img[None, None]                 # (1, 1, H, W)
K = sobel_x[None, None]             # (out, in, 3, 3)
edges = F.conv2d(x, K, padding=1)  # also correlation
